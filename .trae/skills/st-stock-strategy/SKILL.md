# ST股票高胜率投资策略 (ST Stock Strategy)

本技能基于多份量化研报与实战体系（融合“业绩预告摘帽事件驱动”与“弱转强多因子”模型，历史胜率 68%~82%），专为探索市场中潜在的 ST 板块高胜率投资机会并制定买卖策略而设计。

## 核心策略框架：财务扭亏 + 弱转强

1. **基本面安全垫 (防退市)**：仅选择具有国资背景或优质资产，且最新业绩预告/财报**明确扭亏**（扣非净利润>0，净资产转正）的标的。绝不碰连续亏损、股价面临面值退市（<1.5元）或被立案调查的垃圾股。
2. **技术面介入点 (弱转强)**：选择在低位横盘后温和放量，或出现“前日涨停、次日低开缩量回踩10日/20日均线”的空中加油形态。
3. **情绪与周期**：重点在每年 1月（业绩预告期）至 4月（年报摘帽期）进行布局；利用市场对“确定性不退市”的估值修复进行套利。
4. **风控纪律**：ST 股总仓位 ≤15%，单只标的 ≤5%；严格执行 -5% 至 -8% 的单次交易止损线。

## 执行工作流

当用户调用此技能时，你需要自动执行以下 3 个步骤，最后输出完整的分析报告：

### 1. 探索潜在机会 (数据筛选)
使用 **mcp_AI_Tools_ChoiceStockByIndicators** 或 **mx_stocks_screener** 筛选当前满足以下条件的优质 ST 标的：
- 股票名称包含 "ST" 或 "*ST"
- 最新一期净利润同比增长，或扣非净利润为正
- 股价 > 1.5元，市值在 5亿~50亿 之间
使用 **WebSearch** 或 **mx_finance_search** 查询标的是否有“重整完毕”、“实控人变更”或“申请摘帽”等催化事件。

### 2. 买卖点与胜率计算 (深度分析)
针对筛选出的 1~3 只优质候选标的，获取其近期K线数据（**QueryStockPriceInfo** / **GetMinuteKLineData**）并进行量化计算：
- **目标买入价**：结合近期关键均线（如10日或20日均线）及缩量回踩区间的合理低吸价位（例如：较前日收盘价低开 -1% 至 -5% 的区间）。
- **胜率预估**：结合基本面扭亏的确定性与技术面的强度，给出一个胜率预估数值（通常在 60%~82% 之间），并说明支撑该胜率的核心逻辑（如：国资属性+业绩扭亏+弱转强形态）。
- **目标卖出价**：
  - *短期波段*：买入价的 +10% ~ +15%。
  - *事件兑现*：如果博弈摘帽预期，建议在“正式年报披露前”或“摘帽公告发布当天高开时”卖出（买预期卖事实）。
- **明确止损位**：建议设定为买入价的 -5% ~ -8%，跌破核心均线无条件离场。

### 3. 输出策略报告
将上述分析总结为结构化的 Markdown 报告返回给用户。报告需包含：
1. **当前市场环境与板块情绪评估**
2. **目标个股精选分析**（包含：股票基本面逻辑、目标买入价、预估胜率及核心支撑逻辑、目标卖出价、止损位）
3. **仓位管理与红线风控纪律**

## 适用场景
- 用户要求寻找、推荐高胜率的 ST 股票投资机会。
- 用户询问某只特定 ST 股票是否值得买入，以及具体的买卖点。
- 用户要求基于最新市场环境，生成一份 ST 板块投资报告。
