## 四、MD&A 深度信息

### 4.1 经营回顾

**2025年全年业绩亮点：**
- 总收入：118亿美元，同比+4%（不计外币换算影响同样+4%）
- 系统销售额：同比+4%（不计外币换算影响）
- 同店销售额：同比+1%，连续三个季度实现同店正增长
- 经营利润：13亿美元，同比+11%
- 经营利润率：10.9%，同比提升60个基点，创2016年上市以来最高纪录（不含特殊项目）
- 餐厅利润率：16.3%，同比提升60个基点
- 每股摊薄盈利：2.51美元，同比+8%；剔除按市值计价股权投资影响后+14%
- 净新增门店：1,706家，门店总数达18,101家
- 外卖销售：同比+25%，占公司餐厅收入约48%（2024年：39%）
- 会员总数：肯德基及必胜客会员超5.90亿，同比+13%

**分品牌表现：**
- 肯德基：全年净新增1,349家门店（总数12,997家），系统销售额+5%，同店销售额+1%，经营利润+8%，餐厅利润率17.4%（同比+0.5pct）
- 必胜客：全年净新增444家门店（总数4,168家），系统销售额+4%，经营利润+19%至1.83亿美元，餐厅利润率12.8%（同比+0.8pct）
- 新兴品牌：肯悦咖啡门店从约700家增至2,200家，单店日均销售杯数同比+25%；KPRO轻食新增超200家门店；Lavazza门店146家

**成本结构优化：**
- 食品及包装物成本占餐厅收入比下降
- 物业租金及其他经营开支占餐厅收入比下降（新店型投资总额降低，折旧相关费用减少）
- 部分被外卖占比提高带来的人工成本（骑手成本）上升所抵消
- 管理费用率4.9%，同比改善0.1pct

### 4.2 前瞻指引（2026年）

| 指引项目 | 内容 |
|----------|------|
| 净新增门店 | 超过1,900家，门店总数超20,000家 |
| 加盟店占比 | 肯德基和必胜客净新增门店中加盟店占比均达40%-50% |
| 资本支出 | 约6-7亿美元 |
| 股东回报 | 向股东回馈15亿美元 |
| 每股现金股息 | 提高21%至0.29美元/股 |
| 股票回购 | 拟于2026H1进行总计约4.6亿美元的股票回购 |
| 同店销售增长目标 | 0%-2% |
| 长期目标 | 2030年门店数量超30,000家 |

**2027-2028年股东回报展望：**
- 预计2027和2028年股东回报平均每年约9亿至逾10亿美元
- 2028年突破10亿美元
- 从2027年起，计划返还约100%年度自由现金流（扣除非控股权益股息后）

### 4.3 资本配置意图

- **2025年资本配置：** 向股东回馈15亿美元（现金股息3.53亿美元+股票回购11.44亿美元），约占公司总市值8.2%
- **资本支出：** 6.26亿美元，主要用于新店开设和门店翻新
- **自由现金流：** 约8.4亿美元（经营现金流14.66亿美元-资本支出6.26亿美元）
- **回购与分红合计超过自由现金流**，延续"返还现金多于资产负债表重建"的模式
- 现金储备从7.23亿美元降至5.06亿美元，公司更多依赖持续经营现金流而非超额流动性

### 4.4 风险因素

1. **行业竞争加剧**：中国餐饮市场竞争白热化，价格战可能压缩利润率
2. **外卖行业竞争推高用工成本**：骑手成本持续上升
3. **成本端利好因素逐步消退**：原材料价格下降和租金优化的红利可能减弱
4. **消费力下行风险**：宏观经济不确定性影响消费者支出
5. **下沉效果不佳**：低线城市扩张可能不及预期
6. **品牌孵化慢于预期**：新兴品牌（KPRO、Lavazza等）增长可能低于目标
7. **食品安全风险**：餐饮行业固有的食品安全隐患
8. **原材料价格波动风险**：大宗商品价格不确定性
