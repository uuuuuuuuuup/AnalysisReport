## 二、核心分析框架：供给-需求时间轴

```
第一阶段：供给冲击（战争+地缘）
    ├─ 霍尔木兹海峡封锁 → 原油供给中断
    ├─ 油价暴涨 → 通胀飙升
    └─ 企业成本上升 → 供给收缩
    ↓
第二阶段：流动性传导（滞胀期）
    ├─ 日本加息 → 日债崩盘风险
    ├─ 欧债连锁反应 → 外汇掉期/基差套利出问题
    ├─ 美债利率飙升 → 财政刺激空间压缩
    └─ 高估值科技股承压 → 资本脱虚向实
    ↓
第三阶段：需求萎缩（衰退确认）
    ├─ 高油价持续 → 制造业停工停产
    ├─ 东南亚/日韩需求下降 → 中国出口受影响
    ├─ 营建业受冲击 → 就业恶化
    └─ 消费萎缩 → 全面衰退
    ↓
第四阶段：政策应对
    ├─ 美联储被迫扩表/降息
    ├─ 或坚持不扩表 → 流动性枯竭
    └─ 最终结局：绕不开扩表
```

**关键操作原则**：
- 滞胀阶段（供给减少+需求维持）：大宗商品跑赢标普，持有黄金
- 衰退阶段（供给减少+需求萎缩）：清仓风险资产，持有人民币现金

## 九、注意事项（修正版）

1. **数据时效性**: BLS非农数据每月第一个周五发布，CPI每月中旬发布。查询时需注意数据是否已公布。

2. **ISM无建筑业PMI**: 美国ISM不发布独立建筑业PMI，可用NAHB房屋市场指数或S&P Global行业PMI替代。

3. **互换利差和保险费率**: 这两项数据通常需要彭博终端或专业订阅，普通搜索可能无法获取。

4. **霍尔木兹海峡状态**: 关注财新"霍尔木兹日报"系列报道，每日更新通航情况。**这是总开关指标，优先级最高。**

5. **SCFI判断**: 连续上涨需区分是成本推动（船公司涨价）还是供给中断（港口拥堵）。前者偏黄灯，后者偏红灯。

6. **标普500走势判断**: 需结合历史高点位置。当前是否处于"次高点后继续下跌"需要对比前期高点判断。7000点是两倍涨幅满足位，5557是20%回撤位。

7. **原油近远月价差**: 深度倒挂（近月远高于远月）意味着企业不愿增产，将延长供给短缺时间，是重要的前瞻性指标。

8. **铜金比**: 处于历史极低值时，若经济未崩溃，应回归中枢区间。持续创新低+经济恶化=衰退确认。

9. **4月底总开关**: 即使当前评分在黄灯区，如果4月底前霍尔木兹海峡恢复正常，评分可能快速回落；反之，如果战争持续，评分将快速恶化至红灯区。

10. **根本逻辑检验**: 每次检测时需问：黄金上涨的根本逻辑（财政危机+去美元化）是否改变？如果没有改变，回调是加仓机会；如果确认衰退，则清仓。
