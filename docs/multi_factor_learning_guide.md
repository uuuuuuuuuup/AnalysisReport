## 1. 核心概念：因子到底是什么

### 1.1 一个直观类比

想象你要在1000个学生里挑出期末考试会考好的20个。你可以看：

- **平时成绩（质量因子）**：过去3次月考均分 → 类 ROE
- **学习态度（动量因子）**：最近成绩是上升还是下降 → 类价格动量
- **身体状态（低波动因子）**：有没有熬夜打游戏 → 类低换手率
- **家庭条件（价值因子）**：家里有没有请家教（但成绩目前不好）→ 类低 PB

**因子 = 一个可以量化的、能预测未来收益的股票特征。**

### 1.2 因子为什么能赚钱？

两条底层逻辑，必须至少命中一条：

| 逻辑 | 解释 | 典型因子 | 风险 |
|------|------|----------|------|
| **风险补偿** | 承担了某种系统性风险，市场给你补偿 | 价值、小市值 | 熊市中跌更多 |
| **行为偏差** | 投资者系统性犯错，理性交易者套利 | 短期反转、低波动 | 拥挤后失效 |

如果一条因子两条都解释不了，那它大概率是数据挖掘出来的噪音，样本外会归零。

```
验证方法：问自己"对手盘是谁？"
  - 我买低PB股票 → 对手盘是"不愿意持有便宜货"的人 → 他们为什么卖？
  - 我买动量股 → 对手盘是"觉得涨多了要回调"的人 → 他们为什么错？

如果找不到一个合理的对手盘，这个因子就不成立。
```

### 1.3 因子的数学定义

一个因子就是一个**截面上的数值向量**：

```
时刻 t（比如2024-01-31收盘后）：
  股票A: ROE=15%, BP=0.8, Mom_12m=+25%, ...
  股票B: ROE=8%,  BP=1.2, Mom_12m=-10%, ...
  股票C: ROE=22%, BP=0.5, Mom_12m=+40%, ...
  ...

因子值 f_i 和未来收益 r_{i,t+1} 之间的关系，决定了因子是否有效。
```

## 2. 因子测试框架

### 2.1 IC：信息系数（Information Coefficient）

**最核心的指标。** IC 衡量因子值和未来收益之间的截面相关性。

```
IC_t = corr(factor_values_t, forward_returns_{t+1})
```

- **Rank IC（推荐）**：用 Spearman 秩相关，对异常值鲁棒
- **Pearson IC**：用线性相关，受异常值影响大
- **IC > 0**：因子值越大 → 未来收益越高（正向因子，如 ROE、动量）
- **IC < 0**：因子值越大 → 未来收益越低（反向因子，如换手率）

**解读标准：**

| Rank IC 月均值 | 评价 |
|----------------|------|
| > 0.05 | 很强（罕见） |
| 0.03 ~ 0.05 | 良好 |
| 0.01 ~ 0.03 | 可用但弱 |
| < 0.01 | 没有预测力 |
| 符号不稳定（正负交替） | 垃圾因子 |

### 2.2 ICIR：信息系数信息比

IC 的均值和波动率都很重要。**ICIR = mean(IC) / std(IC)** 告诉你 IC 的稳定性。

```
ICIR = IC均值 / IC标准差
```

| ICIR | 评价 |
|------|------|
| > 1.0 | 极稳定（罕见） |
| 0.5 ~ 1.0 | 很稳定 |
| 0.3 ~ 0.5 | 中等稳定 |
| < 0.3 | 不稳定，噪声大 |

**IR = IC × sqrt(调仓次数)** → 月频一年调 12 次，IC=0.03，预期 IR = 0.03 × sqrt(12) = 0.10。这说明 IC=0.03 的因子单独很难做出高夏普。

### 2.3 分层回测：检验单调性

按因子值把股票分成 5 组或 10 组，每组等权持有，看各组未来收益是否单调排列。

```
操作方法：
1. 每月末按因子值排序，分成 Q1（最低）到 Q5（最高）
2. 每组等权持有到下月末
3. 画出 5 条净值曲线

如果因子有效：
  - Q5 收益 > Q4 > Q3 > Q2 > Q1（正向因子）
  - 或 Q1 > Q2 > Q3 > Q4 > Q5（反向因子）
  - Top-Bottom 组合（多Q5空Q1）有正收益

如果因子无效：
  - 各组曲线纠缠不清
  - Top-Bottom 组合收益≈0
```

### 2.4 因子相关性矩阵

两个 IC=0.04 的因子如果相关系数 0.9，合在一起没有增量信息。优选低相关的因子组合。

```
目标：找到 3-6 个 IC 稳定、彼此低相关（|ρ|<0.3）的因子。
```

### 2.5 一个完整因子测试的检查清单

```
□ Rank IC 月度均值 > 0.02 且方向一致（同向月份 > 60%）
□ ICIR > 0.3
□ 分层 Q5-Q1 年化收益 > 5%
□ 分层单调性成立（Q1<Q2<Q3<Q4<Q5 或反向）
□ 因子和其他候选因子相关性 < 0.5
□ 训练区间和检验区间 IC 方向一致（不反转！）
□ 行业中性化后 IC 不归零（说明不是纯行业暴露）
□ 市值中性化后 IC 不归零（说明不是纯规模暴露）
```

## 3. 单因子实战：构造、清洗、中性化

### 3.1 数据处理流水线

每期截面上的因子计算，必须按这个顺序，**顺序不能错**：

```
原始数据
  ↓
① 缺失值处理：缺失即剔除（不用均值填充，会把垃圾拉到中位）
  ↓
② 去极值: MAD 法 (median ± 5×1.4826×MAD) 或分位数法 (1%, 99%)
  ↓
③ 中性化: 对行业哑变量 + ln(市值)回归, 取残差
  ↓
④ 标准化: z-score → 均值0, 标准差1
  ↓
⑤ 方向调整: 如果因子是反向的，乘以 -1
  ↓
最终因子得分
```

### 3.2 为什么必须中性化？

一个真实的陷阱：

```
你发现"ROE高 → 未来收益高"，IC=0.05 很好。
但你做行业中性化后，IC降到0.01 → 几乎归零。

原因是：ROE高的股票刚好集中在食品饮料行业，而食品饮料
         过去几年是大牛市。你的因子不是在选股，是在选行业。

不加中性化 = 你不知道赚的是因子的钱还是行业的钱。
```

同理，**市值中性化**让你排除"只是在选小盘股"的解释。

### 3.3 几个关键因子的构造方法

#### 价值因子：BP（市净率倒数，Book-to-Price）

```python
bp = 1.0 / pb_ratio  # pb_ratio > 0 时才有效
# 方向: +1（BP越高越便宜，预期收益越高）
# 行业中性化尤其重要：银行天然PB低，科技天然PB高
```

#### 质量因子：ROE（净资产收益率）

```python
roe = net_profit / book_value
# 方向: +1（ROE越高越优质）
# 陷阱：ROE高的可能是周期顶点，要结合稳定性
# 应计利润（Accruals）是更好的质量指标：
#   accruals = (Δ流动资产 - Δ现金) - (Δ流动负债 - Δ短期债务) - 折旧
#   低应计 = 高质量（盈利有现金支撑，不是账面数字）
```

#### 动量因子：12-1个月收益

```python
# 过去12个月收益，但剔除最近1个月（避免短期反转污染）
momentum_12m1m = close[-21] / close[-252] - 1
# 方向: +1
# 21个交易日≈1个月, 252个交易日≈1年
```

#### 低波动因子：过去60日收益率标准差

```python
vol_60d = returns[-60:].std()
# 方向: -1（低波动预期收益更高，A股异象！）
# 注意：这与CAPM预测相反，全球多数市场低波动=低收益
# A股散户追逐高波动 → 高波动被高估 → 低波动反而有超额
```

#### 低换手因子

```python
turnover_20d = avg_daily_turnover[-20:]  # 过去20日均换手率
# 方向: -1（低换手=高预期收益）
# 经济学解释：散户过度交易，低换手意味着被市场忽视、定价不充分
```

## 4. 多因子合成

### 4.1 三种合成方法

| 方法 | 公式 | 优点 | 缺点 |
|------|------|------|------|
| **等权** | score = Σ z(f_i) | 不依赖历史，最稳健 | 弱因子和强因子权重一样 |
| **IC加权** | score = Σ IC_i × z(f_i) | 给强因子更高权重 | IC不稳定，权重漂移 |
| **ICIR加权** | score = Σ ICIR_i × z(f_i) | 兼顾强度和稳定性 | 样本内过拟合风险 |

**推荐：等权。** 你的 CSI1000 增强策略已验证：样本内最优权重(roe70/bp30)的样本外 IR 仅 0.06，远不如固定 50/50 的 0.49。

```
教训：因子合成权重和策略参数一样，在训练集上优化会严重过拟合。
      简单等权是最安全的选择。
```

### 4.2 因子入库标准（不达标的因子不进合成池）

```
标准：
  1. 训练区间 Rank IC 月均值 > 0.02
  2. 训练区间 IC 正月率 > 60%（12个月里≥8个月IC为正）
  3. 训练区间和检验区间 IC 方向一致（绝对值不重要，方向必须一致）
  4. 与其他已入库因子相关性 |ρ| < 0.5
  5. 分层 Q5-Q1 年化 > 5%
```

## 5. 组合构建：从得分到持仓

### 5.1 最简单的组合：得分 Top N 等权

```python
ranked = scores.sort_values(ascending=False)
targets = ranked.index[:N]  # 取前 N 只
weight = 1.0 / N            # 等权
```

**优点：** 简单、透明、不引入额外参数。
**缺点：** 可能在某个行业/风格上过度集中。

### 5.2 进阶（不建议你做）：风险模型约束

Barra 模型可以在组合优化中加入行业偏离上限、风格因子暴露上限等约束。**但对 10-100 万的小资金没必要。** 约束越多，超额越少。简单 Top N 等权够用。

### 5.3 调仓频率

```
频率    换手率    容量    衰减风险    适合
日频    极高     小      高          高频因子（不推荐）
周频    高       中      中          技术类因子
月频    中       大      低          ★ 基本面因子最佳选择
季频    低       大      极低        纯价值因子
```

**推荐：月频。** 你的基本面因子（ROE、BP）月度更新已经够用，更频繁调仓只会增加交易成本。

### 5.4 持仓数量

```
持仓数   单仓占比   分散度   跟踪误差   管理复杂度
10只    10%       低       高         简单
20只    5%        中       中         中等  ← 推荐小账户
30只    3.3%      高       中低       中等  ← 推荐100万账户
50只    2%        很高     低         偏高
```

## 6. 训练/检验/留出：防过拟合的纪律

### 6.1 三段式区间设计

**这是整个流程中最重要的部分。** 做错了前面全白费。

```
全区间：        2015-01 ─────────────────────────── 2026-07
                 │                  │                │
训练区间：      2015-01 ──── 2021-12│                │
                 （反复探索，跑无数次）               │
                                    │                │
检验区间：                         2022-01 ── 2024-12│
                                   （只测一次！）    │
                                                     │
留出区间（实盘前）：                                2025-01 ── 2026-07
                                                   （只测一次！）
```

**规则：**

| 区间 | 可以做什么 | 不能做什么 |
|------|-----------|-----------|
| **训练区间** | 反复回测、调整因子、修改参数、看任何指标 | — |
| **检验区间** | **只跑一次**，看结果 | 根据结果回去改参数！ |
| **留出区间** | **只跑一次**，最终确认 | 根据结果回去改任何东西！ |

### 6.2 为什么检验区间只能测一次？

```
你设计了一个因子，在训练区间 IC=0.04。
在检验区间 IC=0.01 → 你回去改参数 → 新参数在检验区间 IC=0.04。
然后你宣称"因子在训练集和检验集都表现良好"。

问题是：你已经看过检验区间了。你的第二次"测试"其实是训练。
检验区间已经被污染了。

正确做法：
  检验区间 IC=0.01 → 这个因子废了，放弃它。
  不要试图"修好"它。用训练区间找新因子。
```

### 6.3 训练区间的正确使用方式

在训练区间你可以：
- 挖掘新因子并计算 IC、ICIR
- 淘汰不达标的因子（IC不稳定、分层不单调）
- 测试不同的中性化方案
- 评估因子相关性，做因子筛选

**不要做的：**
- 用网格搜索找"最佳参数组合"
- 开了几十个因子后挑选 IC 最高的几个
- 在检验区间跑过后再回来改方案

## 7. 从研究到生产

### 7.1 冻结规格文档模板

一旦你确定了因子组合，写死一个冻结规格。参考你已有的模板：

```markdown
# XXXX多因子选股冻结规格

## 策略概述
- 类型: 多因子选股（月频）
- 标的池: 中证800成分股
- 持仓数: 30只等权

## 因子定义
| 因子 | 方向 | 权重 | 构造方法 |
|------|------|------|----------|
| BP（价值） | +1 | 1/4 | 1/PB，行业市值中性化 |
| ROE（质量） | +1 | 1/4 | 过去4季ROE均值，行业市值中性化 |
| 低波动 | -1 | 1/4 | 60日收益率标准差，行业市值中性化 |
| 动量12-1 | +1 | 1/4 | 过去12个月剔除最近1月收益，行业市值中性化 |

## 冻结参数
- 调仓: 每月首个交易日
- 单仓上限: 5%
- 剔除: ST、*ST、上市<120日、涨跌停、动量最高20%
- 成本: 佣金万0.85免5，印花税千1

## 验证结果
| 指标 | 训练 2015-2021 | 检验 2022-2024 | 留出 2025-2026 |
|------|---------------|---------------|----------------|
| 年化超额 | | | |
| IR | | | |
| 最大回撤 | | | |
| 月度胜率 | | | |

## 不改清单
- 因子权重锁定等权
- 中性化方案不变
- 持仓数不变
- 调仓频率不变
```

### 7.2 研究脚本 vs 生产脚本

```
研究阶段（聚宽研究环境 / notebook）
  → 大盘探索、因子测试、IC计算、分层回测

  → factor_research.py

  → 只读冻结参数、不做任何分析计算
  → 代码给模拟盘/实盘用的，不允许频繁修改
  → multi_factor_strategy_bq.py
```
