# 质量增强可转债双低轮动 — 策略设计规格

> 状态：设计完成，待实现
> 日期：2026-07-29

---

## 一、策略核心框架

**策略名称：** 质量增强可转债双低轮动（Quality-Enhanced CB Double-Low）

**一句话逻辑：** 在传统双低（便宜+低溢价）的底子上，用正股质量因子排除"便宜是有原因的"那类券。

**对标基准：** 中证转债指数（000832）

**操作方式（普通投资者 C 类型）：**
- 月频调仓（每月最后一个交易日收盘前）
- 持仓 20 只，等权
- BigQuant 跑信号 → 导出持仓名单 → 手动下单
- 每只买 10 张的整数倍（1 手 = 10 张）

**核心假设（待检验）：**
1. 正股质量因子在可转债上有正向选券能力（IC > 0）
2. 质量因子与双低因子截面相关性不高（< 0.3），组合后有分散增益
3. 加入质量过滤能降低信用风险踩雷概率（搜特/蓝盾类）

## 二、因子定义与数据源

**数据平台：** BigQuant（`dai.query`）

**数据表：**

| 表名 | 用途 |
|---|---|
| `cn_cbond_bar1d_te` | CB 日线（close, cb_over_rate） |
| `cn_cbond_basic_info` | CB 基本信息（stock_code, maturity_date, list_date） |
| `cn_stock_valuation_v6` | 正股估值（pb, pe_ttm → 反推 ROE；market_cap） |
| `cn_stock_bar1d` | 正股日线（动量计算） |
| `cn_stock_financial_v6` | 正股财报（毛利率、资产负债率、经营现金流） |

**因子定义：**

```
双低维度（已有验证）：
  f_price    = -z(close)           # 价格越低越好
  f_premium  = -z(cb_over_rate)    # 溢价率越低越好

质量维度（待检验）：
  f_roe      = z(PB / PE_ttm)      # ROE 估算，越高越好
  f_gross_margin = z(毛利率)        # 最新季报，越高越好
  f_debt     = -z(资产负债率)       # 越低越好
  f_cash     = z(经营现金流/营收)    # 越高越好

质量合并（等权，四个子因子都有效才纳入）：
  f_quality  = mean(f_roe, f_gross_margin, f_debt, f_cash)

最终打分（先验固定，禁止基于回测结果调整）：
  score = 0.40 × f_price + 0.30 × f_premium + 0.30 × f_quality
```

**权重依据：** 双底维度占 70%（价格 40% + 溢价率 30%），质量占 30%。即使质量因子 IC 为零，策略退化为噪音略大的纯双低——安全边际优先。

**候选池过滤：**
- 上市 ≥ 30 天
- 距到期 > 12 个月
- 非 ST 正股
- 信用过滤：`close < 80` 且 `premium > 100%` → 剔除
- 动量硬排除：正股 40 日动量最差 20% 剔除（CSI1000 策略已验证该档年化 -8.7%）

**缺失值处理：**
- 财报数据缺失 ≥ 2 个质量子因子 → 质量分记为 0（退化为纯双低）
- 财报数据缺失 < 2 个 → 有效因子等权合并

**去极值：** MAD 5 倍
**中性化：** 不做。CB 数量有限（通常 200-400 只），行业 + 市值中性化会消耗过多自由度。

## 三、研究协议（防过拟合）

**数据墙：**

```
训练集：2019-01 ~ 2022-12（48 个月）
封存测试集：2023-01 ~ 2026-07（43 个月）
```

选择 2019 起点的原因：可转债市场 2017 年前数量不足（< 50 只），2018 年信用收紧后扩容，2019 年起才具备统计意义。

**研究步骤（严格按顺序，不可跳步）：**

| 步骤 | 内容 | 看的数据 | 产出 |
|---|---|---|---|
| 1 | 单因子 IC 检验 | 训练集 | 每个质量因子在 CB 上的 Rank IC、IC_IR、IC>0 比例 |
| 2 | 因子截面相关性 | 训练集 | 质量因子之间、质量 vs 双低的相关性 |
| 3 | 分层收益 | 训练集 | 各因子分 10 组，看顶-底单调性 |
| 4 | 组合回测 | 训练集 | 固定参数跑一次，记录全部指标 |
| 5 | 前后段一致性 | 训练集 | 拆 2019-2020 vs 2021-2022，夏普差、月胜率差 |
| 6 | N×权重 稳健性 | 训练集 | N=15/20/30，w_quality=0.2/0.3/0.4，看中位夏普范围和极差 |
| 7 | 🔒 冻结参数 | — | 锁定后不可修改 |
| 8 | 🚫 测试集一次性回测 | 测试集 | **只跑一次**，跑完即作废 |

**步骤 8 的判定规则：**

| 测试集结果 | 判定 | 动作 |
|---|---|---|
| 夏普 > 0.8，月胜率 > 55% | 通过 | 进入模拟盘 |
| 夏普 0.5~0.8 | 边缘 | 进入模拟盘，但标注"证据不足" |
| 夏普 < 0.5 或月胜率 < 50% | 不通过 | 退回纯双低 |

## 四、验收标准

| 指标 | 目标 | 最低可接受 |
|---|---|---|
| 训练集夏普 | > 1.0 | > 0.8 |
| 训练集卡玛 | > 1.0 | > 0.7 |
| 训练集信息比率 | > 0.5 | > 0.3 |
| 训练集月胜率 | > 60% | > 55% |
| 前后段夏普差 | < 0.3 | < 0.5 |
| 前后段月胜率差 | < 10% | < 15% |
| 测试集夏普 | > 0.8 | > 0.5 |
| 测试集 vs 纯双低超额 | 正 | — |

## 五、实施文件结构

```
因子检验/
├── cb_quality_factor_research.py    # 步骤 1-6：训练集内全部研究
└── cb_quality_holdout.py            # 步骤 8：测试集一次性回测
```

**cb_quality_factor_research.py 结构：**

```
1. 数据拉取（并行取 CB + 正股估值 + 财报 + 动量）
2. 构建月度调仓日 + 动态候选池
3. 计算各因子截面值 → 去极值(MAD 5x) → z-score
4. 未来收益矩阵（下月 close / 当月 close - 1，等权）
5. 单因子 IC 分析（Rank IC、IC_IR、IC>0 比例）
6. 因子截面相关性矩阵
7. 分层收益（10 组）+ 单调性
8. 质量合并因子构建（缺失退回逻辑）
9. 最终打分回测（N=20，等权，月频）
   - 全训练集绩效
   - 分年度收益
   - 前后段对比（2019-2020 vs 2021-2022）
10. N × w_quality 稳健性网格（N=15/20/30, w_quality=0.2/0.3/0.4）
11. 与纯双低基线的横向对比表
12. 输出冻结参数建议
```

**cb_quality_holdout.py 结构：**

```
1. 加载冻结参数
2. 2023-01 ~ 2026-07 一次性回测
3. 输出全部绩效指标 + 与训练集的对比
4. 判定：通过 / 边缘 / 退回纯双低
```

## 六、已知风险与容错

| 风险 | 可能性 | 影响 | 容错设计 |
|---|---|---|---|
| 质量因子 IC=0 | 中 | 策略退化为噪音放大的纯双低 | 双底占 70%；若测试集验证不如纯双低，退回 |
| 财报缺失/延迟 | 高 | 部分券无法参与质量打分 | 缺失 ≥ 2 子因子时质量分记为 0，退回双低兜底 |
| CB 违约常态化 | 中 | 单券归零 | 信用过滤 + 质量过滤双防线；20 只等权限定单券 ≤ 5% |
| 流动性不足 | 中 | 买不到/滑点大 | 步骤 1 加入流动性字段；若中位日成交 < 50 万，降持仓或放弃 |
| 风格切换失效 | 高 | 质量因子阶段性跑输 | 不择时，通过前后段对比暴露敏感性；差 > 0.5 降低质量权重 |

## 七、训练集 vs 测试集 分离规则

**硬规则（违反即作废）：**
1. 测试集数据在步骤 1-6 中**完全不加载**
2. 任何因子 IC、分层收益、参数选择**只能看训练集结果**
3. 步骤 6 的网格只用于确认参数不敏感，**禁止**选最优参数
4. 冻结参数后，测试集**只能跑一次**

**参考既有教训：**
- CSI1000 增强已验证 IS/OOS 相关性 -0.815，参数优化在 A 股有系统性危害
- 等权是防御过拟合的最强形式
- 缓冲带优于硬性重排（已证缓冲带制造价值陷阱）
- 不做移动止损（已验证止损触发频率过高，在噪音带内）
- 不选时、不择时（MA 择时已验证破坏 alpha）

## 八、对普通投资者的交付物

1. **月度信号脚本** — BigQuant 上跑，输出 20 只 CB 代码 + 名称 + 买入张数
2. **操作步骤说明** — 调仓日期、登录方式、下单步骤
3. **心理准备文件** — 历史最大回撤、逆风年份、最长连续跑输月数、单券归零影响测算
4. **监控清单** — 每月记录项、告警阈值、什么情况停下来复核
