**日期**：2026-05-30  
**版本**：v1.0  
**状态**：待评审

---

## 1. 背景与目标

AI-Tools 的 `QueryStockPriceInfo` 接口已支持返回 `premiumRate`（溢价率）字段。本工具旨在利用该能力，构建一套聚焦 **QDII-LOF** 的溢价套利机会发现系统。

### 核心目标

- 扫描用户配置的 QDII-LOF 清单，筛选溢价率 > 3% 的标的
- 对达标标的进行深度分析（趋势、流动性、费用、风险、操作建议）
- 生成结构化 Markdown 报告，辅助套利决策

### 非目标

- 不做全自动交易执行（仅做分析，不决策）
- 不覆盖 ETF（套利空间极小）
- 不做 A股 LOF（溢价率通常 < 1%，无实质套利空间）
- 不做历史数据长期存储（覆盖式存储，仅保留最新一次）

采用**数据采集脚本 + Claude Code Skill**的两层架构，复用投资组合周报的模式：

```
┌─────────────────────────────────────────────────────────┐
│  Config: config/qdii_lof_list.json                       │
│  （用户手动维护的 QDII-LOF 代码清单）                      │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  Step 1: scripts/fetch_arbitrage_data.py                │
│  数据采集脚本                                             │
│  • 读取代码清单                                           │
│  • 批量查询溢价率 + K线 + 成交量                           │
│  • 输出 data/arbitrage_raw.json                           │
└─────────────────────────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────┐
│  Step 2: Claude Code /fund-arbitrage Skill              │
│  深度分析与报告生成                                        │
│  • 读取 arbitrage_raw.json                                │
│  • AI 分析每只标的的趋势、流动性、风险、净套利空间            │
│  • 生成 ./套利机会报告/YYYY-MM-DD_套利扫描.md              │
└─────────────────────────────────────────────────────────┘
```

## 3. 组件详细设计

### 3.1 配置文件（config/qdii_lof_list.json）

首次使用时由用户手动创建，格式：

```json
{
  "update_date": "2026-05-30",
  "funds": [
    {
      "code": "162411",
      "name": "华宝油气LOF",
      "type": "QDII-LOF",
      "market": "sz",
      "notes": "原油主题，波动大"
    },
    {
      "code": "160644",
      "name": "港美互联网LOF",
      "type": "QDII-LOF",
      "market": "sz",
      "notes": ""
    },
    {
      "code": "501312",
      "name": "海外科技LOF",
      "type": "QDII-LOF",
      "market": "sh",
      "notes": ""
    }
  ]
}
```

**维护说明**：
- 从集思录或东方财富"QDII-LOF"列表导出后粘贴
- `market` 字段用于区分 `sz`/`sh`（API 需要完整代码如 `sz160644`）
- `notes` 留给用户做备忘（如"限购1000元"）

### 3.2 数据采集脚本（fetch_arbitrage_data.py）

**输入**：`config/qdii_lof_list.json`

**输出**：`data/arbitrage_raw.json`

**采集数据项**：

| 数据项 | MCP 工具 | 用途 |
|:---|:---|:---|
| 实时价格 + 溢价率 | `QueryStockPriceInfo` | 核心：判断当前是否满足 >3% 阈值 |
| 近 5 日 K 线 | `GetDailyKLineData` | 计算溢价率趋势（扩大/收窄） |
| 今日资金流向 | `GetStockMoneyFlowDetail` | 评估流动性 |
| 相关新闻 | `GetStockRelatedNews` days=3 | 风险提示（如限购公告） |

**批量查询策略**：
- `QueryStockPriceInfo` 一次最多支持约 10-20 个代码，分批调用
- 其他接口逐个调用，中间加 1 秒延迟防限流

### 3.3 Claude Code Skill（/fund-arbitrage）

**触发方式**：用户在 Claude Code 中输入 `/fund-arbitrage`

**执行流程**：
1. 读取 `data/arbitrage_raw.json`
2. 筛选 `premium_rate >= 3.0%` 的标的进入深度分析
3. 对每只标的执行分析：
   - **溢价率趋势**：对比近 5 日 K 线中的收盘价，判断溢价率是扩大、收窄还是震荡
   - **流动性评估**：成交额是否足够大（建议 >1000 万），主力资金流向
   - **费用测算**：申购费 + 卖出佣金（假设合计 0.15%），计算净套利空间
   - **风险扫描**：新闻中是否有"限购"、"暂停申购"、"外汇额度"等关键词
   - **操作建议**：综合以上给出明确建议（建议申购/观望/风险提示）
4. 生成 Markdown 报告，写入 `./套利机会报告/YYYY-MM-DD_套利扫描.md`

**分析深度控制**：
- 如果 `above_threshold == 0`（没有标的达标），报告转为"全市场 QDII-LOF 套利机会扫描 —— 今日无达标标的"，并列出溢价率最高的 3 只做观察参考
- 如果 `above_threshold > 5`，只深度分析前 5 只，其余列在附录清单中

## 4. 执行流程

### 4.1 首次运行

```bash
# 1. 创建目录
mkdir -p config data 套利机会报告

# 2. 创建代码清单（用户手动编辑）
cat > config/qdii_lof_list.json << 'EOF'
{
  "update_date": "2026-05-30",
  "funds": [
    {"code": "162411", "name": "华宝油气LOF", "market": "sz"},
    {"code": "160644", "name": "港美互联网LOF", "market": "sz"},
    {"code": "501312", "name": "海外科技LOF", "market": "sh"}
  ]
}
EOF

# 3. 运行数据采集
python3 scripts/fetch_arbitrage_data.py

# 4. 在 Claude Code 中生成报告
# 用户输入：/fund-arbitrage
```

### 4.2 日常运行

```bash
# Step 1: 更新代码清单（如需）
vim config/qdii_lof_list.json

# Step 2: 采集数据（约 1-2 分钟）
python3 scripts/fetch_arbitrage_data.py

# Step 3: 生成深度报告（在 Claude Code 中）
# 用户输入：/fund-arbitrage
# 耗时约 2-5 分钟
```

## 5. 错误处理

| 异常情况 | 处理方式 |
|:---|:---|
| 某只基金数据采集失败 | 标记 `error` 字段，报告中标注"数据缺失"，不阻塞其他标的 |
| MCP 接口限流 | 脚本内增加 1-3 秒延迟，重试 3 次 |
| 全部基金溢价率未达阈值 | 报告转为"无达标标的"模式，列出 Top 3 观察名单 |
| 配置文件缺失或格式错误 | 脚本报错退出，提示用户检查 `config/qdii_lof_list.json` |
| `arbitrage_raw.json` 不存在 | Claude Skill 提示用户先运行数据采集脚本 |
