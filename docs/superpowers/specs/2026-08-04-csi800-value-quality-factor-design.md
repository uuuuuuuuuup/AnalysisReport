# 中证800价值质量多因子策略设计

日期：2026-08-04  
状态：训练期设计已确认，待实现与检验

## 1. 目标与数据边界

- 目标：为10万元试验账户和100万元目标账户构建可回测、可模拟、可人工执行的月频个股策略。
- 训练区间：2015-01-01 至 2021-12-31。
- 历史检验区间：2022-01-01 至 2026-07-31，只在代码和参数冻结后运行完整组合一次。
- 已知限制：历史检验区间的单因子IC已被查看，因此完整组合回测属于弱样本外验证；真正的严格验证来自后续模拟盘和小账户前向记录。

## 2. 训练数据结论

- ROE是核心因子：训练期Mean IC 0.0500、ICIR 0.35、正IC月份61%，Q1至Q5收益层次最清晰。
- BP是互补因子：Mean IC 0.0222，强度较弱，但与ROE相关系数为-0.220，具备价值与质量互补逻辑。
- 低波动不进入线性打分：IC较强，但Q3/Q4优于Q5，缺少线性单调性。
- 12-1动量不进入打分：Mean IC仅0.0180，Q4优于Q5，训练证据不足。
- 低换手不进入打分：训练实现实际使用成交量而非换手率，定义错误；同时五因子组合明显恶化。
- 训练期组合中，BP+ROE等权为最佳简洁方案：年化13.1%、超额8.4%、夏普0.50、最大回撤-35.0%、月均换手63%。

## 3. 冻结策略

### 3.1 股票池和过滤

- 使用调仓日前一交易日的中证800历史成分股。
- 排除ST、停牌、上市不足120自然日、当前价格无效的股票。
- 新买入排除涨停；卖出由持仓退出规则决定，跌停或停牌卖不掉时进入每日重试队列。
- 不使用40日动量硬排除，因为本次中证800训练研究没有验证该规则。

### 3.2 因子和处理

- BP：`1 / PB`，仅保留PB大于0的股票。
- ROE：使用调仓日前一交易日可获得的最新财务数据。
- 每个因子分别执行：缺失剔除 → MAD 5倍去极值 → 申万一级行业与ln(总市值)截面回归中性化 → z-score。
- 综合得分：`0.5 * z(BP残差) + 0.5 * z(ROE残差)`。
- 不根据训练期强弱优化权重。

### 3.3 组合与执行

- 综合得分前30名，等权配置。
- 每月第一个交易日10:00调仓；信号仅使用前一交易日数据。
- 先卖后买；不在目标名单的持仓全部退出。
- 按排名向后准备60只候选；一手金额超过单仓目标的股票顺延，尽量补足30只，避免10万元账户产生高价股偏差。
- 对整数手导致的闲置资金进行有限多轮目标值放大；闲置现金低于1.5%即停止。
- 不设置止损、均线择时、排名缓冲带或回撤自动清仓。

### 3.4 成本与监控

- 股票买卖佣金万0.85、免5；卖出印花税千1。
- 聚宽使用真实价格和防未来数据设置。
- 记录月度净值、基准和滚动超额；滚动12个月超额小于0告警，滚动24个月超额小于0建议停用。
- 最大回撤超过训练期约-35%时告警，仅人工复核，不自动减仓。

## 4. 交付物

- 聚宽策略：与现有ETF双动量脚本保持相同章节、注释、日志和监控风格，可用于历史回测和模拟盘。
- BigQuant策略：将当前五因子草稿改为同一BP+ROE逻辑，删除未验证因子、全A股近似池和预加载未来区间数据的风险。
- 冻结规格：改写现有多因子冻结规格，使其与最终实现和训练证据一致。

## 5. 验证顺序

1. 静态检查和单元测试验证因子处理、排名映射、日期边界和一手可买逻辑。
2. 聚宽仅运行2015-2021训练区间，核对持仓数、换手、成本和绩效方向。
3. 参数冻结后，完整组合只运行一次2022-2026历史检验。
4. 通过后进入模拟盘；历史结果不能替代前向验证。
