# 错杀好股扫描器 (value-mispricing-scanner) 设计文档

**日期**: 2026-07-02  
**状态**: 待实现  
**背景**: 科技板块虹吸效应导致非科技优质公司普遍下跌，需要一个可重复运行的系统化扫描器，从 A 股 + 港股通全市场找出"近期被错杀的低估值高质量公司"。

---

## 目标

- 输入: 无（或可选参数：市场范围、排除行业、回撤阈值）
- 输出: 一份 Markdown 候选清单，含评分排名、关键指标、A 股 Top 候选的诊断摘要
- 可重复: 作为 skill 随时调用，每次重跑获得最新候选

---

## 架构：三级漏斗

```
全市场 A股+港股通
        │
   ┌────▼────┐
   │  L1 粗筛 │  selectSecurity API（自然语言选股）
   │          │  → 排科技 + 低估值 + 高质量 + 近期深跌
   └────┬────┘
      ~200 只
        │
   ┌────▼────┐
   │  L2 陷阱 │  searchData API（批量拉财务趋势）
   │  过滤    │  → 排除基本面恶化的价值陷阱
   └────┬────┘
      ~40-60 只
        │
   ┌────▼────┐
   │  L3 评分 │  三维打分排序
   │  + 诊断  │  + stock-analysis API 对 Top A股做诊断
   └────┬────┘
      Top 20-30 只 + 诊断摘要
```

## L1：粗筛

### API
`POST https://ai-saas.eastmoney.com/proxy/b/mcp/tool/selectSecurity`

### A 股筛选自然语言 prompt
```
筛选沪深A股，条件：
1. PE（TTM）处于该股历史30%分位以下
2. ROE（近12个月）大于10%
3. 距52周最高价回撤幅度超过20%
4. 资产负债率低于65%（银行保险等金融股除外）
5. 总市值大于50亿元
6. 排除以下行业：半导体、集成电路、消费电子、计算机软件、互联网服务、人工智能、芯片设计、通信设备
7. 非ST、*ST股票
返回字段：股票代码、名称、所属行业、PE（TTM）、PB、ROE、股息率、52周最高价、当前价格、回撤幅度、资产负债率、总市值
```

### 港股通筛选自然语言 prompt
```
筛选沪港通和深港通可购买的港股（港股通标的），条件：
1. PE（TTM）处于该股历史30%分位以下
2. ROE（近12个月）大于8%（港股基准略低）
3. 距52周最高价回撤幅度超过20%
4. 总市值大于30亿港元
5. 排除以下行业：半导体、消费电子、互联网科技、软件
返回字段：股票代码、名称、所属行业、PE（TTM）、PB、ROE、股息率、52周最高价、当前价格、回撤幅度、总市值
```

### 输出
合并 A 股 + 港股通结果，去重，输出 L1 候选列表（预计 100-300 只）。

---

## L2：防价值陷阱过滤

### API
`POST https://ai-saas.eastmoney.com/proxy/b/mcp/tool/searchData`（批量财务趋势查询）

### 对 L1 每只股票拉取的指标
- 近 4 个季度营收同比增速（yoy）
- 近 4 个季度净利润同比增速（yoy）
- 近 3 年 ROE 逐年值
- 近 12 个月经营活动产生的现金流量净额
- 商誉 / 净资产比（最新财报）

### 淘汰规则（命中任意一条 → 剔除）

| 规则编号 | 条件 | 防范风险 |
|----------|------|----------|
| T1 | 近 3 个季度营收同比增速均为负 | 业务持续萎缩 |
| T2 | 近 2 年净利润同比增速均为负（排除明确的一次性减值） | 主业恶化 |
| T3 | ROE 连续 3 年下行且当期 < 8% | 质量实际差于表面 |
| T4 | 近 12M 累计经营现金流为负 | 利润无现金支撑 |
| T5 | 商誉 / 净资产 > 40% | 潜在减值雷 |

### 输出
过滤后候选列表（预计 40-60 只）。

---

## L3：三维评分与诊断

### 评分模型

对每只候选股计算综合得分（满分 10 分）：

| 维度 | 权重 | 计算方式 |
|------|------|----------|
| 估值便宜度 | 40% | `(30% - PE分位) / 30% × 10`，PE分位越低得分越高；同时参考 PB 和股息率修正 |
| 质量分 | 35% | ROE 绝对值（25%）+ 经营现金流 / 净利润比（10%） |
| 错杀深度 | 25% | 个股回撤 - 同申万行业平均回撤（个股比行业多跌的部分 = 更多的错杀溢价） |

综合得分 = 估值得分 × 0.4 + 质量得分 × 0.35 + 错杀得分 × 0.25

### A 股 Top 20 单票诊断

对综合得分排名前 20 的 A 股候选，逐一调用：
`POST https://ai-saas.eastmoney.com/proxy/app-robo-advisor-api/assistant/stock-analysis`

问句模板: `"请综合分析 {股票名称}（{代码}）当前的投资价值，重点关注基本面质量、估值水平和主要风险"`

提取 `data.displayData` 作为诊断摘要（截取前 500 字）。

港股不调用诊断接口（该接口仅支持 A 股）。

### 最终输出格式

```markdown
# 错杀好股扫描结果 — {日期}

## 汇总

- L1 初筛：{N} 只

- 最终候选：{N} 只

## Top 候选清单（按综合得分排序）

| 排名 | 代码 | 名称 | 市场 | 行业 | 综合分 | PE分位 | ROE | 回撤 | 股息率 |
|------|------|------|------|------|--------|--------|-----|------|--------|
| 1 | ... | ... | ... | ... | ... | ... | ... | ... | ... |

## A 股 Top 20 单票诊断摘要

### 1. {名称}（{代码}）
综合得分：{X.X}

{诊断摘要前 500 字}
```

### 触发条件（SKILL.md 中定义）
- 用户说"帮我跑错杀扫描"/"找被错杀的好公司"/"扫描一下低估值好公司"
- 用户明确提到"扫描非科技价值股"/"找 A 股港股通低估高质量标的"

### 输出目录
`miaoxiang/value_mispricing_scanner/scan_{YYYYMMDD}.md`

## 关键约束

- `EM_API_KEY` 从环境变量读取，与现有 skill 相同
- L1 A股和港股通分两次调用 selectSecurity，结果合并
- L2 批量查询：每批最多 5 只（复用 mx-finance-data 的批量限制经验）
- L3 诊断串行调用，每次请求间隔 1 秒避免限频
- 港股无诊断（stock-analysis 仅支持 A 股）
- 全流程预估耗时：5-15 分钟（取决于 L1 结果数量）

---

## 不在范围内

- 可比公司横向估值（comparable-company-analysis）：L3 已有行业中性的错杀得分，暂不引入，避免过度复杂
- 自动触发龟龟深度报告：人工复筛后手动触发 initiation-of-coverage-or-deep-dive
- 历史回测：当前版本只做实时扫描，不做历史验证
