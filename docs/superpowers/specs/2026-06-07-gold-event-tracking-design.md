- **日期**：2026-06-07
- **作者**：huxu（与 Claude 协作设计）
- **存放位置**：思源笔记 `/投资研究/03_宏观与行业/策略研究/黄金/`
- **状态**：已确认，待实施

## 1. 背景与问题

黄金策略研究目前有两份核心笔记：

- **《分析所需数据清单-2026-06-06》**：黄金市场基本面的快照（央行储备、供需、宏观利率、地缘、价格技术面等七大类数据），是制定策略前的数据起点。
- **《黄金分档建仓计划-3到5年战略-2026-06-06》**：基于快照制定的执行计划，核心是「总开关 = 央行是否持续购金」+ 5 项跟踪指标清单 + 分档触发价表。

问题：新事件不断出现（如 2026-06-05 美国非农大超预期、加息预期变化、央行月度购金数据等），需要**系统化地**对照策略做检查——判断事件是否动到总开关、触发价或核心逻辑——并在笔记里留痕。目前只能手动把新事件零散补进数据清单，缺乏可重复、可追溯的结构。

## 2. 目标

- 建立一个**可重复执行**的「事件 → 检查 → 留痕 → 必要时改策略」闭环。
- 新事件与新数据有明确、唯一的存放位置。
- 任何时点都能「一眼看当前状态」（总开关是否还在、各指标偏多/偏空）。
- 结构可复制到其他策略主题（原油、美债等）。

## 3. 非目标（YAGNI）

- 不为每个事件单独建文档（除非将来个别事件需深挖，再拆分并反向链接）。
- 不自动抓取数据 / 不做自动化告警，事件录入为人工（或会话中协助）。
- 不改动除建仓计划外的其他历史分析笔记。

## 4. 文档角色定位

| 文档 | 角色 | 维护状态 |
|---|---|---|
| 分析所需数据清单-2026-06-06 | **历史基线快照**（分析起点） | ❄️ 冻结，不再维护 |
| 黄金分档建仓计划-3到5年战略 | **执行策略**（触发价/总开关/纪律） | 🔄 活文档，仅事件触动时才改 |
| **黄金事件跟踪日志**（新建） | **当前状态事实源 + 事件检查留痕** | ✍️ 持续滚动追加 |

逻辑闭环：**新事件 → 进日志做对照检查 → 判断是否动策略 → 必要时改建仓计划**。日志是入口，建仓计划是出口；数据清单退居为冻结基线。

## 6. 事件日志内部结构

### 6.1 顶部：核心指标最新状态表（固定置顶）

数据清单冻结后，此表接替它承担「当前快照」职责，随事件随手更新。

| 指标 | 最新值 | 状态 | 更新日期 |
|---|---|---|---|
| 总开关·央行月度购金 | 4月+8.09吨，连增18月 | ✅ 地板成立 | 06-06 |
| 10Y TIPS 实际利率 | 2.09% | ⚠️ 距2.5%警戒 | 06-04 |
| 美联储路径 | 转鹰·加息提前 | 🔴 偏空 | 06-05 |
| 美元指数 DXY | 99.6–100 | ⚠️ 反弹 | 06-05 |
| ETF / COMEX 投机净多头 | — | — | — |

状态标记约定：✅ 支撑多头 / ⚠️ 需关注 / 🔴 偏空。指标项与建仓计划「八、跟踪指标清单」严格对齐。

### 6.2 下方：倒序事件条目（最新在上）

每条用固定模板，即「一次检查」的标准产出，含 5 个字段：

```markdown
## 2026-06-05 │ 非农大超预期 │ 结论：⚠️偏空·不动总开关

**事件**：美国非农就业大超预期，首次加息提前至 2026 年底，10 月成可能节点，降息预期彻底消失。

**对照跟踪指标逐项检查**：
- 总开关(央行购金)：4月+8.09吨，仍增持 → ✅ 不变
- TIPS：2.09%，未破 2.5% → ⚠️
- 美联储路径：转鹰 → 🔴 偏空
- DXY：反弹至 99.6 → ⚠️

**结论/操作**：维持原计划，总开关未动；短期偏空，等 Z1($4,150) 再分批。
**是否触动策略**：否（仅更新建仓计划「市场判断」段）
**来源**：CME FedWatch / 东方财富
```

固定字段：**事件 / 对照跟踪指标逐项检查 / 结论操作 / 是否触动策略 / 来源**。

## 7. 关键设计原则

1. **总开关优先**：每次检查第一项永远先看央行购金，与建仓计划「总开关」逻辑严格对齐。
2. **检查 ≠ 改策略**：绝大多数事件只记录 + 偏多偏空打标；只有动到总开关或触发价时才改建仓计划，并在条目「是否触动策略」中写明。
3. **倒序追加**：最新事件置顶，顶部状态表同步更新。
4. **可复制**：其他策略主题（原油、美债等）可直接克隆「基线快照 + 策略 + 事件日志」三件套。
