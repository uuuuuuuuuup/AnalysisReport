- 笔记层级清晰，命名规范，便于在思源笔记中检索和浏览。

## 4. 单篇笔记内容模板

每篇主题笔记统一采用以下结构：

```markdown
# {主题名称}

## 1. 核心要点

用 3–5 条概括本主题的核心结论，语言精炼。

## 2. 原文摘录

从 txt 原文中摘录与本主题相关的关键段落，按子主题分组。
每条摘录前标注原书章节位置。

> 原文摘录示例（第 X 章）：
> “……”

## 3. 我的划线与批注

将原始笔记中的相关划线与批注按子主题迁移至此。
每条包含：
- 划线原文（可选）
- 用户批注（💬）
- 若批注涉及中国市场延伸，保留其内容

## 4. 实践启示

基于本主题内容，提炼可落地的行动清单或思考清单。
例如：
- [ ] 检查自己的资产配置是否符合防御型投资者原则
- [ ] 识别持仓中是否存在“高 PE 成长股”过度集中风险
```

## 5. 内容迁移规则

### 5.1 从原笔记迁移

1. **去重**：同一章节中完全重复的划线/批注只保留一次。
2. **归类**：按主题而非章节重新组织批注。
3. **补全上下文**：对仅保留批注句子的条目，从 txt 原文补回前后文。
4. **保留个人风格**：用户的口语化表达、中国市场对照、自问我答等全部保留。

### 5.2 从 txt 原文摘录

1. 仅摘录与主题直接相关、且能支撑批注理解的段落。
2. 优先摘录被用户划线或批注引用的原文。
3. 控制单篇原文摘录长度，避免变成原文搬运。

4. **质量检查**
   - 检查是否遗漏重要批注。
   - 检查原文摘录与批注是否对应。
   - 检查命名、层级、格式一致性。

5. **写入思源笔记**
   - 在 `/02_知识库/投资经典/读书笔记/聪明的投资者读书笔记/` 下创建文档。
