# 稳健投资策略分析报告 - 展示网站设计文档

**日期**: 2026-07-11
**版本**: v1.0

---

## 一、项目概述

为 `稳健投资策略分析报告/` 目录中的 200+ 份股票分析报告构建一个展示网站。既是个人投资研究工具（浏览、筛选、追踪标的），也是对外展示投资研究框架的平台。

---

## 二、设计方向

**杂志式投资研究报告风格** — 明亮底色 + 经典商务感，类似 Bloomberg/财经刊物的研究报告页面。

### 色调

- 背景: 米白/暖灰色调
- 文字: 深色（深灰/近黑）
- 强调色: 克制使用的深蓝或墨绿
- 评级标签: 绿色(建仓)、琥珀(观察)、红色(不建议)

### 字体

- 标题: 几何感现代展示字体（参考 kilo.ai 风格）
- 正文: 舒适易读的无衬线字体
- 数据/表格: 等宽或清晰数字字体

### 排版

- 大段呼吸空间，杂志式留白
- 表格清晰的行分隔线，hover 高亮行
- 报告内页以可读性为优先的排版

- 传统分页（每页 25 条）
- 行 hover 高亮，点击进入详情

## 四、技术架构

| 层 | 选型 |
|:---|:---|
| 框架 | Vue 3 + Vite |
| 样式 | Tailwind CSS v4 |
| 路由 | Vue Router（首页 + 详情 + 汇总 三个路由） |
| Markdown 渲染 | marked |
| 部署 | GitHub Actions → 构建 → GitHub Pages |

### 数据流

```
报告目录 (Markdown + index.json)
        ↓ 构建时扫描脚本 (scripts/build-data.js)
静态 JSON 数据 (public/data/stocks.json)
        ↓ 前端运行时 fetch
Vue 页面 (表格 / 详情 / 汇总)
```

### 评级分类逻辑

从每份报告第一行 `> **结论描述**` 中提取结论文本，匹配关键词：

| 评级 | 关键词 |
|:---|:---|
| 建仓 | 可建底仓、可买入、可适度配置、建议配置、高优先级观察、中等仓位 |
| 观察 | 中优先级观察、低优先级观察、观察、建议观察、谨慎观察 |
| 不建议 | 不建议买入、否决、不建议投资、不建仓、低配 |

未匹配到任何关键词的归入"待分类"。

### 行业提取

从报告的「商业质量速写」表格或报告元数据中提取。

### 汇总页面数据

`汇总/` 目录下的 `.md` 文件直接使用，构建时拷贝为静态数据。

### GitHub Actions

```yaml
# .github/workflows/deploy.yml
on:
  push:
    branches: [master]
jobs:
  build-and-deploy:
    steps:
      - uses: actions/checkout
      - run: npm ci && npm run build-data && npm run build
      - deploy to gh-pages
```
