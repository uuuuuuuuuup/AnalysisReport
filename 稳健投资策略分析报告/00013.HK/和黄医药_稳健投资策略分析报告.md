## 决策理由

1. **零分配意愿（一票否决级）**：和黄医药自2021年上市以来从未派发股息，从未进行股份回购。支付率锚定值=0%，穿透回报率计算结果为0%，远低于5%门槛值。公司明确表示将现金用于研发投入和潜在并购，无任何资本返还计划。

2. **经营现金流持续为负**：2025年OCF为−6,470万美元，2024年仅+50万美元，2021-2022年均为大额负值。主营业务"造血功能"严重不足，核心业务盈利（剔除非经常性损益后约4,110万美元）无法覆盖运营支出。

3. **2025年利润严重失真**：GAAP归母净利润4.569亿美元中，4.158亿美元（91%）来自出售上海和黄药业45%股权的一次性收益。核心经营利润仅约4,110万美元，对应PE约52倍，远非"低估值"。

4. **框架边界冲突**：和黄医药本质上仍处于"成长投入期"而非"价值回报期"，属于稳健投资策略框架明确标注的"不适用"范畴——核心业务尚未实现可持续盈利和正向自由现金流。

5. **现金虽多但"被困"**：广义净现金12.74亿美元占市值59.3%，看似安全垫极厚，但公司无分配意愿，现金被锁定在研发和战略投资中，股东无法通过股息或回购获得回报，形成"现金陷阱"。

---

## 风险提示

1. **价值陷阱风险**：低PE（4.88倍TTM）和高净现金/市值比（59.3%）看似便宜，但零分配+负OCF意味着股东无法获得任何现金回报，典型的"看起来便宜但无法兑现价值"的陷阱。

2. **核心产品收入下滑**：2025年国内肿瘤产品收入同比下降21%，索凡替尼（−45%）、赛沃替尼（−36%）大幅下滑，仅呋喹替尼海外销售（+26%）支撑增长，但海外收入依赖武田单一合作伙伴。

3. **研发投入风险**：ATTC平台尚处早期临床阶段，3款候选药物均未读出临床数据，存在较大失败风险。若ATTC平台未能兑现预期，公司估值将面临大幅下修。

4. **地缘政治风险**：美国众议院曾有提案要求FDA拒绝考虑中国生成的临床数据，虽通过概率低，但若落地将严重影响公司全球化战略。

## 关键发现

1. 和黄医药2025年GAAP净利润4.569亿美元中91%来自一次性资产出售收益，核心经营利润仅约4,110万美元，PE(TTM) 4.88倍严重误导。

2. 公司持有12.74亿美元广义净现金（占市值59.3%），但零分配政策使这笔现金对股东而言形同"被困资产"。

3. 经营活动现金流连续两年为负或近零（2024年+50万美元，2025年−6,470万美元），主营业务无法自我造血。

4. 2026年管理层指引肿瘤/免疫业务综合收入3.3-4.5亿美元，暗示收入有望恢复增长，但能否转化为可持续利润和现金流仍是未知数。

5. ATTC平台是全球首创的抗体靶向偶联药物技术，已有2款候选药物进入临床，若成功可能成为长期增长引擎，但距离商业化仍有3-5年。

**粗算公式**：

`粗算穿透回报率 = [Owner_Earnings × 支付率锚定值 × (1−股息税率) + 年均回购] / 当前市值`

= [47.7 × 0% × 0.8 + 0] / 2,147

= **0.00%**

**EV口径双轨制检查**（广义净现金/市值 = 59.3% > 40%，触发EV口径）：

EV = 市值 − 广义净现金 = 2,147 − 1,274.1 = 872.9 百万美元

EV口径粗算回报率 = [47.7 × 0% × 0.8 + 0] / 872.9 = **0.00%**

> 即使假设未来支付率提升至30%（纯假设，无历史依据）：
> - 市值口径：R = [47.7 × 30% × 0.8 + 0] / 2,147 = 11.45 / 2,147 = **0.53%**
> - EV口径：R = 11.45 / 872.9 = **1.31%**
>
> 仍远低于门槛值5%。

- 分配能力验证：OCF −64.7M < Owner Earnings 47.7M ❌（OCF为负，无法支撑任何分配）
- 分配意愿：**零** — 公司从未派息、从未回购，明确表示现金用于研发和战略投资
- 税务泄漏：股息税率 = 20%（当前无实际影响）
