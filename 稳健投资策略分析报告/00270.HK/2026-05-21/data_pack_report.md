## 四、MD&A 深度信息

> **数据来源**：公司2025年度业绩回顾PPT、2025年度业绩公告MD&A部分、东吴证券研报、全联环境商会分析、格隆汇分析

### 4.1 经营回顾

**整体业绩**：
- 2025年持续经营业务收入188.25亿港元，同比+1.7%
- 毛利100.34亿港元，同比+2.2%，毛利率53.3%（2024年：53.1%）
- 持续经营业务税前利润72.41亿港元，同比+11.5%
- 归母净利润46.56亿港元，同比+48.2%

**分部业绩**（持续经营业务）：

| 分部 | 收入（亿港元） | 同比 | 税前利润（亿港元） | 同比 |
|------|---------------|------|-------------------|------|
| 水资源 | 约132.88 | +4.7% | 约59.52 | +3.4% |
| 物业投资及百货营运 | 约21.76 | +6.7% | 约10.68 | +5.6% |
| 基建（道路及桥梁+发电） | 约21.35 | -4.3% | 约4.34 | -3.9% |
| 酒店经营及管理 | 7.05 | +8.7% | 0.99 | -10.8% |

**水资源板块详情**：
- 东深供水项目：收入64.52亿港元（+1.4%），税前利润41.58亿港元（+3.4%），供水量20.78亿吨（-1.8%）
- 对港供水收入52.59亿港元，续创新高（+2.4%）
- 其他水资源项目：收入77.36亿港元（+7.2%），税前利润17.94亿港元（+3.5%）
- 截至2025年末，供水产能1,659.52万吨/日，污水处理产能309.49万吨/日
- 运营项目61个，在建项目4个，新增供水产能91.5万吨/日

**香港供水协议（2024-2026年）**：
- 每年供水量封顶8.2亿吨
- 2025年封顶水价收入：51.8~52.6亿港元
- 2026年封顶水价收入：53.2~53.9亿港元
- 2025年单位水价：0.323港元/吨
- 2026年单位水价：0.331港元/吨

### 4.2 前瞻指引

- 公司战略聚焦"归核化"与"精益管理"，持续剥离非核心资产
- 2025年10月28日公告收购阳江粤海环保51%股权（对价人民币1.56亿元）及汕头粤海水务2%股权（对价人民币7,088万元），从控股股东粤海控股旗下收购
- 2026年Q1收入50.46亿港元（+9.3%），税前利润21.56亿港元（+5.9%），开局良好
- 东深供水特许经营权至2030年到期，预计可续期

### 4.3 资本配置意图

- 维持65%派息比率，每股股息46.29港仙（+48.2%）
- 净金融负债减少41.7%至68.3亿港元，资本负债率降至19.7%
- 公司财务结构空前稳健，为未来逆周期并购提供充足"弹药"
- 2025年资本开支54.34亿港元（+192.62%），主要系项目收购带来的阶段性资本支出增长
- 自由现金流33.71亿港元（-63.47%），剔除粤海置地后经营性现金流净额85.37亿港元（-6.70%）

### 4.4 风险因素

1. **增长天花板**：水务业务虽稳定，但受制于区域供水协议，外延扩张空间有限
2. **汇率波动**：业务横跨香港与内地，年内录得汇兑差异净亏损0.40亿港元，需关注人民币汇率波动对港币计价报表的影响
3. **现金流背离**：经营性净现金流88.05亿港元，同比下降20.6%，创三年新低；水资源等板块营运资金大幅增加（+23.6亿），可能反映账期恶化或项目前期投入
4. **应收账款膨胀**：应收账款及预付款项增至65.38亿，同比增长17.2%，远超1.7%的收入增速
5. **投资物业公允价值变动**：2025年投资物业公允价值变动-2.63亿港元（2024年：-6.78亿港元），虽亏损收窄但仍为负值
6. **东深供水特许经营权到期风险**：2030年到期，存在续期不确定性

### 10.3 数据一致性校验

| 校验项 | 校验结果 |
|--------|----------|
| 总资产 = 总负债 + 非控股权益 + 归母权益 | 101,741 ≈ 58,817 - 15,215 + 42,924 = 86,526（差异因总负债含非控股权益口径） |
| 归母净利润 x 派息比率 ≈ 全年股息总额 | 4,656 x 65% ≈ 3,026；全年股息46.29仙 x 65.38亿股 ≈ 3,026 ✅ |
| 收入 - 销售成本 = 毛利 | 18,825 - 8,791 = 10,034 ✅ |
| 持续经营利润 + 终止经营亏损 = 年度利润 | 5,266 - 21 = 5,245 ✅ |

### 10.4 关键发现与风险提示

1. **资产质量显著提升**：剥离粤海置地后，总资产下降25%但净资产基本持平，"虚胖"资产出表
2. **财务结构空前稳健**：资本负债率从30.9%骤降至19.7%，净金融负债减少41.7%
3. **现金流背离需警惕**：经营性净现金流88.05亿港元，同比下降20.6%，与利润增长方向相反
4. **应收账款膨胀**：同比增长17.2%，远超收入增速1.7%，回款风险上升
5. **水务内生增长温和**：核心水务业务税前利润增幅仅3.4%，增长天花板明显
6. **分红政策稳定**：长期维持65%派息比率，以经营现金流而非债务融资支撑分红
