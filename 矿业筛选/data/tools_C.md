## 一、year参数行为探测结论（关键前置）

对601899（紫金矿业）测试 year=2021 / year=2022 / year=2025 三组：

| 测试 | 返回报告期 |
|---|---|
| indicator year=2021 | 2026-06-30、2026-03-31、2025-12-31、2024-12-31、2023-12-31、2022-12-31（6期） |
| indicator year=2022 | 与2021完全相同（6期） |
| indicator year=2025 | 仅3期（2026-06-30起） |
| cash_flow year=2021 / 2020 | 601899均4期（2024FY~2026H1）；600489/600547等7期（2021FY~2026H1） |
| balance 同上 | 与cash_flow一致 |
| income year=2021 | 7期（2021FY~2026H1），**唯一能取到2021FY营收/净利的类型** |

结论：
1. **year 是起始年份下限过滤**，数据源只保存最近N期，更早历史无法取回。
2. 各类型窗口深度：indicator=最近6期（2022FY~2026H1含Q1）；income=7期（含2021FY）；cash_flow/balance=4~7期不等（**公司级差异**：601899仅4期，多数7期）。
3. 数据源报告期覆盖为"各年报+最新Q1+最新H1"，**任何类型均无2025-06-30（2025H1）**。
4. indicator_batch 只返回最新一期且大量列空，不适用本任务，弃用。

## 二、采集口径与TTM处理

- 每家4类调用：indicator + income + cash_flow + balance（income用于补2021年营收/净利及个别缺失的2026H1营收/净利，如000426、601212）。
- **TTM全部不可得**（rev_ttm/np_ttm/np_deduct_ttm/ocf_ttm/ocf_np_ratio 置null）：2025H1在任何窗口均不存在，按纪律禁止用H1×2近似。
- 金额换算：元→亿元（÷1e8），脚本自动处理；占位0（000792 income 2021）视为null。
- ocf_neg_years：统计2021-2025五个**可得**年度中OCF为负的年数；601899（OCF仅2024-2025可得）与601123（2022年上市，OCF自2022起）不足5期，已在备注列注明。
- 2025扣非占比（deduct_ratio_2025）= 扣非/归母，归母<=0或缺失置null（601212、002240、000762、601123四家）。
