# 投资账本 · 金融终端看板

基于同花顺投资账本 API 的暗色模式金融数据看板，纯 JS 实现（Node.js + 原生 HTML/CSS/JS），零第三方依赖（图表库 ECharts 5.5 走 CDN）。

## 快速开始

```bash
node server.js
# 自动打开浏览器 → http://localhost:8888
```

**前置条件：**
- Node.js ≥ 18（仅用内置模块，无需 npm install）
- `~/.tzzb_cookies` 文件：浏览器登录同花顺投资账本后，从开发者工具复制 Cookie 存入

**响应式断点：**

### 特殊模式

| 模式 | 触发方式 | 效果 |
|------|----------|------|
| 隐私模式 | 顶栏 👁 按钮 | 所有金额/涨跌幅数字 CSS `filter: blur(5px)` 模糊化 |

## 已实现功能

### 卡片 1：资产总览（PORTFOLIO · 资产总览）

**功能：** 账户概览 + 净值走势合并卡，2×2 区域。

- **账户芯片**：每账户一行，显示总资产、累计盈亏、当月盈亏（红绿灯）、仓位进度条（>90% 红 / >60% 橙 / 其余绿）、可用资金。
- **净值走势图**：面积图，Tab 切换「全部合计 / 宁静致远 / 淡泊明志」。大字号显示当前市值，含今日盈亏、区间范围。
- **数据来源**：`account_list` + `stock_position` + `asset_trend`（`year_profit`），首次加载自动获取。
- **空账户过滤**：自动过滤「空空如也」空账户，所有卡片同步隐藏。

### 卡片 2：K线行情（CANDLESTICK · K线行情）

**功能：** 收盘价折线 / K线蜡烛图切换，2×2 区域。

- **模式切换**：「折线 / K线」按钮一键切换图表类型。
- **折线模式**：收盘价面积图 + MA5/MA10/MA20 均线（使用腾讯前复权 120 日数据）。
- **K线模式**：标准 OHLC 蜡烛图（红涨绿跌）+ 成交量柱状图 + MA5/MA10/MA20 + dataZoom 缩放条。
- **标的切换**：下拉选择器按账户分组列出全部持仓，切换即刷新。
- **数据来源**：腾讯 `web.ifzq.gtimg.cn/appstock/app/fqkline/get`（前复权日K，经 `/proxy/kline` 代理），首次加载后缓存。
- **代码映射**：6/5/9 → sh（沪市），0/2/3 → sz（深市），4/8 → bj（北交所）。

### 卡片 3：每日盈亏（P&L CALENDAR · 每日盈亏）

**功能：** GitHub 贡献图风格日历热力图，2 列宽。

- **热力图**：每个交易日一格，按日收益率分档着色（红 = 正收益多档深度，绿 = 负收益多档深度，灰 = 零）。
- **Tab 切换**：「全部合计 / 宁静致远 / 淡泊明志」。
- **统计信息**：区间盈亏总额 + 区间收益率 + 交易日计数。
- **数据来源**：`asset_trend` 的 `year_profit`（累计盈亏逐日差分得当日盈亏，日收益率 = 当日盈亏 / 前一日资产）。
- **自适应**：格子大小根据容器宽高动态计算，始终保持正方形。

### 卡片 4：股票列表（STOCKS · 股票列表）

**功能：** 持仓明细 + 自选行情双 Tab 卡，2 列 × 3 行。

**Tab 1 - 持仓明细：**
- 8 列表格：名称 / 代码 / 持仓 / 成本 / 现价 / 市值 / 盈亏 / 盈亏%
- 按市值降序排列，卡片内滚动。
- 跟随全局视图切换过滤对应账户。

**Tab 2 - 自选行情：**
- 头部：↑N ↓M 涨跌计数 + 红绿分布条 + 平均涨跌幅大数字。
- 列表：名称 / 现价 / 涨跌幅（红涨绿跌），Top 40 显示，卡片内滚动。
- 排序切换：涨跌幅↓（默认）/ 自选顺序 / 代码。
- **数据来源**：`sort_list`（213 只自选）+ `rise_fall`（涨跌分布统计）。

### 卡片 5：资金流向（MONEY FLOW · 资金流向）

**功能：** 全市场主力净流入/流出 treemap 热力图，2×2 区域。

- **Treemap 布局**：流入（红色系）/ 流出（绿色系）各 Top 10，块面积 = 主力净流入额的绝对值，金额越大颜色越深。
- **过滤 ETF**：自动过滤 sh51/58、sz15 开头的 ETF/货币基金。
- **悬浮 Tooltip**：显示名称、代码、现价、涨跌幅、主力净流入额。
- **数据来源**：新浪 `vip.stock.finance.sina.com.cn/.../MoneyFlow.ssl_bkzj_ssggzj`（经 `/proxy/moneyflow` 代理），流入/流出各一次请求。

### 卡片 6：持仓权重（HOLDINGS · 持仓权重）

**功能：** 横向柱形图，2 列 × 3 行。

- 按市值从左到右展开（小 → 大），红涨绿跌着色，右侧标注涨跌幅百分比。
- dataZoom 纵向滚动（当标的超过 20 只时自动启用）。
- 跟随全局视图切换过滤对应账户。
- **数据来源**：`stock_position`（实时持仓）。

### 卡片 7：资金流水（CASH FLOW · 资金流水）

**功能：** 近 30 天交易/资金流水列表，1 列宽。

- **Tab 切换**：按账户切换，默认显示第一个账户。
- **表格列**：日期 / 名称 / 操作 / 数量 / 金额 / 备注。
- **操作徽章**：交易类（买入/卖出）橙色 `#f97316`，资金类（入账/转出）蓝色 `#448aff`。
- **加载更多**：按钮在表格底部，`page+1` 追加；到达最后一页后按钮隐藏。
- **数据来源**：`get_money_history`（分页 20 条/页，3 账户各拉第 1 页并行加载）。

| 功能 | 说明 |
|------|------|

## 服务端（server.js）

| 路由 | 用途 |
|------|------|
| `/` | 看板页面（index.html） |
| `/api/*` | 同花顺 API 反向代理（自动附加 Cookie，转发到 `tzzb.10jqka.com.cn`） |
| `/api-check` | Cookie 存在性检查 + userid 提取 |
| `/proxy/kline?code=sh600519&count=120` | 腾讯前复权日 K 线代理（OHLC + 成交量，带防盗链 Referer） |
| `/proxy/moneyflow?order=desc\|asc&num=12` | 新浪个股资金流排行代理（带防盗链 Referer） |

## 数据源对照

| 接口 | 用途 |
|------|------|
| `POST /caishen_fund/pc/account/v1/account_list` | 账户列表 |
| `POST /caishen_fund/pc/asset/v1/stock_position` | 实时持仓（含现价、成本、盈亏） |
| `POST /caishen_fund/pc/asset/v1/asset_trend` | 历史资产净值（`year_profit`：累计盈亏 + 每日资产，用于净值走势和每日盈亏日历） |
| `POST /caishen_fund/pc/account/v2/get_money_history` | 资金流水（近 30 天，分页 20 条/页） |
| `POST /caishen_fund/pc/optional/v1/sort_list` | 自选列表（现价/涨跌额/涨跌幅/加入时间） |
| `POST /caishen_fund/pc/optional/v1/rise_fall` | 自选涨跌分布（stock_rise / stock_fall / avg_rate） |
| `GET 腾讯 web.ifzq.gtimg.cn/appstock/app/fqkline/get` | 前复权日 K 线（OHLC + 成交量，经 `/proxy/kline` 代理） |
| `GET 新浪 vip.stock.finance.sina.com.cn/.../MoneyFlow.ssl_bkzj_ssggzj` | 个股资金流排行（主力净流入 r0_net，经 `/proxy/moneyflow` 代理） |

## 已知限制

1. **K线数据来源**：通过腾讯财经接口获取前复权日K（OHLC + 成交量），非同花顺 API。同花顺投资账本 `getQuotes` 仅提供按日收盘价，无 OHLC 数据。
2. **K线首次加载较慢**：首次查询某标的需拉取 120 日数据，前端有缓存，二次查询秒出。
3. **资产走势含资金进出影响**：`asset_trend` 返回的净值含资金流入流出影响，非纯投资收益曲线。
4. **每日盈亏为累计差分**：`year_profit` 的 profit 是「截至当日的历史累计盈亏」，需逐日差分才能得到当日盈亏。
5. **清仓统计接口不可用**：该账户类型不支持 `cleared_position`（所有参数组合返回 HTTP 400）。
6. **自选只读**：看板不提供加删自选功能。
7. **Cookie 过期**：Cookie 失效后需重新从浏览器复制到 `~/.tzzb_cookies`。
8. **外部数据依赖**：资金流向依赖新浪接口，K线依赖腾讯接口，外部服务不可用时对应卡片显示错误占位。

## 技术架构

```
浏览器 (index.html)
  │
  ├── ECharts 5.5 (CDN) ── 全部图表渲染
  │
  └── fetch() ──► Node.js server.js (:8888)
                    │
                    ├── /api/*  ──► 同花顺 API (tzzb.10jqka.com.cn)
                    ├── /proxy/kline ──► 腾讯 K线 (web.ifzq.gtimg.cn)
                    └── /proxy/moneyflow ──► 新浪资金流 (vip.stock.finance.sina.com.cn)
```

- **前端**：原生 HTML/CSS/JS 单文件，无框架，无构建工具。
- **后端**：Node.js 内置 `http`/`https` 模块，零 `npm install`。
- **数据流**：`loadAllData()` → 并行拉取账户列表 + 持仓 + 趋势 → `renderAll()` 分发到各卡片初始化。
- **缓存策略**：K线 OHLC 数据内存缓存（`klineOHLCCache`），资金流水分页缓存（`cashRows`），资产趋势存 `store.trends`。
