## 1. 背景与目标

现有看板 7 个 UI 组件、使用 4 个数据端点（README.md「已实现功能」）。本期新增 3 张卡片：

1. **月度收益** — 每账户 12 个月盈亏柱状图
2. **资金流水** — 近 30 天交易/资金流水列表
3. **自选行情** — 213 只自选股涨跌分布 + 行情列表

**关键结论（已验证，2026-08-13 实测）：**

- `merge_compare` / `get_money_history` / `sort_list` / `rise_fall` 四个接口对当前账户类型可用，全部走查询参数 POST，可经 server.js 现有 `/api/*` 通用代理透传 → **server.js 零改动**，本期为纯前端工作（index.html）。
- `cleared_position`（清仓统计）**放弃**：所有参数组合 HTTP 400，且用户在同花顺页面找不到「已清仓」入口，该账户类型不支持。
- `win_compare` 胜率数据基本全 0，**不展示**。
- `stock_quotes` 不采用：sort_list 已自带 213 只的现价/涨跌额/涨跌幅，够用（省一次请求）。

## 3. 组件规格

### 3.1 月度收益卡 MONTHLY P&L // 月度收益（col-2）

- **数据**：`merge_compare`，3 个账户各调一次，取 `ex_data.profit_compare`（`{month: "2026-04", profit, win_rate}[]`，12 个月）。
- **Tab**：`总合计 | 宁静致远 | 淡泊明志 | 空空如也`。总合计 = 三账户同月 profit 客户端求和（profit 为收益额，不含资金进出，可加）。加载时 3 账户并行拉取，Tab 切换纯客户端，无新请求。
- **图表**：ECharts 柱状图。正值红 `#ef4444`、负值绿 `#22c55e`、profit=0 用灰色小柱（数据源无法区分「无持仓」与「零盈亏」，不误导）。
- x 轴 12 个月（`2025-09`～`2026-08`，显示为「9月」格式）；y 轴金额。
- tooltip：月份 + 精确金额（`¥-14,644.70` 千分位）。
- win_rate 不展示。

### 3.2 资金流水卡 CASH FLOW // 资金流水（col-2）

- **数据**：`get_money_history`，参数（实测可用组合，勿改）：

  ```
  manual_id="", fund_key=<账户>, rzrq_fund_key="", fundid="", custid="",
  user_id=<userid>, start_date/end_date=近30天(YYYYMMDD), query_list="",
  page, count=20, sort_type="1", sort_order="1", h5id=""
  ```

  ⚠️ 实测 `query_list:"[]"`、缺 sort 参数、fund_id 参数名（应为 fundid）都会导致 HTTP 400。
- **Tab**：3 个账户名（无「总合计」）。加载时 3 账户各拉第 1 页（并行、缓存），Tab 切换纯客户端；默认显示第一个账户。
- **表格列**：日期 | 名称(代码) | 操作 | 数量 | 金额 | 备注。操作列按 `op_name`（买入/卖出/入账/转出等）显示彩色徽章：交易类橙色、资金类蓝色。
- **接口返回顺序**已按时间倒序（实测 08-12 在前），直接渲染，不额外排序。
- **加载更多**：按钮在表格底部，`page+1` 追加；`page >= max_page` 后按钮隐藏。
- 隐私模式：金额列纳入 `body.privacy` 模糊范围。

### 3.3 自选行情卡 WATCHLIST // 自选行情（row-2 瘦长卡）

- **数据**：`sort_list`（一次，213 只自选，含 `code/name/price/rate/price_change/addTime/market`）+ `rise_fall`（一次）。
- **rise_fall 参数格式（已从 bundle 验证，与 stock_quotes 相反）**：`stock_code` 用 `market:code` 逗号拼接全部 213 只；`fund_code=""`。返回 `{avg_rate, stock_rise, stock_fall}`。
- **头部**：`↑N ↓M` 计数 + 红绿分布条（rise 占比红、fall 占比绿）+ `avg_rate` 大数字（正红负绿，百分比 2 位小数）。
- **列表**：名称 | 现价 | 涨跌幅（红涨绿跌），213 行，卡片内滚动。
- **排序切换**（头部下拉）：涨跌幅↓（默认）/ 自选顺序（addTime 升序）/ 代码升序。纯前端排序。
- 只读，不提供加删自选。

## 4. 数据流与错误处理

- `loadAllData()` 完成后并行触发：月度收益（3× merge_compare）、资金流水（3× 第 1 页）、自选（sort_list + rise_fall）。共 8 个请求，互不阻塞。
- 任一请求失败：对应卡片内显示错误文案占位，不影响其他卡片。
- 复用现有 `apiFetch()` 辅助函数与 `/api/*` 代理，参数用 URLSearchParams 拼接。
