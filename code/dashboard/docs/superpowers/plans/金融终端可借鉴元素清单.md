## 1. 已实现（本次完成）

### 1.1 顶部指数滚动 Ticker
- **来源**：参考 demo 顶部橙色标题栏下方的指数跑马灯（DAX / XAU / WTI / DXY / SPX / IXIC / DJI / GSPTSE 等）。
- **已抄元素**：
  - 粘性定位（sticky top: 46px）。
  - 左侧固定标签「全球市场」+ 红色 live 点。
  - 右侧无限滚动指数条目：名称 + 价格 + 涨跌幅（红涨绿跌，中国市场习惯）。
  - 悬停暂停滚动。
  - 左右边缘渐变 mask。
- **实现位置**：`index.html` CSS `.ticker-wrap`、JS `renderTicker()`。
- **数据源**：`server.ts /proxy/global-indexes` → 腾讯财经 `proxy.finance.qq.com/ifzqgtimg/appstock/app/rank/indexRankDetail2`。
- **已知问题/待优化**：
  - 当前 Ticker 条滚动的是「全部全球指数 + 配置指数」，未按地区分 ticker 条。
  - 美股数据收盘后涨跌幅为负时显示绿色，与中国用户习惯一致；但 demo 使用红跌绿涨（美股习惯），可后续配置切换。

### 1.2 指数行情卡片

- **已抄元素**：

  - 每张卡片：名称 + 地区标签 + 大号价格 + 涨跌幅 + 状态（已收盘/交易中）。
  - 卡片悬停微上浮 + 边框高亮。
- **当前配置顺序**（按市场相邻）：
  - A股：上证指数、深证成指、创业板指、沪深300、科创板指
  - 港股：恒生指数、恒生科技
  - 美股：道琼斯、纳斯达克、标普500
- **实现位置**：`index.html` CSS `.index-grid` / `.index-card`、JS `GLOBAL_INDEX_CONFIG` / `renderIndexCards()`。
- **数据源**：
  - 腾讯全球指数接口（主要指数）。
  - 新浪行情 `hq.sinajs.cn`（补充创业板指/沪深300/科创板指/恒生科技，因腾讯接口不含这些）。
  - 后端接口：`/proxy/global-indexes` + `/proxy/stock-price`。

### 1.3 市场宽度（Market Breadth）
- **来源**：demo 首页右侧「02 市场宽度」。
- **已抄元素**：
  - 三列大数字：上涨数量（红）、下跌数量（绿）、平盘数量。
  - 涨跌比（上涨/下跌，下跌为 0 时显示 ∞）。
  - 涨跌幅中位数 + 平均涨跌幅。
  - 领涨、领跌个股各一只（名称 + 涨跌幅）。
  - 最活跃板块：行业资金排行净流入第一（板块名 + 主力净流入亿）。
  - 底部小字：统计仅描述当前自选 N 只样本，不代表全市场宽度。
- **实现位置**：`index.html` dashboard 网格第 8 行 `area-bdst` 卡片、CSS `.bdst-*`、JS `loadBreadth()` / `renderBreadth()`。
- **数据源**：
  - 同花顺自选 `sort_list` + `rise_fall`（涨跌统计、样本、中位数、领涨领跌，复用已有 watchlist 数据）。
  - 新浪行业资金排名 `MoneyFlow.ssl_bkzj_bk`（最活跃板块）。
- **已知问题/待优化**：
  - 领跌示例为「Ｒ-001」等逆回购品种（自选内利率品种），属正常样本内统计。
  - 涨跌比为样本内比例，与全市场宽度无关（已注明）。

## 4. 数据接口资产汇总（供后续实现直接复用）

已在 `server.ts` 中实现的代理：
- `/proxy/global-indexes`：腾讯全球指数（已清洗控制字符）。
- `/proxy/stock-price`：新浪个股/指数实时行情（A 股 + 港股，GBK 转 UTF-8）。
- `/proxy/kline`：腾讯 K 线（前复权日 K）。
- `/proxy/moneyflow`：新浪个股资金流排行。
- `/proxy/news`：新浪财经直播 feed（zhibo.sina.com.cn），剥 JSONP + 去 HTML/样式控制字符。（AI-Tools `MarketNewsTool` 同源）
- `/proxy/sector-money`：新浪行业资金排名（行业/概念），Windows Edge UA + Host/Referer 防盗链头，用于「最活跃板块」。（AI-Tools `MoneyFlowTool` 同源）
- 同花顺投资账本原有接口：账户、持仓、资产走势、自选、资金流水等。

AI-Tools 项目中已梳理但未在本项目实现的数据源：
- 新浪财经新闻
- 财联社电报（当前被 block）
- 上海黄金交易所 / COMEX 黄金 / SPDR ETF
- CFTC 持仓、宏观经济数据（GDP/CPI/PMI 等）
- 行业涨跌幅/资金流向（东方财富接口被 block）

## 5. 注意事项

1. **颜色习惯**：demo 使用美股红跌绿涨；当前 dashboard 使用 A 股红涨绿跌。后续若要支持美股视角，需增加颜色配置切换。
2. **性能**：当前 loadAllData 串行获取多个同花顺账户数据，loading overlay 全屏遮挡，导致指数区域虽已加载仍不可见。后续若继续增加模块，建议把 loading 改为局部遮罩，或先 render 指数/新闻等不依赖 cookie 的部分。
3. **移动端**：demo 明显是桌面端设计；当前 dashboard 已有基础响应式，但复杂模块（treemap、多列卡片）在小屏上需进一步适配。
4. **数据源稳定性**：腾讯全球指数接口返回中夹杂控制字符，已在 server 端清洗；新浪接口需正确 User-Agent/Referer 且不能对股票代码逗号做 URL 编码。
