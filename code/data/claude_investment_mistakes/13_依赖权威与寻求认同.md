# 事件13：依赖权威与寻求认同

> 所属类别：四、认知与实践的脱节
> 创建日期：2026-06-05
> ⚠️ 需用户补充：具体情境

---

## 当时发生了什么

（具体情境待补充）

在投资决策过程中，有一个反复出现的模式：把外部权威的判断当成了自己买入的核心理由，而不是通过自己的独立研究去验证这些判断。

这个"权威"在不同阶段换了不同的面孔：

1. **博主**：最早是听某位博主的逻辑（如"油价涨→粮食涨→买苏垦农发"），不验证就买
2. **AI工具**：后来转向AI推送的标的（永辉超市、华旺科技），看到推荐就买
3. **巴菲特角色扮演**：甚至和DeepSeek的这次对话，也可能成为新的"权威依赖"

## 错在哪里

寻求外部意见本身没有错——错了也不会。错的是：**不是在用外部意见来丰富自己的判断，而是在用外部意见来代替自己的判断。**

两者的区别：

| 独立思考 | 依赖权威 |
|---------|---------|
| "巴菲特的框架是怎么看的？让我也按这个框架自己算一遍。" | "AI说这家公司好，巴菲特也说好，那肯定没问题——买。" |
| 外部观点是研究的起点 | 外部观点是决策的终点 |
| 错了会反思自己的分析哪里出了漏洞 | 错了会怪博主/AI/"巴菲特" |
| 为自己的决策承担全部责任 | 内心深处在为自己找"背书"，以便亏了可以说"不是我的错" |

DeepSeek 总结得好：

> "独立思考是投资者最硬的护城河。没有任何人可以替你承担决策后果，你必须学会为自己负责。"

## 一个隐含的危险

我自己可能还没意识到的是——这次和DeepSeek的对话本身，也可能变成新的"权威依赖"。如果我听完之后只是说"巴菲特说得对，我照做"，而没有亲自去研究分众的护城河、海螺的周期位置、苏垦农发的商业模式……那我不过是换了一个更聪明的权威来依赖。

## 这条经验怎么用

- 任何外部建议——博主的、AI的、巴菲特的——都必须在自己做过独立研究之后才能执行
- 区分"我在学习一个框架"和"我在借别人的结论"。前者是自己走一遍推理，后者是直接相信终点
- 如果亏了钱，第一反应不该是"他推荐错了"，而应该是"我当时为什么同意？我漏了什么？"
- 为自己的每一个买卖决策负全责。没有人拿着枪逼你下单——是你自己点击的确认
