# 事件7：亏损焦虑驱动频繁操作

> 所属类别：二、交易纪律的执行
> 创建日期：2026-06-05

---

## 当时发生了什么

（具体时间和操作细节待补充）

当分众传媒等持仓出现持续下跌时，我没有耐心等待"击球点"的到来，而是出于一种本能的焦虑感，连续多日小额加仓——不是因为价格到了低估区间，而是因为看到账户浮亏，想做点什么来"补救"。

## 我当时怎么想的

根据后续复盘，典型的心理过程是：

1. 打开账户，看到分众又跌了
2. 心里不舒服，"不能干看着它跌"
3. 加一点仓，"摊低成本"
4. 第二天又跌，再加一点
5. 反复多次，仓位在不经意间累积变大

表面理由是"摊低成本"，真实驱动力是：**面对亏损的无力感驱动下的情绪发泄。** 做点什么——任何事——都比什么都不做感觉好。

## 错在哪里

**1. 混淆了"有计划加仓"和"情绪化加仓"。**

有计划加仓：价格进入击球区→按预定分档执行→买入多少心中有数→后续涨跌都有预案。

情绪化加仓：价格跌了→焦虑→买入一点缓解焦虑→没有目标仓位→不知道止跌还是继续跌→下次跌了继续焦虑，继续加。

"Doing something is not the same as doing the right thing."

**2. "摊低成本"是自我欺骗。**

在下跌中加仓确实能摊低平均成本，但前提是：你知道它为什么跌、你确信它的基本面没变、你有加仓的纪律和上限。

如果只是"因为它跌了所以我摊低成本"，那和赌徒输了加倍下注没有区别。

**3. 焦虑驱动下的操作，最大的代价不是那几笔可能错误的交易，而是它强化了一个错误的行为回路。**

每次焦虑→操作→焦虑暂时缓解，大脑就学会了"焦虑的时候应该操作"。这个回路一旦建立，将来在真正需要什么都不做的关键时刻，你会控制不住自己的手。

## DeepSeek 的观点

DeepSeek 在对话中反复强调"什么都不做"的价值：

> "真正的交易经验，不是练习怎么买入和卖出，而是练习怎么在什么都不做的时候，依然能保持理性。"

## 这条经验怎么用

- 为每只持仓提前设定明确的分档买入计划（如"股息率6%买X，7%买2X，8%买3X"），到了就执行，没到就不动
- 当发现自己查看账户频率增加、想要"做点什么"的时候，关闭交易软件——这是最高效的操作
- 区分"我在执行计划"和"我在发泄情绪"。前者有明确的触发条件和数量，后者只有模糊的不安感
