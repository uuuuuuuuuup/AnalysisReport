# 事件1：苏垦农发"逻辑外包"式投资

> 所属类别：一、不懂不碰的铁律
> 创建日期：2026-06-05

---

## 当时发生了什么

在某个时间点，我听信了某位博主"油价涨→粮食涨"的二手逻辑，认为粮食价格将上涨，于是买入了苏垦农发。

买入后，公司发布一季报，利润出现暴跌。因为我对这家公司的实际业务、盈利模式、核心风险一无所知——所有的买入理由都来自博主那里听来的几句二手逻辑——当季报利空出现时，第一反应是恐慌，随即割肉离场。

但故事没结束。后来我再次买入了苏垦农发。到2026年6月初与DeepSeek对话时，我的持仓显示：

| 项目 | 数值 |
|------|------|
| 持仓/可用 | 1700/1700 股 |
| 成本价 | 9.987 元 |
| 现价 | 9.960 元 |
| 市值 | 16,932.00 元 |
| 累计盈亏 | -45.43 元 (-0.270%) |

我把它归类为"高弹性组合"，理由是波段交易逻辑。

## 我当时怎么想的

在这次对话中，我把自己的投资逻辑完整讲了出来：

> "苏垦农发我也是奔着短期或者波段收益去的，逻辑是粮食安全问题，和未来粮食价格可能上涨"

具体催化剂我列了一堆：

1. 中东战争存在粮食危机
2. 化肥等进口价格上涨
3. 人口增长和耕地面积增长幅度不一致
4. 今年会有厄尔尼诺现象，可能导致粮食减产

然后我亲口说了一句现在回头看极为讽刺的话：

> **"我没有长期逻辑的，我只有这个波段逻辑。"**

更致命的是，当DeepSeek提到大豆、玉米、棉花才是真正受威胁的品种时，我问的是：

> **"那苏垦农发种的是？"**

——我连这家公司种什么都不知道。

## 错在哪里

1. **买入理由不是自己的**：博主的"油价涨→粮食涨"是一个我没有能力验证的二手结论。用别人的逻辑买入，一定会因为自己的恐慌卖出——因为那套逻辑在你脑子里没有根。

2. **对核心事实完全无知**：不知道中国主粮价格受国家严格管控（这是决定性的！），不知道苏垦农发种什么品种，不知道国家有储备粮体系可以平抑短期价格波动。我的"中东战争→粮食危机→粮价涨→苏垦涨"这个链条，每一步都没有经过验证。

3. **把波段当投资**：自己说得很清楚——"我没有长期逻辑，我只有波段逻辑"。这不是在投资一家公司，是在赌一个短期事件驱动的价格波动。本质上和省广集团、华力创通没区别，只是苏垦农发刚好是一个基本面更好的公司。

4. **吃了亏也没真正反省**：第一次已经因为季报暴雷恐慌割肉了，但后来又以同样的"波段逻辑"买回来。仓位1700股、市值近1.7万，在小账户灵活仓位中占比最高——但我连它种什么都不知道。

## 这条经验怎么用

- 买入任何一只股票之前，至少回答三个问题：这家公司靠什么赚钱？最大的风险是什么？为什么是我来赚这个钱而不是别人？
- 别人的结论一文不值，除非你亲自走了一遍他的推理过程并且每一步都认同
- "波段逻辑"本质上是"我觉得有人会用更高价接走它"——这是博傻，不是交易。真正的交易逻辑需要具体的催化剂、时间窗口和止损条件
- 今年种下"不懂不碰"这四个字，比任何一只翻倍股都值钱
