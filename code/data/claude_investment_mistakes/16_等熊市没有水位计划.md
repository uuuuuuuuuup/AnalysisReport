# 事件16：等熊市但没有水位计划

> 所属类别：五、系统性策略问题
> 创建日期：2026-06-05

---

## 当时发生了什么

我的核心策略是：

1. 牛市末端不激进加仓，守住利润
2. 把100万主力资金放在短融ETF等待
3. 等市场"充分回调"后，再分批进场布局
4. 目标是下一轮牛市资产翻倍

在诊断这个策略时，我提了一个问题：

> **"什么信号出现时适合开始用那100万分批布局？"**

## DeepSeek 的诊断

> "你能有这个想法，说明你的血管里已经流淌了一些价值投资的血液了。别人贪婪时恐惧，这个道理不新鲜，但能做到的人凤毛麟角。你能在牛市末端主动踩刹车，这很难得。"
>
> "但你问'什么信号出现时适合开始分批布局'——这说明你还在找水晶球。"
>
> "不存在一个神奇的信号。"

## 错在哪里

我把入场时机当成了一个"等信号"的问题——期待某个明确的事件或指标出现，告诉我"现在可以买了"。

但现实中：
- 没有一个铃声会在底部响起
- 真正的熊市底部，所有信号都是混乱的、互相矛盾的
- 在最该买的时候，感受到的情绪是恐惧而非信心

DeepSeek 用自己的经历说明：

> "2008年金融危机最恐慌的时候，我写了一篇文章说'我正在买美国'。我买完之后呢？市场又狠狠跌了几个月。我抄的不是底，我买的是'价值相比于价格已经足够划算的区间'。"

**我等的"信号"不存在。我需要等的不是信号，而是一个"水位"。**

## 正确的做法

DeepSeek 给出了完整的执行框架：

> "从现在开始，你就去研究如果熊市来了你想买的东西——宽基指数也好，你真正懂的公司也好。给它们标好价：'当沪深300跌到XXX点，对应市盈率XXX倍，我就买多少比例'。"
>
> "把这个计划现在就写下来，用钢笔写在纸上，锁进抽屉。"
>
> "等到熊市真来了，恐惧弥漫，新闻标题全是'现金为王'，连你的理发师都在跟你说要清仓的时候，你拿出那张纸，机械地执行它。"
>
> "**用规则对抗情绪。**"

具体执行节奏：

| 要素 | 方案 |
|------|------|
| 标的 | 宽基指数（低费率）为首选，或真正懂的公司 |
| 触发条件 | 明确点位 + 市盈率水位（例：沪深300跌到XXX点，PE≤XX倍） |
| 节奏 | 分12-18个月分批买入，不一把梭 |
| 纪律 | 提前写在纸上，到时就机械执行，不管当时多恐慌 |

## 为什么必须"提前写在纸上"

因为在"理发师都劝你清仓"的时刻，你的直觉会告诉你"这次不一样，还会继续跌"。如果靠直觉做决策，你绝对不会在那时候买。

提前写在纸上的计划，是"冷静时的你"给"恐慌时的你"留下的唯一救命绳。

## 另一层警惕：万一"牛市末端"的判断错了呢？

DeepSeek 还指出了我的策略中一个更根本的隐患：

> "你整个策略都建立在'现在是牛市末端'这个判断上。万一你错了呢？万一这只是一个大牛市的半山腰？"
>
> "我活了九十多年，没见过谁能次次猜对这个。所以你的策略里必须有个'万一错了怎么办'的预案——比如保留一部分永远不择时的定期投入。"

**不要在预测上押注全部资金。** 永远留一手，因为你可能猜错。

## 这条经验怎么用

- [ ] 把这个"水位计划"真正写下来——不是"改天再写"，是现在。具体点位、具体比例、具体标的
- [ ] 预留一部分资金做"不择时"定期投入——作为"万一牛市还没结束"的对冲
- [ ] 不要在等熊市的过程中变得焦虑而冲进去——球没来别乱挥，球来了别不敢挥
