# 事件5：恒生互联ETF"换汤不换药"

> 所属类别：一、不懂不碰的铁律
> 创建日期：2026-06-05

---

## 当时发生了什么

在清掉省广集团和华力创通之后，我重新整理了小账户，把持仓分为"高分红组合"和"高弹性组合"两组。在"高弹性组合"里，我放了一个新标的：

| 项目 | 数值 |
|------|------|
| 标的 | 恒生互联（互联网ETF） |
| 持仓/可用 | 30200/30200 股 |
| 成本价 | 0.421 元 |
| 现价 | 0.419 元 |
| 市值 | 12,653.80 元 |
| 累计盈亏 | -54.08 元 (-0.430%) |

乍一看没什么大不了的——亏了54块钱，仓位1.2万。但这是整个事件5的核心问题。

## 我当时怎么想的

DeepSeek 在看完我的持仓后，第一刀就砍向了恒生互联。他问了一个问题：

> "你买它，是因为你深入研究了中国头部互联网公司的每一条业务线、监管环境和竞争格局，认为它们作为一个整体被严重低估了吗？"
>
> "还是因为你觉得它跌了够久，互联网是'国之重器'，应该'抄个底博反弹'？"

在对话中，我承认了：

> **"我认为恒生互联是跌多了该反弹一下。"**

就这一句话。没有业务分析，没有估值计算，没有竞争格局研究。唯一的理由是——"跌多了该涨了"。

## 错在哪里

**我没有变。我只是换了一件更体面的外衣。**

之前买省广集团、华力创通，理由是什么？"波动大、有题材"——赌有人接盘。

现在买恒生互联，理由是什么？"跌多了该反弹"——赌板块轮动。

内核完全一样：**我根本不懂自己买的是什么，只是在不同的赌桌上换了筹码。**

DeepSeek 的原话，非常刺耳但完全正确：

> "你只是把一个具体的题材股，换成了一篮子题材股的ETF。包装更精美了，名字更响亮了，但内核依然是：'我赌这个曾经辉煌的板块会被资金再次光顾。'"
>
> "在你没搞懂它底层的10只重仓股之前，这只ETF就是一个你完全不懂的股票。"

### 为什么ETF比个股更危险？

ETF给人一种"安全"的错觉——"我买的是一篮子，分散了风险"。但分散的是个股风险，不是"无知风险"。

如果我不懂恒生互联持仓的前十大重仓股各自的业务模式、护城河、估值水平、竞争态势，那这个ETF和一只我完全不懂的个股没有区别。它不会因为"是一篮子"就变得更安全。

恰恰相反——因为它是ETF，我可能更麻痹大意、更不愿意止损、更容易说服自己"互联网总会回来的"。

### 更深一层：我在给自己做"心理洗白"

清掉省广和华力之后，我显然觉得自己已经"改正错误"了。把新持仓命名为"高弹性组合"而非"灵活仓位"，也是在语言层面合理化自己的行为。

但内核没有变。我只是把赌博行为包装成了一个更体面的名字，然后心安理得地继续赌。

## DeepSeek 的建议

> "恒生互联：卖掉。今天就卖，不要在成本价附近等回本。那一丁点亏损，是你付给自己的'认知税'，是为了让你永远记住：不要买你无法估值的东西。这堂课，60块钱的亏损，太便宜了。"

## 这条经验怎么用

- 买ETF之前，先打开它的前十大重仓股，逐个问自己：我懂这家公司吗？有一家不懂，这个ETF就不该买
- "跌多了"永远不是一个买入理由。地板下面还有地下室，地下室下面还有地狱
- 当你发现自己开始给持仓"取好听的名字"的时候，警惕——你可能在用语言包装来麻痹自己
- 54块钱的亏损换这堂课，确实太便宜了。很多人是用五万四甚至五十四万才学会的
