# 事件9：估值靠"感觉"而非计算

> 所属类别：三、研究深度的欠缺
> 创建日期：2026-06-05

---

## 当时发生了什么

在我买入分众传媒、海澜之家、老板电器、海螺水泥的时候，决策过程大概是这样的：

- 看到股息率还不错
- "感觉"价格不算贵
- "应该"是低估区间
- 买入

没有一个量化的估值模型，没有一个明确的安全边际要求，没有一个分档买入的价格计划。

## 错在哪里

**1. "感觉便宜"不是一个投资决策。**

DeepSeek 反复强调的观点是：

> "便宜是算出来的，不是感觉出来的。"

一只股票"看起来便宜"可能有三种情况：
- 它真的便宜（估值处于历史低位，基本面良好）
- 它看起来便宜是因为基本面在恶化（利润下滑→PE看起来很低）
- 它只是比去年便宜了（跌了≠便宜）

没有量化的锚，"感觉便宜"可以是上述任何一种。

**2. 没有"击球区"。**

价值投资的核心不是"找到好公司"——分众、海螺都是好公司——而是"在正确的价格买入好公司"。

正确的价格不是"大概便宜就行"，而是一个明确的区间：
- 当股息率达到X%时，对应当前利润水平，隐含的回报率是多少
- 当股价跌到Y元时，对应的PE是多少倍，是否低于历史中枢
- 目标仓位是多少，分几档建仓

我没有这些。所以我只能在"感觉便宜"的时候买入，然后在继续下跌时焦虑——因为我不知道自己买贵了没有。

## 一个具体的替代方案

DeepSeek 建议的框架：

| 要素 | 示例 |
|------|------|
| 目标标的 | 分众传媒 |
| 估值锚 | 股息率 |
| 击球区 | 股息率≥6%开始关注，≥7%买入第一档 |
| 分档计划 | 6%: 观察不买 · 7%: 买目标仓位30% · 8%: 再买30% · 9%: 买满 |
| 最大仓位 | 不超过进攻账户XX% |

有了这个框架，当股价下跌的时候，我不会焦虑——因为我知道什么时候该出手、出多少。当股价没到击球区的时候，我也不会被"怕踏空"驱动去追——因为规则说没到就没到。

> "一个清晰的分档买入计划，能有效管住手。"

## 这条经验怎么用

- 每只持仓必须有一个量化的估值锚（股息率、PE、PB、自由现金流收益率，选一个最适合该公司的）
- 买入前必须有"击球区"定义——到哪个数字才开始动手
- 必须有分档计划——第一档买多少、第二档买多少、最多买到多少
- "感觉"可以用作研究起点（"这个公司好像不贵，去看一下"），但不能用作决策终点
