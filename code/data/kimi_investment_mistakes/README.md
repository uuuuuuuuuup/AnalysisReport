## 巴菲特核心诊断汇总

1. **现金是残值期权**，持有本身有成本（通胀），不是"防守"
2. **不懂不做**，如果跌30%不敢加仓，就不该持有
3. **把"等信号"改成"盯水位"**，提前写好计划，恐慌时机械执行
4. **10万账户是模拟驾驶舱**，不是游乐场
5. **区分"消费"和"投资"**，1万可以赌，但要做好归零准备
6. **按"生意"买股票**，不是按"标签"
7. **短线是零和博弈**，价值投资是正和博弈
