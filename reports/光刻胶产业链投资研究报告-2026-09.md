## 摘要（一页看懂）

**一句话结论：生意是真的，方向是真的，价格是全球最贵的。与初步分析"等待放量拐点确认"的判断一致，且经数据强化——现阶段不买，全部进观察池，用触发器等待。**

**五个核心发现**：

1. **逻辑链"需求侧"强验证、"断供侧"证伪**。中国大陆2026-2028年300mm设备投资940亿美元居全球第一、晶圆产能份额20%→32%（2030E）；但"日本断供"从未发生——2019年对韩管制2023年已解除、2023年7月日本23类设备管制不含光刻胶、2025年10月"加税/三锁"查无官方文件、2026年6月"四大厂停接新单"被海关数据证伪（2026年1-5月自日进口光刻胶8,900+吨，月度平稳）。替代的真实驱动是**晶圆厂供应链"双供"风险管理+政策扶持+本土响应速度**——是慢变量，不是事件催化。8·19板块暴跌5-9%（费半-5%拖累+获利回吐，彤程7月高点102.28元后最低54元）正是事件炒作脆弱性的预演。

2. **空间比初步分析更大，阶段比初步分析更早**。KrF国产化率主流口径仅3-10%（初步分析为15-22%）、ArF不足1-5%、上游树脂90%依赖进口（初步分析为<30%）——每一层的空间都更大，但每一层都更早阶段。行业仍处"从1到10"的爬坡初期。

3. **"A股无纯正标的"的悖论有了量化答案**。最"纯"的恒坤新材（光刻材料占营收78%）恰恰财务最弱：PE(TTM) 145x、2026H1利润55%来自公允价值变动（理财+投资）、客户集中度前五大94%、无券商盈利预测、2026年11月首批解禁；而质量最好的彤程新材（ROE 16%、五年扣非翻倍）光刻胶占总营收仅约15-22%。"纯度"与"质量"系统性错位——买光刻胶，本质是买**平台型公司的第二曲线**。

4. **跨市场估值差是本行业最重要的估值锚**。A股光刻胶本体公司PE(TTM) 58-146x，全球同业：东进世美肯TTM≈11-12x（FY2025静态≈22x）、信越化学≈24x、TOK≈33x、Qnity(原杜邦电子)≈35x。韩国替代的标杆成功者（东进，2019年管制后3年突破EUV光刻胶并导入三星、2026H1净利+248%）至今只被市场按化工股定价——**这是A股光刻胶终局估值最有力的一面镜子**。

5. **首选观察组合**（全部未触发，不建仓）：彤程新材（核心仓候选；触发器：PE≤40x 或 光刻胶收入连续两季+50%——2026H1已+50%，Q3是关键确认点）、鼎龙股份（卫星候选；基本盘现金流最厚+光刻胶免费期权）、南大光电/八亿时空（期权仓候选）、徐州博康（未上市估值锚约71-74亿·2024年交易口径，IPO候选）。**主题仓位上限：进攻账户10-15%，大账户（债基）不参与**。

## 第一步：投资逻辑链构建与验证

### 1.1 逻辑链

```
中国晶圆厂扩产（产能份额20%→32%，2020→2030）
    → 光刻胶需求增长（中国需求占全球约1/3，2028年市场规模150亿元）
        + 日本供应链集中风险（前五大厂76-90%份额）+ 政策推动（02专项/大基金三期）
            → 晶圆厂主动导入国产（供应链风险管理驱动，而非现实断供）
                → 国产厂商验证-放量（KrF放量拐点、ArF爬坡初期）
                    → 业绩兑现（预计2027-2030年梯次兑现）
```

## 第二步：产业链全景图

### 2.1 产业链结构

```
【上游：原料层——90%进口依赖区，弹性最大】
├─ 树脂（光刻胶成本占比约50%）
│   ├ 日系垄断：三菱化学(KrF/ArF PHS树脂)、住友电木(酚醛)、旭化成、陶氏
│   └ 国产：彤程新材自产(i线已量产、KrF PHS多款量产、ArF树脂仅中试)、
│            八亿时空(KrF树脂2025年吨级出货)、圣泉集团(PHS小批量)、
│            徐州博康(未上市)、强力新材(树脂以LCD/PCB级为主)
├─ 光酸PAG/光引发剂（成本占比约15%）
│   └ 日系：东洋合成(4970.T)、ADEKA(4401.T)、BASF || 国产：强力新材、万润股份、徐州博康
├─ 单体（i线100-200元/kg → KrF 500-1,000 → ArF 3,000-10,000，价值量逐级跳升）
│   └ 国产：瑞联新材(ArF单体已量产、KrF单体2026Q2满产)、徐州博康(KrF单体全球份额20%+)、万润股份
├─ 溶剂PGMEA：哈纳材料(韩)、伊士曼体系 || 国产：怡达股份(方向性)
└─ 萤石→高纯HF/含氟PAG：中国掌握全球萤石产量约70%——中方在含氟环节的反制筹码

【中游：本体+配套——验证壁垒核心区】
├─ 光刻胶本体（JSR/TOK/信越/住友/富士前五合计约90%，JSR已于2024年被JIC私有化退市）
│   └ 国产梯队：北京科华(彤程系·SEMI八强·KrF本土>10%)、鼎龙、上海新阳、
│               南大光电(ArF六款验证)、苏州瑞红(晶瑞系·i线市占第一)、徐州博康、恒坤
├─ SOC/BARC抗反射层：Resonac(日) || 国产第一：恒坤新材
├─ 显影液TMAH：东京应化/富士 || 国产：格林达(下游90%为面板)、肯特催化(原料G4级进中芯/长存)
├─ 光刻气：华特气体、中船特气
└─ 涂胶显影设备（强相关非材料）：芯源微（A股唯一，但2025年扣非亏损）

【下游：需求层——全球最大增量区，全部满载扩产】
├─ 逻辑代工：中芯国际(81亿美元capex、2026产能117万片/月)、华虹(140亿12英寸线、利用率106%)
├─ 存储：长江存储(三期提前至2026H2、科创板IPO受理)、长鑫存储(2026设备采购50-60亿美元)
└─ 特色工艺：晶合集成(四期355亿)、粤芯半导体(2026-06创业板过会)
```

### 2.3 卡脖子环节识别（按"卡"的程度排序）

1. **ArF/EUV用高端树脂**——最卡：彤程ArF丙烯酸树脂截至2025年报仅"完成开发定型、中试放大"尚未量产自给；全行业高端树脂国产化率不足5%
2. **ArF光刻胶本体**——日系垄断96%+：国产合计份额不足1-5%，南大6款验证+恒坤小批量+鼎龙爬坡，均处0→1阶段
3. **KrF光刻胶本体**——正突破：国产化率3-15%（口径分歧），科华本土市占>10%已领先
4. **KrF用PHS树脂**——彤程多款量产+八亿时空吨级出货，1→10进行中
5. **PAG光酸/显影液**——部分国产（肯特催化G4级进中芯/长存）

> **段永平追问：这门生意的本质是什么？** 光刻胶是"配方+信任"的生意——技术代际决定单价（i线约数百元/升 → KrF约800元/升 → ArF约2,500元/升，浸没式更高），客户验证决定生死（2-3年验证、一旦进入Baseline极少更换）。它天然是慢生意、好生意，但A股把它当快题材炒——错配就在这里。

### 5.2 历史类比（三面镜子）

**类比一：韩国2019-2025——最直接的前传**
2019年7月日本管制（韩国库存仅够2-3个月）→政府扶持+企业攻关→2021年东进世美肯EUV胶通过三星可靠性认证→2022年底三星首次导入本土EUV光刻胶量产（**单点突破用时3年**）→对日依赖从93.2%（2018）降至65.4%（2024，**用时5-6年，且未清零**）。**投资结局**：替代"成功"了，但东进世美肯当前TTM-PE仅约11-12x（2026H1净利+248%后；FY2025静态约22x）——市场最终按化工股给替代成功者定价。2019-2021主题阶段赚钱者众，业绩兑现期必须忍受估值中枢从"期权"回归"化工"的坍缩。**启示**：中国大概率复刻韩国节奏；A股当前价格同时押注"替代成功"与"维持成长股估值"两个乐观。

**类比二：日本材料股30年——生意的终局**
信越FY3/26归母净利4,744亿日元、PE约24x——高壁垒材料是三十年长牛生意，但估值中枢始终20-30x，赚的是EPS的钱。JSR私有化对价隐含约15x（2024年退市）——**日本主权资本（JIC）入场保护材料产业，但其2026年拟出售时的产业买家（富士/三菱被指有意）出价逻辑仍是化工估值**。材料的战略价值被国家背书，财务定价仍是化工——这个反差本身就是A股高估值的镜子。

**类比三：A股半导体材料2020-2024轮回**
2020-2021国产替代主题行情→2022-2024杀估值（板块龙头高点回撤50-70%）→2025-2026叙事再起。本轮光刻胶行情由2026年6月"断供传闻"点燃（彤程6月30日创历史新高97.98元），随后传闻被辟谣+8·19外部暴跌，一个月内最大回撤40%+——**情绪周期的位置感**：当前处于"传闻退潮后的反弹初段"（9月7日板块+2.09%），不是"无人问津的底部"。

### 5.3 偏误自查

- **叙事偏差**："卡脖子+国产替代"故事完美——但断供从未发生，故事真实内核（风险管理+政策+性价比）是慢变量。故事越完美越要问：谁在卖故事？
- **锚定**：板块从6月高点回撤30%后反弹，容易把6月价格当"合理锚"——但6月高点本身就是传闻驱动的水位。
- **从众**：聚源"光刻胶"概念83只中约50只无实质业务——蹭概念公司的数量是情绪温度计，当前读数偏高。
- **幸存者偏差**：本报告聚焦的六家都是"跑出来的"；2021年那批光刻胶概念股中相当部分从未回到前高（如上海新阳2021年高点至今未复）。

## 第六步：文明趋势判断（李录框架）

- **底层趋势定性：文明级，非阶段性热潮**。两股文明级力量交汇：①算力成为文明基础设施（AI），半导体是其物理载体，材料是载体的载体——"新石油的上游"；②地缘安全重构，供应链按主权重新画地图。半导体材料全球大转移第三浪：美国→日本（1970-80s，成就信越/TOK/JSR三十年霸权）→韩台（1990-2010s，东进等分得第二杯羹）→**中国（2020s-，本轮需求占全球1/3、规模最大）**。
- **10-20年终局**：中国晶圆产能全球份额32%（2030E）→光刻胶自给率2030年30-50%、2035年50-70%（"韩国+"）；形成2-3家本土本体龙头（最可能：科华/彤程系平台+一家技术型公司）+树脂/单体国产配套生态（博康、八亿时空、瑞联等）。**中国出现自己的"信越化学"是大概率的文明事件。**
- **赢家通吃环节**：光刻胶本体——客户验证锁定使先发者通吃各自客户池（科华已锁定的12寸线份额极难被后来者夺走）；树脂环节的终局集中度将高于本体。
- **最可能被颠覆环节**：i线（已被国产内卷到无超额收益）；EUV胶若十年内突破将重构高端格局，但全球EUV胶市场2026年仅4.36亿美元（占半导体光刻胶约13%），是战略高地而非近期业绩变量。
- **下注顺序（文明趋势×兑现时间矩阵）**：KrF本体（2026-2028兑现）> KrF/ArF树脂（2027-2030）> ArF本体（2028-2032）> EUV（2032+）。

### 7.3 主题仓位上限建议

- **光刻胶主题≤进攻账户（约9.4万）的10-15%**，即约1.0-1.4万元，触发后分2-3批建仓；**大账户（110万债基）不参与**——与既有资金纪律一致
- 理由：①估值全球最贵（58-146x vs 11-35x）；②逻辑链"断供环节"被证伪，替代靠慢变量；③验证周期2-3年、业绩兑现分化大；④按"胜率大"标准，当前阶段属于高波动叙事押注——这正是去劣筛选已经给出过"不买"结论的同一类资产
