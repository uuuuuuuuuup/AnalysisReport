# AI大模型产业链投资研究报告

**报告日期**：2026-09-04 ｜ **数据截止**：2026-09-04（行情为当日盘中）
**研究框架**：产业链全景扫描 + 四大师（段永平/巴菲特/芒格/李录）个股分析
**数据说明**：全部数据由 5 个并行数据子代理采集（anysearch 实时搜索 / ai-tools / mx-data / 灵犀），关键财务数据经双源交叉验证，冲突口径已标注。本报告不构成投资建议。

---

## 摘要（一页看懂）

1. **需求侧已充分验证且指数级**：中国日均 token 调用量两年增长超千倍（1,000亿→500万亿），四大云厂 capex 2026 年指引约 7,250 亿美元（+77%），2025 年大模型政企中标金额 295.2 亿元（+356%）。这是"规模化放量初期"，不是概念期。
2. **但收入验证严重分化**：Anthropic run-rate 650 亿美元、Cursor/Claude Code 等编程场景最强；可灵 ARR 近 5 亿美元（70% 海外）是 中国AI应用最强样本；而国内纯模型公司收入仅数亿元人民币量级（智谱 2026H1 9.54 亿元、MiniMax 1.166 亿美元）且普遍经调整亏损扩大。
3. **模型层是全产业链生意属性最差的环节**：智谱综合毛利率从 64.6%（2023）崩至 26.4%（2026H1），中国旗舰模型定价仅为 Claude 的 1/6～1/50，上游算力涨价（"算力通胀"）与下游 token 降价两头挤压。
4. **估值极端分化是最大的结构性事实**：智谱 PS(TTM)≈318 倍（约 42 倍 ARR，比 Anthropic 的 15 倍 ARR 贵近 3 倍）、寒武纪 PE 148 倍；而阿里/快手仅 19 倍 PE。可灵已完成分拆重组（独立主体北京可灵智能科技）并完成最高 30 亿美元 Pre-IPO 融资（投后 180 亿美元、快手仍控股 68.33%）——按该估值，快手持有的可灵股权约 123 亿美元、占自身市值约 65%，隐含主业 PE 仅 2-5 倍。
5. **核心结论**：用合理价格的**平台型公司**（阿里 19 倍 PE + 云 +45% 加速 + AI 收入连续 12 季三位数）承载主仓位，用**应用层已验证标的**（快手/可灵）做卫星，把纯模型层（智谱/MiniMax）当高波动期权而非核心资产。主题仓位上限建议 15%，其中纯模型层 ≤5%。

## 第一步：投资逻辑链构建与验证

### 1.1 逻辑链

```
大模型技术突破（GPT-5/Claude/Qwen/DeepSeek）+ 推理成本下降 280 倍
    → Token 消耗量指数级增长（中国日均 1,000亿 → 500万亿，两年千倍）
        ├→ 分支A：算力基建需求爆发（capex +77%、智算 2,185 EFLOPS）
        │    → 上游算力硬件量价齐升（NVDA +106%、AVGO AI +221%、国产芯片 41%）
        │        → 受益：芯片/光模块/服务器/IDC
        ├→ 分支B：应用层繁荣（月活近 5 亿、企业采用率 88%）
        │    → 少数场景跑通商业闭环（AI编程 ARR 百亿美元级、视频生成可灵 5 亿美元）
        │        → 受益：编程工具、视频生成、垂直应用
        └→ 分支C：模型层收入起量（智谱 +400%、DeepSeek 年化 4-5 亿美元）
             → 但价格战 + 资本开支 → 毛利率坍塌、经调整亏损扩大
                 → 模型层公司依赖融资输血（IPO/配售）
```

### 2.3 卡脖子环节识别

1. **最硬的卡脖子**：先进制程代工（台积电）与 EUV（ASML）——物理级垄断，AI 扩产唯一路径
2. **中国的卡脖子（=国产替代机会）**：AI 芯片。2025 年国产化率 41%（约 165 万颗），昇腾 81.2 万张居首；中移动集采指定 CANN 生态占 70%——**行政力量正在把需求定向输送给国产链**
3. **利润最厚的环节**：模型 API 的"闭源溢价"——Claude 输出价 $25/M vs DeepSeek $0.28/M（V4-Flash 2元）。但该溢价正被中国开源模型快速侵蚀（差距已缩至 0.6 个百分点的 SWE-bench 分数）

> **巴菲特追问**：哪个环节 10 年后还存在？——铲子（芯片/代工/光器件）和入口（超级App）一定在；**中间的"模型 API 层"很可能被开源压缩成公用事业**。Qwen 30 亿次下载已经在做这件事。

| **中游价格战持续**（毛利率坍塌固化） | 高（>60%） | 高 | 智谱毛利率 64.6%→26.4% 已发生；DeepSeek 错峰定价仍在降价。应对：不把纯模型层当核心仓 |
| 估值泡沫破裂（智谱 PS 318x 回归） | 中 | 高（传染全板块情绪） | 智谱已自高点回撤 63%、MiniMax 71%——泡沫已在局部释放。应对：模型层 ≤5% 仓位 |
| 替代技术/范式突变 | 低（10-15%） | 中 | 开源追平闭源（差距 0.6pp）反而利好应用层降本 |
| 监管黑天鹅 | 低-中 | 中 | 备案制常态化（988 款）；端侧已放行首批 7 款——监管趋暖而非收紧 |
| 地缘/出口管制升级 | 中 | 高（国产链受益/全球链受损的双向博弈） | 国产芯片 41% 占比是缓冲；已按"中国链+全球链"分散 |

### 5.2 历史类比

**类比对象：2000 年互联网+光纤基建**

| 维度 | 2000年光纤/互联网 | 当前 AI |
|---|---|---|
| 基建先行 | 环球电讯等铺设过剩光纤 | 四大云厂 $7,250 亿 capex |
| 基建商结局 | 多数破产（环球电讯 2002） | **未知——取决于 2027 年应用收入能否接棒** |
| 成本暴跌 | 带宽成本 -90% | 推理成本 -280 倍 |
| 最终赢家 | 基建之后的应用平台（YouTube/Netflix/云计算，2005 年后才显现） | AI 编程/视频/Agent（正在显现）；平台终局未定 |
| 思科启示 | 2000 年 PE 130 倍见顶，产业对了、股票 20 年未收复 | NVDA ~14 倍市销率不算极端，但**周期属性相同** |
| 亚马逊启示 | 跌 92% 后成为最大赢家 | **当前的应用层赢家可能是"还没上市的公司"** |

**多数投资者在 2000 年亏钱的原因**：买了对的趋势、错的标的、错的价格。当前启示：**趋势不容置疑（token 千倍增长），但仓位结构决定生死**。

### 5.3 偏误自查

- **叙事偏差**：AI 故事确实"太完美"（token 千倍+ARR 百亿美元）——刺是 PwC 56% 无 ROI、豆包订阅上线即掉粉 610 万。故事为真 ≠ 收入为真。
- **锚定效应**：智谱 +858% YTD 会锚定后来者的心理价位；2,980 港元的高点不是任何估值锚。
- **从众效应**：豆包 3.82 亿 MAU 是用户从众；PS 318 倍是资金从众。**从众在产品层面成立（网络效应），在定价层面是灾难。**

## 第六步：文明趋势判断（李录框架）

1. **这是"文明级范式转移"还是"阶段性热潮"？**——是范式转移。判断依据不是估值而是渗透速度：电力用了几十年覆盖工业，互联网用 15 年覆盖消费，**AI 用 3 年让企业采用率到 88%、中国 token 调用量两年千倍**。且这次有一个此前技术革命没有的特征：**技术本身以月为单位自我迭代**（GLM 11 个月六代）。这不是 3D 打印式的"技术永远差五年"。
2. **最接近的历史类比**：电力（1900s）。大模型正在变成"不可见的公用事业"——最终没人会"谈论"用哪个模型，就像没人谈论用哪家电厂。**公用事业化意味着：模型层利润率被永久压缩，价值向两端（芯片制造/应用入口）迁移。**
3. **10-20 年终局**：少数通用大模型（全球 3-5 家）+ 无数垂直 Agent；模型调用像电力按表计费。**赢家通吃环节**：上游制造（台积电/EUV——物理垄断）与入口（超级App/OS 级 Agent——习惯垄断）。**最先被颠覆环节**：无差异化数据的中间 API 层、SaaS 壳公司、搜索中介。
4. **中国的独特位置**：中国用**开源换生态**（Qwen 占全球开源下载 50%+、HF 平台 41% 下载来自中国模型），美国用**闭源换利润**（Anthropic $650 亿 ARR）。两种模式赛跑——开源策略的回报不体现在模型收入，而体现在**生态标准权**（相当于 Android 之于 Google：不靠系统赚钱，靠生态赚钱）。
5. **李录式结论**：方向上"做多中国 AI 生态"和"做多全球 AI 基础设施"都成立；但 1999 年买思科的人对了产业、错了投资，2002 年敢买亚马逊的人才赚到时代的钱。**现在最确定的赢家（算力）价格已不便宜，真正的终局赢家（应用平台）多数还没上市或还没被认出来——所以用"平台型公司+小仓位期权"的方式参与，是既不错过时代、又不被时代杀死的唯一姿势。**

### 7.3 主题仓位上限

**建议 AI 大模型主题 ≤ 总仓位 15%**，其中：
- 纯模型层标的（智谱/MiniMax/商汤）合计 ≤5%
- 上游算力（如通过本组合外配置）计入同一上限
- 理由：逻辑链前半段验证充分但后半段（利润兑现）未验证 + 板块估值方差极大（PS 1.8 倍到 318 倍）+ capex 周期风险真实存在。这是"高确定性趋势 + 低确定性回报结构"的典型组合，只配得上卫星级总仓位。

### 四位大师模拟点评

> **段永平**："模型层是同质化的苦生意——价格战打到毛利率 26%，客户今天用你明天就能换 DeepSeek，这不是我想要的生意。但用 19 倍 PE 买阿里，等于电商现金牛白送一个全球第一的开源生态；快手更夸张，光它手里那 68% 的可灵股权，就值掉快手段市值的六成半，剩下的主业一年赚 200 多亿才定价两三倍。**买主业送期权的事我看得很懂，追 858% 涨幅的事我不碰。**"

> **巴菲特**："我看到 10 年后确定还在的是台积电的工厂和用户手机里的超级 App；确定不在的是今天这 10 家模型公司里的 8 家。中国的模型定价是 Claude 的五十分之一——**没有定价权的生意，增长越快烧钱越快**。我会等，等潮水退去后买真正有转换成本的公司，或者现在就用合理价格买被错误分类的平台。"

> **芒格**："四大云厂一年 7,250 亿美元 capex，而 56% 的 CEO 说 AI 没带来任何收益——这让我想起 2000 年的光纤：带宽确实涨了千倍，但埋光纤的人多数破产了。**反转什么时候来？我不知道。所以只做两件事：买有现金流和现金垫的（快手、商汤的 130 亿现金），用可以归零的小仓位买彩票（智谱）。**"

> **李录**："方向我毫不怀疑——3 年 88% 的企业渗透率、两年千倍的 token 增长，这是电力级别的事。但历史的教训是：技术革命的第一波财富属于基建商（思科），最大财富属于第二波的应用平台（亚马逊），而后者在第一波破灭时还没上市或被抛弃。**今天你要做的不是预测谁赢，而是确保自己既在牌桌上、又不会被清盘——平台型公司打底、应用验证标的加厚、模型层只当彩票。**"
