## 二、漏斗步骤（四步，各带验收标准）

### 第 0 步：粗筛修复（预计半天）

| 动作 | 说明 |
|---|---|
| 补样本 | 按行业分组重扫（单行业单查询，绕开问财复杂语法截断），与既有 40 只取并集 |
| 补分位 | 全部标的补 10 年 PB / PE / 股息率分位（粗筛只有绝对值） |
| 补字段 | 股息率 null 补齐；L2 财务报告期全部回源定档（尤其保利发展的口径矛盾） |

**验收**：修复后清单 80-150 只，每只带三维 10 年分位 + 触发条件标注。

### 第 1 步：分位初筛（低估特征 + 错杀特征双条件）

- **低估特征（三选一入池）**：PB 十年分位 ≤ 30% ∨ PE-TTM 十年分位 ≤ 30% ∨ 股息率 ≥ 4%；
- **错杀特征（二选一入池）**：距 52 周高点回撤 ≥ 30% ∨ 近 1 年跑输所属行业指数 ≥ 20%（区分"普跌中的个股连坐"与"行业性下跌"）；
- **周期行业特别规则**：以 PB 分位为主，PE 分位仅参考（周期顶 PE 失真，见 T1）。

**验收**：入池名单，每只标注触发条件组合（如"PB 分位 22% + 回撤 38%"）。

### 第 2 步：行业打包体检（防止个体误判）

入池标的按行业分组，每行业出一张**五维体检卡**：

1. 行业估值分位 vs 个股分位的偏离度（个股比行业低多少 = α 还是纯 β）；
2. 景气位置（营收/利润增速趋势、核心产品价格历史分位、资本开支与库存周期）；
3. 政策环境（鼓励 / 中性 / 压制）；
4. 供给格局（集中度趋势、产能出清进度）；
5. 资金行为（北向 / 机构持仓 / 行业 ETF 申赎）。

**行业三结论**：①行业性低估 → 全行业进第 3 步；②行业中性 → 只挑显著偏离者；③行业性陷阱 → 整行业归档禁区（不再逐票浪费工作量）。

**验收**：收窄至 3-5 个行业，个体池 20-40 只。

### 第 3 步：个体判别（八类框架 + 决策树，见第三节）

- 每只跑决策树，产出**低估类型判定卡**（主类型 + 副类型 + 证据 + 证伪 + 锚建议）；
- 判定纪律：每档判定需 **≥3 条硬证据，缺一条降一档**；全程【数据事实】/【推断】分离标注。

**验收**：判定卡齐全，类型归因明确，无"疑似"字样残留。

## 三、低估类型判别框架（核心章节）

八类三组：**甲组假低估**（T1-T4，市场没看错，排除）、**乙组真低估**（T5-T7，市场看错，猎物）、**丙组灰区**（T8，需催化）。

### 甲组：假低估——排除对象

#### T1 周期顶假低估（最会骗人）

- **机理**：景气顶部利润暴增 → PE 显得极低。周期顶的低 PE 是最贵的估值。
- **判别指标**：PB 分位高 + PE 分位低背离；核心产品价格处历史高分位；在建工程/资本开支高峰；行业新增产能集中投放。
- **证伪问题**：利润 normal 化到 5-10 年平均 ROE 中枢后，PE 还低吗？当前盈利处在自身历史分位的什么位置？
- **A股案例参照**：2021 年中远海控 PE 约 3 倍（海运超级周期顶），随后两年利润大幅回落、股价腰斩。
- **对应粗筛**：华友钴业（PE 8.8 + ROE 7.1%，需查钴镍锂价格分位定档）。

#### T2 一次性损益扭曲

- **机理**：当期利润被一次性项砸低（PE 虚高）或垫高（PE 虚低），账面估值失真。
- **判别指标**：扣非 vs 归母净利润背离度；公允价值变动 / 资产处置 / 大额减值 / 政府补助占利润比重。
- **证伪问题**：剔除非经常项后的正常化 PE/PB 是多少？连续 3 年扣非净利润的趋势方向？
- **A股案例参照**：2018 年报季商誉减值批量爆雷，一批"低 PE"公司由盈转亏。

#### T3 财务质量折价（理性定价，一票否决级）

- **机理**：利润真实性 / 资产质量存疑 → 低估值是市场的理性定价，不是错杀。
- **判别指标**：经营现金流净额 / 净利润 3 年累计 < 0.7；应收+存货增速持续显著高于营收；大存大贷；关联交易占比高；审计意见历史瑕疵。
- **证伪问题**：如果利润是假的，现在的"低估"还是低估吗？审计师近 5 年换过吗？为什么？
- **A股案例参照**：康得新、康美药业暴雷前的"低 PE 白马"形态。
- **处置**：命中 2 条以上即出局，不进入后续判别。

#### T4 价值陷阱（永久性衰退）

- **机理**：便宜是真的，但会永久便宜——行业需求见顶 / 模式被颠覆 / 竞争力流失，估值中枢结构性下移，"便宜"本身就是均衡价格。
- **判别指标**：5 年营收 CAGR 为负或趋零；行业需求变量（人口 / 渗透率 / 替代品）见顶；ROE 中枢逐级下移（每轮周期高点低于上轮）；分红超过自由现金流（不可持续）。
- **证伪问题**：行业的终局是什么？10 年后它还存在且赚钱吗？上一轮行业下行它靠什么走出来——这一轮还有什么不同？
- **A股案例参照**：2021 年起地产股 PB 0.3-0.5 "便宜"了四年继续跌；百货 / 纸媒。
- **对应粗筛**：C 档广汽（合资出清未结束，破净是果不是错）、保利（减值周期未确认见底）。

### 乙组：真低估——猎物

#### T5 事件性错杀（最高优先级）

- **机理**：利空连坐 / 情绪冲击 / 机制性卖压（指数剔除、基金赎回、衍生品敲入等被动抛售），基本面完好或仅暂时受损。
- **判别指标**：①超跌系数——股价回撤幅度 ≥ 盈利下修幅度的 3 倍；②资产负债表完好（净现金或低有息负债）；③行业格局未恶化（份额稳定 / 集中度提升）；④产业资本行为（回购 / 增持 / 员工持股在买入）；⑤利空可归因为一次性（单一大客户、单一政策、汇率油价等外生变量）。
- **证伪问题**：假设明天没有恐慌盘，愿按现价买入持有 3 年吗？利空解除后盈利能回到什么水平？当前价格对"利空永久化"情景的定价有多充分？
- **A股案例参照**：2018 年 10 月白酒（外部冲击+情绪底，随后翻倍）；2024 年 2 月微盘崩塌中被连坐的大盘股。
- **与 T6 的区分**：T5 有利空事件、跌幅陡峭；T6 无事件、阴跌磨底。

#### T6 风格与资金压制（可修复，次优先）

- **机理**：无利空事件，纯资金搬家 / 不在风口 / 筹码结构恶化（外资集中撤离、机构持仓降至历史冰点）。
- **判别指标**：机构持仓分位处历史低位；股东户数趋势；成交额萎缩至冰点；基本面质量与估值分位形成剪刀差（ROE 稳定但估值分位创新低）。
- **证伪问题**：压制因素可逆吗？潜在买家是谁（保险/长线配置盘的买入逻辑成立吗）？已阴跌多久（3 年 vs 半年——时间成本完全不同）？
- **A股案例参照**：2021-2023 白马股杀估值段（茅台 2600→1300 途中基本面增速仍在）；2023 "中特估" 行情前的建筑央企。
- **注意**：T6 修复依赖风格切换，时点不可控 → 击球锚必须按"股息率补偿等待成本"设计。

#### T7 认知差 / 隐性资产

- **机理**：市场没有算进去的资产价值——持有其他上市公司股权、成本法记账的投资性物业、土地重估、新业务拐点、改革红利。
- **判别指标**：隐性资产 / 市值比 ≥ 30%（股权按可比市值加总、物业按公允口径重估）；新业务收入占比出现拐点。
- **证伪问题**：这些资产可变现、可分红吗（变现路径与税负成本）？市场为什么长期没定价（有无流通/合规约束）？
- **A股案例参照**：2014-2015 国企改革行情中的土地/股权重估逻辑；反面教训——品牌价值类"隐性资产"（如张裕式品牌叙事）因不可变现长期不获定价。
- **对应粗筛**：中油资本（金融牌照+股权结构，但需警惕流动性折价长期化）。

### 丙组：灰区

#### T8 治理折价（半永久，需催化）

- **机理**：大股东占款 / 高频减持 / 治理瑕疵 → 市场长期给折价，无催化不修复。
- **判别指标**：大股东质押率 > 50%；高频减持史；分红记录差而再融资频繁；实控人司法/监管记录；少数股东权益被侵蚀。
- **证伪问题**：有无改善催化（国资入主 / 回购注销 / 分红承诺 / 治理整改）？无催化的折价就是永久损耗。
- **处置**：有催化 → 按 T6 处理；无催化 → 归禁区。

### 3.4 判别决策树（顺序执行，不可跳步）

```
1. T3 财务质量硬检查 ──── 不过 → 出局（一票否决）
2. T2 正常化利润重算 ──── 剥离一次性项，重算估值
3. T1 周期位置判定 ────── 周期顶 → 出局；周期左侧 → 转"拐点跟踪"单列
4. T4 行业终局判定 ────── 陷阱 → 出局
5. T5/T6/T7 归因 ──────── 有利空事件 → T5；无事件阴跌 → T6；有隐性资产 → T7
6. T8 治理检查 ────────── 有催化 → 升级猎物档；无催化 → 禁区
7. 排序输出：T5 > T6 > T7 > T8(带催化)；档内按"超跌系数 × 资产负债表强度"排序
```

### 3.5 框架通用纪律

- **双口径**：所有分位数据同时报 1 年与 10 年口径（沪深 300 教训）；
- **周期股**：PB 分位为主、PE 为辅；
- **收息类**：穿透率锚一律取保守值口径（10/14 复核教训：池锚与暴风雨库两套并存）；
- **标注**：【数据事实】与【推断】全程分离（沿用工作区约定）。

## 四、出口纪律

### 4.1 三档输出

| 档位 | 来源类型 | 产出物 |
|---|---|---|
| 猎物档 | T5 / T6 / T7 | 候选清单，**每只带击球锚** |
| 拐点跟踪档 | T1 周期左侧 | 拐点信号清单（产品价格、库存、产能出清进度），**不给买价锚** |
| 禁区档 | T3 / T4 / T8 无催化 | 归档禁区清单，防未来误入——负产出同样有价值 |

### 4.2 击球锚生成规范

- 收息类 = 股息率锚 + 穿透率（保守口径）；
- 资产型（T7）= PB 锚（按重估后净资产）；
- 修复型（T5/T6）= 正常化 PE 锚（剔除一次性后的利润 × 合理倍数）；
- 每个锚必须含三要素：**触发价 + 触发条件 + 证伪条件**（证伪条件触发即撤锚，不等价格）。

### 4.3 与关注池衔接

- 候选属关注池**空白行业** → 按扩池纪律入池（必须带锚）；
- 候选行业**已有覆盖** → 仅作对照参考，不重复入池。

### 4.4 零候选处理与仓位边界

- 若猎物档为零 → 正式结论="当前无错杀"，转**月度触发器监测**：每月重跑第 1 步分位初筛，新入池者触发个体判别；
- 本计划只产出候选与锚，**仓位决策走既有体系**（阶梯/红线框架），不在本计划范围内。

## 六、已知盲区（诚实清单）

1. **初筛漏斗型偏差**：会漏掉"横盘多年一直便宜"型（无回撤、不触发错杀特征）——股息率 ≥4% 条件部分兜底，但不完全；
2. **"深跌"假阳性**：粗筛已自证"跌得多 ≠ 错杀"（华菱钢铁/长安汽车），第 3 步弃用深跌评分是针对性修正，但"超跌系数"本身仍是辅助指标而非充分证据；
3. **T5 vs T4 的事前不可全分**：利空"一次性还是永久"常需事后验证——用证伪问题清单 + 触发器跟踪缓解，不承诺消除；
4. **样本覆盖不保证穷尽**：问财接口截断是硬约束，分行业重扫可缓解；
5. **叙事时点风险**："老登股错杀"叙事自 2023-24 流行至今，防御轮动已发生一年以上，部分标的的"错杀"可能已被修复——这正是必须用 10 年分位而非绝对值复核的原因，也是对视频论断最大的保留。
