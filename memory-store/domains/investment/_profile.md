# 投资领域画像

## 概况
用户25岁，总资产约116万，采用极端保守的资金隔离策略。投资5年，累计盈利约12万，主要在近两年牛市中获得。正在从"保本防守"向"学习进攻"过渡。

## 关键事实
- 总资产116万，106万主力资金配置短融ETF、国债ETF、十年国债ETF，10万进攻账户做弹性交易
- 风险偏好保守：牛市末端守利润，等熊市回调后100万分批布局，目标下一轮牛市翻倍
- 当前进攻账户持仓：分众传媒、双低可转债（月频，20只，仓位50%）
- 已清仓：海螺水泥、老板电器、恒生互联、华利集团（观察中）
- 投资心理：有纪律但偏僵化，需警惕"过度保守"和"牛市末端判断错误"的风险
- 用户明确拒绝短线投机，但存在"想参与市场"和"不知买什么进攻仓位"的矛盾
