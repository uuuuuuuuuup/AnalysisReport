# 方法论与常见误区

本文件是穿透叙事框架的底层方法论红线。社会科学研究难以控制变量，同一现象常有多种"都能自圆其说但推论截然相反"的解释，故方法论比结论更重要。SKILL.md"方法论红线"与第三步"评估叙事变化可能性"的详细依据。

## 一、用统一框架解释尽可能多的现象

**核心原则**：解释范围最广的框架往往预测能力最强。切忌为细分场景量身定做框架，否则陷入过度拟合与循环论证。

### 1.1 地心说类比

地心说被日心说取代，不是因为日心说理论本身更优——日心说刚提出时解释力度远不如地心说。地心说经近2000年发展（均轮套本轮，实质是傅里叶级数展开），可近乎完美解释内太阳系行星运动。真正冲击来自观测技术进步：发现更多天体后，地心说每个天体所需本轮数不同，缺乏预测能力。

### 1.2 投资中的"打补丁"

给原有理论不停打补丁或无限细分场景（如先分成长/周期/价值，再从成长细分大盘/周期/景气成长），固然提高解释力，但意义有限。贴标签本身就是价值判断，再据此评估股票价值是循环论证，最后变成自说自话。

**本框架的态度**：用"空间叙事+拍卖机制"统一解释成长股、周期股、价值股，不做类别预设。

## 二、逻辑推理优于归纳总结

### 2.1 统计回归的五大假设

高斯-马尔可夫定理要求回归结果为BLUE（最佳线性无偏估计量）需满足5个经典假设，任一不满足都有误。最棘手的是：
- **样本有偏**（第二条）：几乎无解，只能靠逻辑分析+扩大样本量缓解
- **内生性**（第四条）：处理极复杂，计量经济学一半内容在和它斗争

以案例为出发的复盘及时间序列处理，稍不留神就成为幸存者偏差、样本选择偏误、自选择偏误、遗漏变量、因果倒置的错题集。A股时间跨度短、值得深度复盘的案例寥寥，想同时满足5大假设几乎不可能。

### 2.2 三圆模型

想象数据为三个圆：
- **最外圈**：所有理论可能性
- **中圈**：所有现实中出现的可观测样本
- **内圈**：研究选取的样本

理想模型中内圈代表中圈、中圈代表外圈。各类偏差：
- 幸存者偏差/样本选择偏误：内圈无法代表中圈
- 自选择偏误：中圈无法代表外圈
- 遗漏变量/因果倒置：外圈本身有问题

扩大样本量是样本无偏的必要不充分条件。我们生活在有限样本、有限时间的世界，可能轮不到大数定律登场，特异性和随机性是更重要的力量。

### 2.3 相关性不可传递

只有因果性可以传递，相关性不能。例如：爸爸和孩子有血缘关系（可通过任意强度显著性检验），孩子和妈妈也有血缘关系，但得不出爸爸和妈妈有血缘关系的结论。

流行研究范式的缺陷：先拟合证明A与B强相关、B与C强相关，观察到A拐点就认为C会变化。这是把相关性当因果性传递。

### 2.4 数据拟合的陷阱

仅凭数据本身无法判断未来是单边趋势还是均值回归。A、B变量走势吻合度高但近期背离，未来继续背离还是收敛？一切皆有可能。

**硬币示例**：连投5次硬币全是正面，下次正面概率多少？选项1（趋势力量，看多正面）、选项2（均值回归，押反面）、选项3（理论推导，各50%）——**都不选**。连投5次正面，首先应检验硬币是否均匀。

## 三、做反方观点的最佳辩手

### 3.1 证伪而非证实

寻找对自己观点有利的案例太容易（从"狭路相逢勇者胜"到"退一步海阔天空"都有）。借用显著性检验思想：不是直接论证假设正确，而是论证是否"有足够理由拒绝与所要结论相反的假设"。

### 3.2 显著性与样本量、方差

5%显著性水平下：
- 投10次硬币出现8次正面 → 不能认定不均匀（出现8次及以上同面的概率10.94%>5%）
- 投10000次硬币 → 正面>5098次或<4902次才认定不均匀（比例超51%即可）

能否拒绝原假设与样本数量、方差直接相关。方差越大越难拒绝。忽略样本量与方差谈概率无意义——很多直觉相关且看似相关的两组数据，都通不过显著性检验。

### 3.3 在投资中的应用

穷尽所有可能也无法反驳所持观点时，才接受它。投资成功与否本身是概率事件，存在大量"既不能证实也不能证伪"的观点，但讨论底层方法论时必须足够苛刻。

**实证**：申万一级行业PB与当年ROE散点图，无论横截面还是时间序列，PB与ROE都没有必然线性关系，连正相关都说不上。因为PB=ROE·PE，PE受天花板倍数影响，ROE不变但天花板预期下降则PB大降。PB-ROE框架只适用于业绩稳定的重资产行业，短期ROE不能代表稳态期ROE。

**实证**：申万一级行业PE与当年业绩增速散点图，直接证伪"PE与业绩增速正相关"。PE取决于天花板倍数与折现率——天花板不上修，增速越快距离天花板越近，PE反而越低。

## 四、贝叶斯回溯，不开后视镜

### 4.1 世界是概率事件

即便历史重来，相同起点未必走到相同终点。投10次硬币，参与者足够多就有人投出10次正面，但从中总结不出成功经验。

开后视镜两个问题：
1. 遗漏关键历史细节，将真实决策过程流程化、戏剧化
2. 严重高估预期收益率，给人选出牛股很容易的错觉

### 4.2 贝叶斯条件概率

预期实现需A和B同时成立时，实现概率 = P(A) × P(B|A)。大部分情况下A、B只是必要条件非充分条件，需将所有概率按贝叶斯方程乘起来。

**避免"福尔摩斯推票法"**：因为A所以B，因为B所以C……链条一长市场大概率不按剧本走。更有意义的研究是将贝叶斯链拓展为**贝叶斯网**——做好各种情况下的预案，计算每个节点的市场空间及改变叙事的信号，分析每个十字路口的可能性与实际抉择，而非仅增加逻辑的纵向深度。

### 4.3 叙事先行，超额收益区间短暂

业绩是股价支撑，但股价不跟业绩同步上涨，而是**叙事先行**，超额收益区间非常短暂且在时间轴上分布不均。超额收益区间就是贝叶斯条件概率发生变化的点。

复盘应找这些重要节点，还原当时决策流程。若叙事变化不能预期，超额收益是纯粹命运馈赠或承担风险的补偿；若能预期，就要分析需求决定因素的发展脉络、竞争格局演化、商业模式优劣等。

### 4.4 预期收益率的贝叶斯计算

假设全A出现翻倍股概率10%，某投资者识别翻倍股准确度80%（真翻倍股80%选出；非翻倍股20%误选，误选后跌30%）。认定某股为翻倍股时，真是翻倍股的概率：

> P(真|认) = (10%×80%) / (10%×80% + 90%×20%) = 30.77%

预期收益率 = 30.77%×100% + 69.23%×(−30%) = 10.0%。若证伪跌幅超30%，总收益可能为负。

**启示**：
1. 选出翻倍股的概率还取决于市场中本身翻倍股概率（池塘里有多少鱼）
2. 预期收益率还取决于选错后跌幅——预期越高的公司证伪后下行空间越大
3. 没有任何叙事的"躺平股"或红利低波策略长期收益率不错，因惩罚机制很轻

### 4.5 预期兑现度的惯性

实证：全A样本连续两年业绩兑现度（实际/年初一致预期）散点图拟合R²达0.56。
- 上年大幅低于预期的公司，下年大概率继续低于预期，"利空出尽"很难直接成利好
- 过去三年业绩从未达预期50%的公司，第四年突然超预期概率基本为零
- 持续大超预期（>50%）的公司，第四年大概率低于预期——持续超预期易导致预期失控

若公司业绩持续低于预期，很可能是商业模式根本缺陷，A股对这种深层次利空反应非常不充分。

## 五、复盘的标准动作

### 5.1 变换起始点对比指数

将个股累计涨跌幅与沪深300（或创业板指）对比，不断变换起始点位：
- 走势重合段 = 叙事兑现期（无超额收益，只能赚折现率）
- 走势分离段 = 叙事变化期（超额收益来源，可正可负）

### 5.2 五问框架

对每段叙事变化回答：
1. 之前的叙事是什么
2. 为什么旧叙事不对
3. 新叙事又是什么
4. 改变叙事的诱发因素是什么
5. 新叙事形成的标志是什么，超额收益什么时候结束

### 5.3 用DCF反算验证绝对值点位

股价最终涨到DCF算出的绝对值点位。用 `scripts/dcf_implied.py` 反算每段叙事变化起止时点的隐含终局利润L，验证叙事变化的估值含义。如隆基：
- 2017年7月前：市值隐含的天花板较低（单晶终局份额预期40%）
- 政策变化后单晶替代预期40%→100%，天花板提升2.5倍 → 市值应上一台阶
- 2017年11月真实市值顶，与反算的隐含天花板吻合
- 2021年11月真实市值顶，隐含天花板达到"10倍当前业绩"级别，与双碳叙事吻合

涨幅取决于涨之前的起点有多低（起点隐含L越低，上修空间越大）；涨多久取决于市场形成新一致预期所需时间（市场化供需变化一般较长，政策变化一般很短）。所有涨幅和持续时间的对标都是刻舟求剑。

## 六、常见误区清单

1. **把相关性当因果性**，尤其跨环节传递
2. **开后视镜**：用全年真实业绩增速解释全年涨幅（站在年初并不知道）
3. **景气度投资**：只看增速不看天花板，增速上修天花板不变时不涨
4. **贴标签**：先分成长/周期/价值再分别估值，是循环论证
5. **PE均值回归**：PE无稳定均值，天花板高度动态变化
6. **无风险利率下行利好权益**：长期数据不支持，风险溢价才是关键
7. **福尔摩斯推票法**：长逻辑链条，市场大概率不按剧本走
8. **忽略方差谈概率**：方差大时平均数拟合再好也通不过显著性检验
9. **把估值起伏归因为审美偏好/资金流向**：这些是估值结果而非原因
10. **为细分场景量身定做框架**：过度拟合，丧失预测能力
