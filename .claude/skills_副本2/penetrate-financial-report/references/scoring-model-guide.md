# 全A样本财务打分模型使用指南

> **v4.0 状态说明**：本指南自 v4.0 起降级为**可选参考**，不再用于报告生成。
> v4.0 已删除报告第四部分「全A样本分位数定位」，综合结论改为基于三张表深度分析的财务质量五维评估。
> 仅当用户**主动要求**进行全A样本对比时，才参考本指南使用财务打分模型.xlsx。常规穿透财报分析无需上传此文件。

## 〇、数据来源要求（v3.0 规则，v4.0 可选）

> v4.0 起本节为可选规则。仅当用户主动要求全A样本对比时适用。

1. **用户上传**：报告的「全A样本对比」部分所需数据，来自用户上传的「财务打分模型.xlsx」，**严禁从网络摘取**。内置 JSON 数据已废弃删除。
2. **未上传则不生成**：用户未上传或文件无效时，不生成全A样本对比部分（v4.0 常规分析本就无需此部分）。
3. **只从「输出」sheet 提取**：用户在「输出」sheet 的 B4 格填入公司简称，其余单元格由 Excel 公式自动生成。脚本 `scripts/financial_scoring.py` 只提取「输出」sheet 的数据（用 data_only=True 读取公式缓存值），不遍历年度/季度 sheet。
4. **缓存值检测**：若输出 sheet 公式未计算（文件从未被 Excel/WPS 打开保存），脚本会检测到缓存值缺失并提示用户用 Excel 打开文件、确认输出 sheet 数据正常显示后保存再重新上传。

## 一、模型概览

全A样本财务打分模型（剔除银行与非银金融）覆盖2015年至最新季度（2026Q1），包含44个sheet：
- **输出** sheet：输入公司简称即自动生成5大指标分析
- **年度数据** sheet（2015-2025）：全A样本年度财务数据，含分位数
- **季度数据** sheet（2016Q1-2026Q1）：全A样本季度财务数据，含单季度指标
- **wind预测** sheet：wind一致预期净利润数据

## 二、五大指标体系详解

### 指标1：应收款项周转率（对数）与毛利率

**定义**：应收款项周转率 = 营业收入 /（应收账款 + 应收款项融资 + 合同资产），取自然对数。

**经济含义**：
- 周转率越高 → 单位应收款创造收入越多 → 回款能力越强
- 与毛利率结合看：周转率与毛利率应同向变动（薄利多销 vs 厚利少销）
- **背离信号**：周转率下降 + 毛利率上升 = 可疑（放账换收入，或应收账款注水）

**分位数解读**：
- 取对数后分布更接近正态，分位数有意义
- <20%：回款能力极弱，需排查应收账款质量
- >80%：回款能力优秀

**典型异常案例**：
- 华讯方舟（000687）：应收账款周转率持续下降，毛利率维持，最终查实虚增应收账款
- 东方金钰（600086）：周转率极低，毛利率异常高，翡翠存货难以验证

### 指标2：（固定资产+无形资产）周转率

**定义**：（固定资产+无形资产）周转率 = 营业收入 /（固定资产 + 无形资产），取自然对数。

**经济含义**：
- 衡量再投资质量：单位生产性资产创造收入的能力
- 持续下降 → 再投资效率恶化 or 产能过剩 or 固定资产注水
- 上升 → 产能利用率提升 or 轻资产转型

**分位数解读**：
- <30%：再投资质量偏低，需关注产能利用率和在建工程转固节奏
- >70%：资产效率优秀

**典型异常案例**：
- 抚顺特钢：固定资产周转率持续下降，最终查实将成本藏进固定资产（虚增资产）

### 指标3：营运净资产（不含存货）/总资产

**定义**：营运净资产（不含存货）= 应收账款 + 应收款项融资 + 合同资产 + 预付款项 - 应付账款及票据 - 合同负债。

**经济含义**：
- 反映运营能力与产业链地位
- 负值 → 强势占款（占用上下游资金），产业链话语权强
- 正值且持续上升 → 被动被占用资金，话语权弱
- 不含存货：剔除存货波动影响，聚焦纯营运占款

**分位数解读**：
- 分位数越低越好（负值占比高 → 分位数低 → 优秀）
- <20%（负值大）：产业链地位强势
- >80%：营运资金压力大，被上下游占用

### 指标4：经营性现金流量净额/总资产

**定义**：经营性现金流量净额 / 总资产。

**经济含义**：
- 衡量现金流创造能力，是利润现金含金量的核心指标
- 权责发生制下的净利润可能注水，但经营性现金流难以伪造
- 持续低于净利润 → 利润水分大

**分位数解读**：
- <20%：现金流创造能力极弱，利润质量可疑
- >80%：现金流充裕，利润质量高

**注意**：季度数据有季节性，Q1-Q3的经营性现金流通常偏低（年末集中回款），必须同季度对比。

### 指标5：wind一致预期 vs 实际业绩

**定义**：比较历年所在时点（如年中）的wind一致预期净利润与最终实际归母净利润。

**经济含义**：
- 反映商业模式的可预测性与业绩稳定性
- 持续高估 → 商业模式不稳定 or 市场预期过高
- 持续低估 → 业绩超预期能力强（但也要看是否系统性低估）

**偏差解读**：
- 预测误差 =（实际 - 预期）/ |预期|
- 误差持续 > 30% → 预测性差，估值锚不稳
- 误差在 ±10% 以内 → 预测性好，商业模式稳定

## 三、"输出"sheet使用方法

### 输入

在"输出"sheet的B4单元格输入公司简称（如"宁德时代"），模型自动从各年度/季度sheet中VLOOKUP该公司数据。

### 输出结构

每个指标组包含4个模块（各约20行）：
1. **全A样本分布**：最新一期全A样本该指标的分布情况（直方图数据）
2. **全A样本年度中位数走势**：2015-最新年度中位数（及Q1/Q2/Q3季度中位数）
3. **目标公司历史走势**：该公司历年的指标值
4. **目标公司分位数走势**：该公司在全A样本中的分位数（年度+季度）

### 分位数计算方法

分位数 = 该公司在全A样本中的排名 / 有效样本数

- 有效样本 = 剔除空值和#N/A后的样本
- 周转率类指标：先取对数再计算分位数（消除右偏）
- 比率类指标（毛利率、营运资本占比、现金流/总资产）：直接计算分位数

## 四、使用脚本自动化（v3.0——只从输出sheet提取）

使用 `scripts/financial_scoring.py` 从用户上传的财务打分模型**「输出」sheet**提取数据（不遍历年度/季度 sheet，不从网络摘取）：

```bash
# 方式1：自动读取 B4 的公司简称（推荐）
python scripts/financial_scoring.py \
  --model "财务打分模型.xlsx" \
  --output "财务打分结果.json"

# 方式2：显式指定公司简称（优先级高于 B4）
python scripts/financial_scoring.py \
  --model "财务打分模型.xlsx" \
  --company "宁德时代" \
  --output "财务打分结果.json"
```

### 脚本执行流程

1. **文件校验**：确认首个 sheet 名为「输出」，B4 有公司简称。
2. **读取 B4**：获取公司简称（或用 --company 指定）。
3. **提取输出 sheet**：用 `data_only=True` 读取输出 sheet 全部单元格的公式缓存值。
4. **智能识别**：
   - 公司基本信息（代码/行业/上市时间）
   - 5大指标最新分位数汇总（最新年报 + 最新Q1）
   - 年度趋势（各指标的公司值/全A中位数/分位数，2015-最新）
   - 季度趋势（同季对比，2016Q1-最新Q1）
   - wind一致预期时间序列
5. **输出原始矩阵**：同时输出输出 sheet 的所有非空单元格（保留行列位置），作为数据完整性的 fallback。
6. **缓存值检测**：若数值型单元格过少，提示用户用 Excel 打开文件并保存。

### 输出 JSON 结构

```json
{
  "公司简称": "宁德时代",
  "分析时间": "...",
  "数据来源说明": "全部数据来自用户上传的财务打分模型.xlsx输出sheet...",
  "缓存值检测": {"有数值缓存": true, "数值型单元格数": 1234, ...},
  "公司基本信息": {"代码": "...", "一级行业": "...", ...},
  "五大指标最新分位数汇总": {"2025年报_指标1_...": 75.2, ...},
  "年度趋势": {"指标1": {"全A中位数": {...}, "分位数": {...}}, ...},
  "季度趋势": {"指标1": {"全A中位数": {...}, "分位数": {...}}, ...},
  "wind一致预期": {"2015Q1": ..., "2015A": ..., ...},
  "识别告警": [...],
  "输出sheet_原始矩阵": [[...], ...],
  "输出sheet_非空单元格": [[row, col, value], ...]
}
```

### 重要提示

- **公式缓存值**：openpyxl 的 `data_only=True` 只能读取上次用 Excel/WPS 打开并保存后的缓存值。若文件从未被打开，公式单元格值为 None。脚本会检测此情况并提示。
- **未上传文件**：若用户未上传「财务打分模型.xlsx」，脚本退出并提示上传，报告不生成全A样本对比部分。
- **公司简称匹配**：B4 填入的公司简称必须与输出 sheet 中 VLOOKUP 引用的底层 sheet 的 B 列公司简称完全一致。

## 五、注意事项

1. **样本范围**：全A样本已剔除银行与非银金融行业（报表结构差异大）。
2. **季度可比性**：季度数据有季节性，必须同季度对比（Q1比Q1），不可跨季度比较。
3. **负值处理**：ROE等指标出现负值时，分位数计算需特殊处理（负值通常排在最末）。
4. **新上市公司**：上市不足1年的公司，年度数据可能缺失，仅有季度数据。
5. **港股公司**：打分模型仅含A股样本，港股公司可参考A股同行业分位数，但需说明口径差异。
6. **对数变换**：周转率类指标取自然对数后计算分位数。若周转率为负或零，对数无意义，分位数设为0。
