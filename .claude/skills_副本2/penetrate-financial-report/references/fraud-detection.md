# 财务舞弊识别方法

## 一、为什么能造假：权责发生制的漏洞

利润表基于权责发生制，记录的是企业"应该"赚多少钱，而非实际收到多少钱。**没有收到的钱也可以算利润，实际支付的钱也可以不进利润表**——这是所有利润表操纵的根源。

根据会计恒等式：资产 = 负债 + 所有者权益，可得：
- **虚增利润归根结底都是虚增资产**（或将负债藏起）
- **虚减成本归根结底也是虚增资产**

因此，识别造假的核心是：**找出资产负债表中藏水分的科目**。

---

## 二、造假动机

1. 业绩诉求（融资、市值管理、股权质押）
2. 规避退市（连续亏损ST/退市）
3. 配合减持（大股东/高管套现）
4. 满足业绩对赌（并购承诺）

---

## 三、收入舞弊：三步循环法

### 初级版本：虚增应收账款

```
Step1: 虚构销售合同、出货凭证 → 虚增营业收入
Step2: 虚增应收账款（资产负债表配平）
```

**识别信号**：
- 应收账款周转率持续下降
- 应收账款增速 >> 营业收入增速
- 经营性现金流/净利润持续偏低
- 毛利率异常高于行业

**案例**：华讯方舟（000687）——应收账款周转率持续下降，最终查实虚增利润1.5亿元。

### 升级版本：三步循环法（有现金流配合）

```
Step1: 虚增收入 → 虚增应收账款
Step2: 虚增成本/费用 → 虚增存货/预付/固定资产（将利润藏进其他资产）
Step3: 虚增现金流 → 通过关联方走款（经营性现金流看起来正常）
```

**识别信号**：
- 经营性现金流"看起来正常"但投资活动现金流异常流出
- 存货/预付款项/在建工程异常增长
- 应收账款与应付账款同步增长（走款闭环）
- 毛利率与周转率背离

**案例**：东方金钰（600086）——虚增翡翠存货，存货周转极低，最终查实三步循环造假。

### 高级版本：真真假假

与真实客户、供应商配合造假，比"无中生有"更难识别：
- 真实交易但价格虚高（关联方伪装成独立第三方）
- 真实现金流但循环走款（A→B→C→A）
- 识别关键：穿透股权关系，找出隐性关联方

## 四、成本舞弊：收入舞弊的反向操作

```
Step1: 少计成本 → 虚增利润
Step2: 虚增资产 → 资产负债表配平
Step3: 虚增现金流（可选）
```

### 常见手法

| 手法 | 藏入科目 | 识别信号 |
|------|----------|----------|
| 少计原材料成本 | 存货 | 存货周转率异常下降 |
| 少计人工成本 | 应付职工薪酬 | 应付薪酬异常增加 |
| 少计折旧 | 固定资产 | 固定资产周转率下降+折旧率下降 |
| 资本化费用 | 在建工程/无形资产/开发支出 | 资本化率异常高 |
| 少计财务费用 | 在建工程（利息资本化） | 在建工程长期不转固 |

**案例**：抚顺特钢（600399）——将成本藏进固定资产，固定资产周转率持续下降，最终查实2010-2016年虚增利润19亿元。

## 五、舞弊识别红旗清单

### 资产负债表红旗

| 科目 | 红旗信号 | 严重程度 |
|------|----------|----------|
| 货币资金 | 存贷双高（大额货币资金+大额有息负债） | ⭐⭐⭐⭐⭐ |
| 应收账款 | 周转率持续下降+增速远超营收 | ⭐⭐⭐⭐ |
| 存货 | 周转率异常+跌价准备计提不足 | ⭐⭐⭐⭐ |
| 其他应收款 | 金额过大+关联方往来 | ⭐⭐⭐⭐⭐ |
| 在建工程 | 长期不转固+工程进度停滞 | ⭐⭐⭐⭐ |
| 商誉 | 占净资产>50%+并购业绩对赌到期 | ⭐⭐⭐ |
| 投资性房地产 | 公允价值持续上升+与市场背离 | ⭐⭐⭐ |
| 长期股权投资 | 投资收益>分红现金流 | ⭐⭐⭐⭐ |

### 利润表红旗

| 科目 | 红旗信号 | 严重程度 |
|------|----------|----------|
| 营业收入 | 增速与行业背离+年末突击确认 | ⭐⭐⭐⭐ |
| 毛利率 | 远高于同行+无合理原因 | ⭐⭐⭐⭐⭐ |
| 销售费用 | 销售费用率持续下降+营收增长 | ⭐⭐⭐ |
| 研发费用 | 资本化率异常高 | ⭐⭐⭐⭐ |
| 减值损失 | 大幅波动（大洗澡/隐藏利润） | ⭐⭐⭐⭐ |
| 非经常性损益 | 占归母净利润>50% | ⭐⭐⭐ |
| 所得税 | 有效税率远低于法定（无合理优惠） | ⭐⭐⭐ |

### 现金流量表红旗

| 信号 | 说明 | 严重程度 |
|------|------|----------|
| 经营性现金流持续为负 | 业务模式不可持续 | ⭐⭐⭐⭐⭐ |
| 经营性现金流/净利润<50% | 利润水分大 | ⭐⭐⭐⭐ |
| 投资活动现金流持续大额流出 | 在建工程/并购异常 | ⭐⭐⭐ |
| 筹资活动现金流大额流入+经营流出 | 靠融资维持 | ⭐⭐⭐⭐ |
| 现金流画像"---"或"-++" | 危险信号 | ⭐⭐⭐⭐⭐ |

### 其他红旗

- 频繁更换审计师/会计师事务所
- 审计意见非标准无保留意见
- 关联交易频繁且金额大
- 大股东股权质押比例高
- 管理层频繁变动
- 定期报告频繁更正

## 六、舞弊识别的系统化方法

### 第一步：全局扫描

对全A样本分位数中排名末尾（<20%）的指标重点排查：
- 指标1（应收周转率）低分位 → 收入舞弊嫌疑
- 指标2（固定资产周转率）低分位 → 成本舞弊嫌疑
- 指标4（经营现金流/总资产）低分位 → 利润水分嫌疑

### 第二步：三表勾稽验证

- 营收增长 → 应收增长 vs 经营现金流增长？
- 利润增长 → 未分配利润增长 vs 资产增长？
- 资本开支 → 在建工程/固定资产增长？

### 第三步：同业对比

- 毛利率与同行业偏离>10个百分点 → 异常
- 费用率与同行业偏离>5个百分点 → 异常
- 周转率与同行业偏离>50% → 异常

### 第四步：趋势分析

- 指标持续恶化 → 基本面恶化 or 造假暴露前兆
- 指标突然改善 → 业绩转折 or 造假升级
- 季度数据波动异常 → 关注Q4 vs Q1-Q3（年末调节）

### 第五步：定性判断

- 管理层动机：是否有强烈的业绩诉求？
- 治理结构：一股独大？独立董事是否独立？
- 信息披露：是否充分、及时、一致？
- 市场反应：机构投资者是否用脚投票？

---

## 七、合理怀疑的原则

作为二级市场投资者，我们**没有能力也没有必要**证实造假，只需合理怀疑：
1. 多项指标异常、彼此不能自圆其说 → 用脚投票
2. 不需要找到造假的"铁证"，只需判断风险收益比不利
3. 识别造假的目的不是做空获利（A股做空受限），而是避免踩雷
4. **有罪推定**：当红旗足够多时，默认有问题，除非公司能自证清白

> 识别财务造假是一项必备技能。一切估值方法的前提是报表真实，万一报表本身有问题，再精妙的估值模型都是空中楼阁。
