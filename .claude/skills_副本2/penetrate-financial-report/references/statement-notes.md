# 报表科目注释：IS/BS/CF 完整科目说明

本文件列示A股标准化财务报表的全部科目（源自Wind口径），并标注每个科目的分析要点。港股报表科目略有差异，需按A股口径调整后对比。

---

## 一、利润表（Income Statement, IS）

### 收入与成本

| 行 | 科目 | 说明与分析要点 |
|----|------|---------------|
| 1 | 营业总收入 | 含营业收入和其他类金融业务收入（金融类）。非金融公司通常=营业收入 |
| 2 | 营业收入 | **核心科目**。关注：增速、季节性、分产品/分地区结构。收现比=销售收现/营收 |
| 3 | 其他类金融业务收入 | 金融类业务收入，非金融公司通常为0 |
| 4 | 营业总成本 | 营业成本+税金及附加+四费+其他业务成本 |
| 5 | 营业成本 | **核心科目**。毛利率=(营收-营业成本)/营收。关注成本结构（原材料/人工/制造费用） |
| 6 | 税金及附加 | 消费税、城建税等，与营收正相关。异常波动需关注 |
| 7 | 销售费用 | 关注销售费用率变化。下降可能是渠道优化，也可能是压货 |
| 8 | 管理费用 | 关注管理费用率。股权激励费用通常计入此处 |
| 9 | 研发费用 | 2018年后单列。关注资本化比例（资本化率高=利润调节嫌疑） |
| 10 | 财务费用 | 利息费用-利息收入+汇兑损益+手续费。有息负债的影子 |
| 11 | 利息费用 | 财务费用子项。与有息负债规模匹配 |
| 12 | 利息收入 | 财务费用抵减项。货币资金充裕时的利息收入 |
| 13 | 其他业务成本(金融类) | 金融类业务成本 |

### 其他收益与投资收益

| 行 | 科目 | 说明与分析要点 |
|----|------|---------------|
| 14 | 其他收益 | **政府补助为主**。非经常性，需扣非看待。持续大额=对补贴依赖 |
| 15 | 投资净收益 | 对联营合营企业投资收益+金融资产投资收益+处置收益 |
| 16 | 对联营企业和合营企业的投资收益 | 权益法核算的长期股权投资收益。关注是否为关联方输血 |
| 17 | 以摊余成本计量的金融资产终止确认收益 | 金融资产处置收益 |
| 18 | 净敞口套期收益 | 套期保值业务收益，通常较小 |
| 19 | 公允价值变动净收益 | 交易性金融资产/负债公允价值变动。**非付现**，影响利润但不影响现金流 |
| 20 | 资产减值损失 | 存货跌价+固定资产减值+无形资产减值+商誉减值等。大幅波动=利润调节 |
| 21 | 信用减值损失 | 应收账款坏账+其他应收款坏账。大幅波动=利润调节 |
| 22 | 资产处置收益 | 处置非流动资产收益。非经常性 |
| 23 | 汇兑净收益 | 汇率变动影响。出海公司需关注 |

| 40 | 少数股东损益 | 子公司非全资部分归属少数股东的利润 |
| 41 | 归属于母公司所有者的净利润 | **核心指标**。净利润-少数股东损益。市场关注的"业绩" |

## 二、资产负债表（Balance Sheet, BS）

### 流动资产

| 科目 | 说明与分析要点 |
|------|---------------|
| 货币资金 | **核心科目**。关注受限资金比例（保证金/定期存款）。短期借款>>货币资金=短债长投风险 |
| 交易性金融资产 | 短期理财+股票债券投资。公允价值变动进损益 |
| 衍生金融资产 | 期货/期权等。通常较小 |
| 应收票据及应收账款 | 银行承兑汇票（近乎现金）+ 商业承兑汇票 + 应收账款 |
| 应收票据 | 银承 vs 商承比例。银承占比高=回款质量好 |
| 应收账款 | **核心科目**。周转率、账龄、坏账计提。应收增速>营收增速=放账换收入 |
| 应收款项融资 | 2019年后新增。持有收款的合同现金流+出售目的的应收款项 |
| 预付款项 | 对上游预付=弱势。预付给关联方=资金占用嫌疑 |
| 其他应收款(合计) | 应收股利+应收利息+其他应收款。其他应收款过大=关联方占款嫌疑 |
| 应收股利 | 已宣告未发放的股利 |
| 应收利息 | 已产生未收到的利息 |
| 其他应收款 | **关注异常**。非经营性往来款、押金保证金。过大=资金占用 |
| 买入返售金融资产 | 金融类业务资产 |
| 存货 | **核心科目**。原材料+在产品+产成品。周转率+跌价准备。异常堆积=滞销或虚增 |
| 消耗性生物资产 | 农林牧渔类存货，如生猪、林木。审计难度大（盘点困难） |
| 合同资产 | 新收入准则新增。附条件的收款权（需履行剩余义务）。与应收账款区分 |
| 划分为持有待售的资产 | 拟出售的非流动资产 |
| 一年内到期的非流动资产 | 一年内到期的长期应收款、长期待摊费用等 |
| 待摊费用 | 已支付未摊销的费用。过大=推迟费用化 |
| 其他流动资产 | 理财产品、预缴税款等。关注结构 |
| 流动资产差额 | Wind平衡项 |
| 流动资产合计 | |

### 非流动资产

|------|---------------|

| 其他债权投资 | 公允价值计量但变动进其他综合收益的债权 |

| 其他非流动金融资产 | 除上述外的长期金融资产 |

| 生产性生物资产 | 农林牧渔类固定资产（如奶牛、经济林） |

## 四、科目间勾稽关系速查

1. **货币资金**：期初+三类CF净额=期末
2. **未分配利润**：期初+归母净利润-分红（减盈余公积计提）=期末
3. **固定资产**：期初+在建工程转固+购建-折旧-处置-减值=期末
4. **应收账款**：期初+营业收入(赊销)-收回-坏账核销=期末
5. **存货**：期初+生产入库-营业成本结转-跌价=期末
6. **应付账款**：期初+采购(赊购)-支付=期末
7. **递延所得税**：资产端+负债端变动=所得税费用与应交所得税的差异

数据单位：亿元，CNY。数据来源：Wind。
