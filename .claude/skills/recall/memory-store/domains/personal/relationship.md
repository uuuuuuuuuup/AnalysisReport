## 礼物与付出的互动模式
- **事实**: 2026-09-13 通话中，女友明确说出「你老拒绝我，我都不知道给你买什么了」「我感觉你说什么都会被拒绝」「你拒绝我之后，我就会减少这种想给你买东西的心情」（录音原话 L183–L219）。她多次主动提出送礼——皮带/腰带、手表、耳机、墨镜、手机分摊——均被用户以"我有""还能用""换电池就行"拒绝；游泳课 1000 元转账被拒收，年卡"她出一半 1500"用户答应了但未办。她的自我诊断（L242–247）：「你根本就不需要东西……必需品你是有的，有了这个基础就不会再想买更好的或替换的，觉得有一个够用就行了」——用户确认属实。
- **用户方送出/承诺**: 女友生日时添 1000 元换金饰（金戒指+金耳钉）；2026-09-13 送包 2600 元（股市利润）；此前答应过的 2000 元；另用利润买约 3000–4000 元；十一旅行基金 4000 元。
- **用户真实诉求**: 不是要更贵的礼物，是要"她自己的判断"——即体验一次**被认真挑选**（对照她给朋友不点菜、自己挑的 500 元香水挂件）。
- **两道门（2026-09-14 补全）**: ① 用户拒收 → 她收手（录音已验证）；② 更隐蔽的一道——**用户每次开口"我想要X"，就把礼物降级成订单**（200 多元按摩仪 = 用户点名 + 她执行）。订单只有交付、没有挑选。只解开门①（接住她的提议）不够，必须同时解开门②。
- **修法（三向）**: ① 接一件她主动提议、用户未点名要的东西——手机"用户出可接受价位、她补差"最现成，游泳年卡"她出一半 1500"是已达成的约定（办掉即兑现，性质不算礼物）；② 她 11 月底生日，用户主动挑包/饰品（品类偏好她已在同一通话 L144–150 说明："包和饰品会给不一样的感觉，日用品、护肤品就没有"），不要再问"想要啥"——那是复制用户抱怨过的结构；③ **最关键的一步：用户自己下一次生日不要点菜**，她问就说"你挑"。②是练给她看，③才是真正拆掉订单结构。
- **时机判断**: 用户顾虑"刚送完包就提，像索取"——不成立：那句话是**回应**她先说的「少拒绝我」，用户是回应方不是索取方。但无需主动开一场谈话，用天然窗口（她生日 / 用户自己生日）即可，不要自己造谈话。
- **来源**: Claude 对话 2026-09-14（微信录音原文 SRT + 用户自述）
- **可信度**: 高（含录音原话）；"订单结构"为分析归纳，中高

## 沟通模式：间接表达（跨议题）
- **事实**: 同一天内三个议题同一形状——礼物议题上用拒绝代替直说、期待对方读懂（见 [[礼物与付出的互动模式]]）；协议议题上用一条视频递话、期待从对方反应读出答案（见 [[婚前协议话题]]）；礼物不平衡的感受靠观察（她给朋友的香水挂件 500 元）而非发问，然后自行不适。
- **结论**: 不直接表达 → 拿二手证据 → 自行揣摩焦虑。该模式在投资上是长处（不动声色、靠证据链），在亲密关系中是主要漏点。
- **延伸**: 用户会把"表达自己的需求"体验为"向对方索取"（"现在提这个像是在和她索取"），与拒收游泳课 1000 元转账（"不好意思收"）同源——这是不直接表达的动机层，不只是方法层。
- **来源**: Claude 对话 2026-09-14 归纳
- **可信度**: 中高（基于两轮对话）
- **变更记录**:
  - 2026-09-21: 第三次复现（[[王俊凯演唱会冲突（2026-09-20）]]）。但**本次漏点变形**：以往是"不直接表达"（漏点在前半段），本次用户**是直接表达的**——直接说了"我的爱是排他的""我觉得异性就是不行"。漏点转移到后半段：他直接提的是一个**要求对方改写感受**的诉求。故该模式的准确表述应拆为两段：①"不直接表达→拿二手证据→自行揣摩"（前两次）；②"直接表达，但表达的是对对方感受的要求，而非自己的需求"（本次）。②与既有的"把表达需求体验为索取"（见本条延伸）是两套不同的失效方式，不可混为一谈。

## 她有选择地停止争论（2026-09 前后）
- **事实**: 因最近吵过几次架，女友表示"有的事情不想和我争了"。2026-09-13 通话中可观察到具体范围：她在**消费习惯类议题**上说完观点即让位（耳机换不换「那你就接着省吧」L346–349、正品鞋服、要不要换手机），且同一场对多个议题都是"说完理由就不推"的风格；但在**关系层面的议题上仍直接表达**（「少拒绝我」「你老拒绝我，我都不知道给你买什么了」L215–219）。
- **判断**: 是**让位**不是妥协——她的观点未改，只是从"劝"退到"随你"；用户的解读"她妥协了"不准确。该让位是**选择性的**、不是全局关闭，比全面沉默健康。目前仍处于早期阶段（停止争论），尚未发展到停止表达、停止在意。
- **风险路径**: 停止争论 → 停止表达 → 停止在意。**早期警报信号**：① 她开始不说自己想要什么（已有边缘迹象：她对自己 11 月底生日答"现在没有想要的东西，到时候看吧"）；② 让位对象从"用户怎么花钱"扩到"她自己的事"。
- **应对**: 判断标准是"这件事对我重要吗"——不重要的事可以顺势让她让；重要的事**不接受让位**，推回去（「这个别迁就我，你怎么想的？」）。核心提醒：**"她不想争了"长得和"同意"一模一样**，而用户习惯把对方的沉默收下当同意。

- **可信度**: 高（她的原话由用户转述）；范围划分为录音推断，中高
- **变更记录**:

## 王俊凯演唱会冲突（2026-09-20）
- **事实**: 女友赴王俊凯演唱会，行前曾向用户说明两个理由——① 现场唱得好/喜欢现场氛围、② 弥补高中时的梦想；用户当时表示认同。2026-09-20 她发朋友圈，配演唱会照片 + 一句歌词 "Cuz' nobody can replace You"。用户由该歌词推断她对王俊凯的感情不是"欣赏+圆梦"而是爱慕，当场爆发并升级到分手：用户表态"我的爱是排他的""我觉得异性就是不行""你有男朋友为什么还欣赏其他男性呢"，将她设为"仅聊天"，并称"我不想我的女朋友和我在一起还三心二意"。女方回应：这是纯欣赏、不涉男女之情；"我看任何一个歌手的演唱会，我都会发一条朋友圈去记录"；"这只是一句歌词而已，而且这句歌词也不一定是指代他"；并提出承担退票费用（"不够的话我再补给你"）。
