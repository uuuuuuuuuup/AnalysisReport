# 投资研究框架

## 苏垦农发核心逻辑
- **事实**: 用户持有苏垦农发（601952）作为进攻账户核心仓位。核心逻辑：136万亩自有耕地（江苏，一年两熟/三熟），种水稻+小麦（主粮压舱石），30年长租约（2011-2041）。与北大荒对比：北大荒是"地主收租"模式（1296万亩、高分红但粮价弹性低），苏垦农发是"农民种地"模式（自种比例>80%，粮价弹性最大）。用户选择苏垦农发而非北大荒，因匹配其"博弈粮价周期从底部反转"的进攻目标。
- **来源**: DeepSeek 对话 2026-05-05，巴菲特视角深度分析
- **可信度**: 高
- **变更记录**:
  - 2026-08-16: 用户已不再持有该标的（事件驱动买入未赚钱），并要求此后不再主动提及。本条仅作历史存档

## 粮食安全投资框架
- **事实**: 用户建立了粮食安全投资逻辑：①中国大豆对外依存度>80%（真正软肋），大豆进口约1.08亿吨；②口粮（稻谷、小麦）自给率>98%，绝对安全；③玉米进口依赖度已降至2.2%；④食用油自给率仅31%。苏垦农发种植稻麦，是主粮安全标的，非大豆博弈工具。博弈大豆涨价应看北大荒、大北农等。
- **来源**: DeepSeek 对话 2026-05-05
- **可信度**: 中（基于对话时数据）

## 医药板块投资框架（2026中报体检沉淀）
- **事实**: 四条可复用的阅读规则：
  ① **License-out财报铁律**——首付款/里程碑收入是一次性损益（泽璟制药2026H1净利+979%，其中55%营收为首付款），必须以"剔除授权收入后的产品销售增速/经调整归母增速"判断真实增长，区分泽璟式撑报表与先声式真增长；
  ② **CXO是独立于国内内需的海外现金流资产**——本轮确认行业从"修复"进入"兑现"；药明康德在手订单增速（2026H1 +25.2%）可作CXO景气度先行指标持续跟踪；
  ③ **消费医疗（医美/重组胶原）和国内仿制药/OTC跟随宏观终端冷热**，无独立周期——爱美客三连降、济川下滑均由此来；
  ④ **器械集采出清后是"填坑恢复"非反转**——心脉模式（扣非转正+现金流极佳+收入贴地），熊市里安全边际结构好但仍缺收入弹性。
- **来源**: Claude 扫描15只医药股2026中报总结，对话 2026-08-27
- **可信度**: 中高（基于一轮完整中报截面，待后续财报季验证）
- 变更记录:
  - 2026-08-27: 基于医药池第1轮体检创建本条目

## 行业周期底部的估值阅读法（2026-09 网安行业筛选沉淀）
- **事实**: 三条可复用的行业级阅读规则：
  ① **「PE高分位 + PS低分位」= 利润周期底，不是估值泡沫**——网络安全板块 PE(TTM) 142.9x（历史95.5分位）而 PS(TTM) 仅2.16x（历史2.4分位），同一板块两种口径反向极端，是分母（利润）塌方而非分子（市值）虚高。遇此组合不得用单一 PE 下"太贵"结论，真问题是收入端何时转正。反之「PE低分位 + PS高分位」才是真泡沫。
  ② **区分"行业回暖"与"公司降本"**——行业收入连续12季负增长时，个别公司净利大增往往来自费用压降/减值基数/公允价值变动。判据：**剔除并表与非经常项后看扣非增速**；若扣非与归母背离超30个百分点，先查一次性项（奇安信26H1归母减亏46.58% vs 扣非仅减亏1.94%，差额来自3.70亿公允价值变动）。
  ③ **行业分散阶段看"唯一性"而非"排名"**——集中度低（网安硬件前三合计仅32.2%）的行业里，"规模第一"不等于"质量第一"。用三个"唯一"定位地图：唯一稳定盈利者、唯一真实拐点者、唯一过硬指标者。
- **补充口径坑**：A股总股本不可用资产负债表 `PaidInCapital`（含未转股部分会低估），须用 `profile` 的 `regCapital`；东财系接口"营收同比/净利同比"字段系统性失真，一律自算。
- **来源**: 《网络安全行业漏斗筛选报告》2026-09-11（reports/网络安全-funnel-20260911.md），Claude 对话 2026-09-11
- **可信度**: 中高（基于一轮完整行业截面 + 跨市场估值锚，待更多行业复验）
- 变更记录:
  - 2026-09-11: 基于网络安全行业漏斗筛选创建本条目
