# 公司检查台账

> **用途**：关注池全量标的的检查总账——一眼看出「谁查过、谁没查、在等什么」。一张表到底 + 文字记录区，不再设分表/待检名单/未纳入小节。
> **列规则**：① 检查日省略年份（默认2026），跨年写全年份；② 报告期缩写 26H1 / 26Q1 / FY25，带 `*` = 垫底数据（Q1或上一年报顶替），正式披露后须复扫；③ 同一标的多行堆叠 = 多轮或多类型检查，每类各一行。
> **标签**：🚨雷 / ⚠️瑕疵 / ➡️平稳 / ✅改善 / ⬜未检查（❓保留备用：分析过但存在硬欠账）。
> **类型**：体检 = 财报体检 / 六关 = investment-checklist / 收息 = income-investment / 深研 = investment-research / 估值 = 估值情景判断（对话分析）。后四种 skill 只往表里写**一行结论摘要**（含报告文件路径），完整内容留在各自的报告文件里，不搬运进本记忆。
> **数据源与口径坑**：ai-tools MCP（东方财富系）。① 港股库内"营业总收入"比公告口径偏高2~3.4%；② 库内"营收同比"字段有严重失真案例（药明公告+38.9% vs 库内+0.9%等）→ 数字落地前一律与公告原文核对。
> **排序**：按标签坏好序（🚨→✅→⚠️→➡️→⬜），新轮次结果就地更新原行或在后方追加新行。

### 第1轮板块结论
- **全局**：「上游热终端冷」，消费β不配只做结构α。
- **医药**：四条阅读规则已沉淀至 [[investment-logic]]——License-out剔除授权收入看真实增长；CXO是独立于内需的海外现金流资产，药明在手订单增速作先行指标；消费医疗/OTC跟随终端冷热；器械集采出清后是"填坑恢复"非反转。
- **公用/能源**：①红利防御在本轮反弹市失效（上证区间+3.7%，长电-2.8%/神华+2%/海螺+1.4%全线跑输）——机会成本正是等熊市策略的门票钱，绝对回撤<7%不构成动摇框架的理由；②对商品价差的免疫排序：神华一体化 > 燃气顺价 > 电力转型者（华润FCF为负）；③新增雷金禾实业、海螺水泥加速恶化。
