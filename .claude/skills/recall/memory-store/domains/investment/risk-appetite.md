# 风险偏好与策略

## 核心策略：资金隔离
- **事实**: 用户执行严格的资金隔离：100万主力资金只在熊市充分回调后分批进场（目标下一轮牛市翻倍），10万进攻账户用于验证逻辑和积累经验。大账户和小账户严格分离，不允许因小账户逻辑"确定"就调动大账户。
- **来源**: DeepSeek 对话 2026-05-04 ~ 2026-08，用户自述
- **可信度**: 高

## 风险偏好：保守但有矛盾
- **事实**: 用户风险偏好保守——牛市末端主动踩刹车、守利润不激进。但存在矛盾心理：大部分现金持有中"感觉参与不到市场"、"不知买什么进攻仓位"、羡慕别人赚钱（如群里锂矿赚50万）但明确不会做满仓投机。有"无聊感"但已接受不做短线。
- **来源**: DeepSeek 对话 2026-05-04 ~ 2026-08
- **可信度**: 高

## 大账户使用边界
- **事实**: 用户多次试探大账户使用边界（苏垦农发、五粮液、ST人福、山东黄金），均被巴菲特视角否决。唯一讨论过的例外：在2.4%利率买30年国债、2.1%卖出做波段，但未被鼓励。核心纪律：大账户只等熊市暴风雨。
- **来源**: DeepSeek 对话 2026-05-05 ~ 2026-08
- **可信度**: 高

## 对"等熊市"策略的疑虑
- **事实**: 用户25岁，曾质疑"100万等风暴，我能经历几次？我能等到吗？会翻倍吗？"反映出对长期等待策略的焦虑。同时也担心"会不会现在不是牛市后期"导致误判。
- **来源**: DeepSeek 对话 2026-08
- **可信度**: 高

## 投资业绩
- **事实**: 投资5年累计盈利约12万（非最初说的9万），主要来自近两年牛市。从亏损5万做到打平再赚9万利润。
- **来源**: DeepSeek 对话 2026-05-04，2026-08更新
- **可信度**: 高
- **变更记录**:
  - 2026-08: 用户更正盈利为12万，非9万
