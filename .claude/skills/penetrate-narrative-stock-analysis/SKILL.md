# 穿透叙事股票分析框架

## 通用化说明（v3.0 新增）

本 skill 已支持任意 A 股公司分析。运行方式：

```bash
cd .claude/skills/penetrate-narrative-stock-analysis/scripts
python generate_report.py --company 中际旭创 --code 300308.SZ
```

输出：默认 `reports/中际旭创/中际旭创_穿透叙事分析报告.md` + 图表 PNG。
可选 `--format docx` 或 `--format html`。

数据源优先级：优先使用项目内 skill `mx-data` / `gtht-lingxi-unified` 获取市场数据与一致预期，
其次通过 AI-Tools 获取，必要时再交叉 Wind / 公开研报 / Alpha 派调研纪要。

当被 `penetrate-financial-report` 调用时，进入 `financial-support` 模式，只返回 DCF 结果和关键叙事结论。

## 框架总览

本框架源自DCF第一性原理的逻辑推演，核心命题是：**超额收益只能来自叙事变化**，兑现叙事不产生超额收益。所谓"叙事"即市场对公司终局（天花板高度）的共识，而非过程（增速）。

A股市场同时存在两套定价机制：

1. **空间叙事（锚）**——DCF反算，用当前市值+前3年一致预期业绩，反推股价隐含的终局利润L（天花板高度），与公司能够触达的理论业绩空间对照判断高估/低估。折现率取8%、10%、12%三档给出区间。这是客观的绝对值点位，相当于远洋航行的坐标。
2. **拍卖机制（漂移）**——因做空受限，股价由最乐观资金定价，等于中线位置+截距。截距取决于预期分布离散度与流动性，带来"A"型波动。

二者结合：牛市前半段横着拔估值（上修天花板L，有基本面支撑，涨幅不回吐）；后半段竖着拔估值（降折现率r，流动性冲击，最终吐回去）。

## 分析工作流

分析一只股票时，按以下顺序推进。每步对应的详细方法论见 `references/` 下文件，估值反算用 `scripts/dcf_implied.py`。

### 第一步：反算当前股价隐含的天花板（最重要）

确定公司当前股价隐含的终局利润预期是什么。调用 `scripts/dcf_implied.py` 完成DCF反算：

**输入参数**：
- 当前市值（亿元）
- 未来3年分析师一致预期净利润 E1、E2、E3（从Wind/同花顺等获取）
- 折现率三档：r = 8%（低协方差红利资产）、10%（默认中性）、12%（高风险或流动性折价）

**模型假设**（v2.4.0变更：稳态期默认2035年，详见 `references/valuation-framework.md`）：
- 前3年（t=1,2,3）：直接使用一致预期 E1、E2、E3
- 第4年至稳态年（默认2035）：从 E3 起匀速（等比）增长至终局利润 L
  - 增长年数 N = 稳态年 - (基准年 + 3)，基准年=E0对应年份
  - 例：基准年2025，稳态年2035 → N=7（即2029-2035共7年匀速增长）
- 稳态年+1起（默认2036起，t=3+N+1..∞）：L 永续稳定，不给予永续增长率（g=0）
- 净利润 ≈ 权益现金流（忽略营运资本变动；若公司权益现金流远低于净利润，应定性下调L）

**输出**：三档折现率下各自反算的隐含终局利润 L、L/E3倍数、L/E0倍数、第4年至稳态年隐含复合增速 g、动态PE。

**后续判断**：
- 将隐含 L 与公司能够触达的理论业绩空间测算的终局利润对照 → 判断高估/低估/合理
- L/E3 倍数反映市场预期：<0.5 深度下滑、<1 下滑、1-2 温和增长、2-5 较高增长、5-10 高增长（叙事较饱满）、>10 极高增长（透支风险大）
- 三档折现率给出区间而非单点，更贴近现实中的不确定性
- 若公司权益现金流远低于净利润（重资产/应收高），应定性下调隐含L的合理性

**v2.4.0新增：反算各券商目标价隐含的理论业绩空间**

除反算当前股价外，必须同时反算国内外主流券商研报目标价隐含的终局利润L，并分解为可验证的微观指标。调用 `scripts/dcf_implied.py brokers` 子命令批量反算：

- 收集至少5-8家券商目标价（含外资投行如高盛/摩根士丹利/瑞银/摩根大通，国内券商如中金/中信/国泰海通/华泰/招商）
- 对每个目标价（×总股本=市值）反算三档折现率下的隐含L
- 将各券商隐含L分解为：TAM（市场总空间）× 市占率 × 净利率，判断券商假设的激进程度
- 对比外资 vs 国内券商目标价差异，分析预期分歧来源（通常外资更看重出海空间，国内更关注政策风险）
- 将各券商隐含L与加权理论业绩空间L对照，给出偏离度，判断券商目标价合理性

### 第二步：判断当前所处阶段

将个股累计涨跌幅与沪深300（或创业板指）对比，不断变换起始点位，走势重合段=叙事兑现期（无超额收益），分离段=叙事变化期（超额收益来源）。回答五问：

1. 之前的叙事是什么；2. 为什么旧叙事不对；3. 新叙事又是什么；4. 改变叙事的诱发因素；5. 新叙事形成的标志与超额收益结束信号。

核心判别：**起点决定涨幅**。当前隐含L越低（市场预期越悲观），未来上修空间越大；隐含L已远超公司能够触达的理论业绩空间测算，短期业绩double/triple都难再上修，需更宏大叙事。

### 第三步：评估叙事变化的可能性

按贝叶斯条件概率思考，把投资逻辑展开为"贝叶斯网"而非单链。对每个可能改变叙事的节点，评估其发生概率与信号。重点考察：

- **天花板高度L能否上修**：技术路线变化、政策导向、出海打开全球空间、第二增长曲线。
- **折现率r能否下移**：证明与宏观经济协方差低（穿越周期的业绩稳定性）、出海降低单一经济体依赖。注意"无风险利率下行利好权益"长期不成立，风险溢价才是关键。
- **向下叙事风险**：当前高隐含L+高预期=脆弱；业绩持续低于预期有惯性，"利空出尽"很少直接成利好。

警惕**景气度陷阱**：增速上修但天花板不变甚至下修（如5年3倍替代10年5倍），股价不涨反跌。详见 `references/methodology.md`。

### 第四步：识别拍卖机制的影响

判断当前股价中"中线位置"与"截距"各占多少：

- 预期分布离散度（天花板算不清、朦胧美）越高，截距越大，流动性敏感度越高。
- 观察个股涨幅与全A成交额的拟合度：拟合度高=截距水分大，涨跌同源，熊市必补跌；拟合度低（如长江电力）=靠中线位置支撑，抗跌。
- 牛市后期流动性正反馈阶段，越有基本面的票越跑不赢指数——这是离场信号而非加仓理由。

详见 `references/pricing-mechanism.md`。

### 第五步：商业模式与护城河定性

判断天花板高度L的可靠性及业绩能否稳定兑现：

- **成本曲线位置**：行业成本曲线陡峭+公司处于少数低成本端=稳定超额利润（如水电vs火电、神华一体化）。成本曲线平坦=同质化内卷。
- **分红率>股息率**：分红率是估值原因（大小股东利益一致性声明），股息率只是结果。高IRR<折现率时再投资减损价值。
- **出海能力**：同时上修天花板L与下移协方差（降折现率r），实现"斜着拔估值"。
- **社交/奢侈品属性**（白酒等）：核心是"一般等价物"定位，最贵=最好，聚焦单品高辨识度优于全价位覆盖（对比茅台vs五粮液贴牌）。

详见 `references/case-studies.md` 与 `references/key-insights.md`。

### 第六步：形成投资结论

综合给出：
1. 当前股价隐含的终局利润 L（三档折现率区间）；
2. 与公司能够触达的理论业绩空间测算对照的偏离度（高估/低估/合理）；
3. 可能的叙事变化方向、概率与信号；
4. 所处阶段（展望期/兑现期/流动性冲击期）；
5. 决策建议与风险提示。

3. **数据交叉验证**：表格中涉及计算的数据，须在表下文字中复述计算关系（如"市值=股价×总股本=XX元×XX亿股=XX亿元"），并与第二数据源对照。
4. **结果解读**：对表格输出结果逐行解读，不得只挑一行说明。重点解释异常值、拐点、区间含义。
5. **对结论的支撑**：该表结果如何支撑本步判断、如何衔接到下一步或核心结论。
6. **反例与局限**：该表假设的主要局限、可能被推翻的条件、反方观点。

**字数要求**：每个表格配套的文字论证**不少于 300 字**；涉及 DCF 反算、理论业绩空间情景、券商目标价隐含L对比、敏感性分析四类核心表格，配套文字**不少于 500 字**。

**禁止行为**：
- 禁止表格后仅跟一句"如上表所示，……"即转入下文。

### 数据质量红线（DATA QUALITY RULES）

- 所有金额数据获取后必须交叉验证：**股价 × 总股本 = 总市值（单位：亿元）**；所有表格涉及计算的都计算两次，确保正确，然后在表格下方小字注释所有数字计算关系。
- iFind / DataYes 返回的原始数据为"元"，必须 `/1e8` 转换为"亿元"，**禁止 `/1e9`**。
- DCF 反算结果出来后，必须用敏感性表反向验证至少一个数据点（如：用反算出的天花板高度 L 正算回市值，误差应 < 5%）。`scripts/dcf_implied.py` 的 `implied`/`analyze` 子命令已自动执行反向验证。
- 若一致预期净利润 > 当年营收 × 历史最高净利率，触发数据异常告警，暂停并重新核对，用标亮颜色提示。
- 所有金额单位统一标注"亿元"，禁止用"亿"简写；明确单位是人民币还是港元。
- **理论业绩空间情景表子项收入交叉验证（v2.3.0）**：情景表中任何分项收入均不得大于总营收。若出现"分项收入 > 总营收"的情况，触发数据异常告警。校验关系：**总营收 = 各分项收入之和**（误差 < 1%）。修正原则：以总营收为锚反推分项，再算市占率 = 分项收入 / TAM。
- **市占率合理性校验（v2.3.0）**：公司当前实际市占率 = 当期分项收入 / 当期市场TAM。情景假设市占率应与当前实际市占率合理衔接——保守情景不应大幅高于当前实际市占率。四档市占率应从当前实际市占率出发递增，每档增幅合理。
- **TAM起点必须检索当年实际值（v2.4.0新增）**：理论业绩空间情景表的TAM测算，必须先检索分析基准年的实际市场空间数据（如中国创新药市场2025年约1.22万亿元，来源中商产业研究院/沙利文），以此为起点外推至稳态年（默认2035）。禁止直接引用过时数据或拍脑袋假设TAM。检索关键词示例："中国创新药市场 2025年 市场规模 沙利文 前瞻产业研究院"。
- **正算L值与情景表交叉验证（v2.4.0新增，最重要红线）**：用加权理论业绩空间L正算合理市值时，必须先验证该L值确实来自情景表四档L的加权结果，而非其他数值。**常见错误根因**（恒瑞案例2026-06-30发现）：正算时误用了与情景表不对应的L值（如情景表加权L=539亿，正算却用了L=820亿），导致合理市值/合理股价计算错误，结论从"持有"错为"加仓"。**校验方法**：正算前调用 `dcf_implied.py` 的 `verify_L_vs_scenario` 函数，或手动核对——正算所用L必须在情景表四档L区间[min, max]内，且最接近某一档或加权值。正算结果出来后，用敏感性表反查：在敏感性表中找到正算所得市值对应的L/E3倍数，确认该L/E3与情景表加权L/E3一致（误差<2%）。

### 六步检查清单（SIX-STEP CHECKLIST，每一步必须逐条包含）

**通用要求（适用于全部六步）**：本步出现的每一个表格，都必须按上文"表格论证规范"配套文字版详细论证（目的/关键假设逐条解释/数据交叉验证/结果逐行解读/对结论支撑/反例与局限），核心表格≥500字、一般表格≥300字，禁止只放表不解读。

**第一步：反算隐含天花板**
- ☐ DCF 反算三档结果（8% / 10% / 12%），明确标注稳态年（默认2035）与增长年数N
- ☐ **反算各券商目标价隐含L**（v2.4.0新增，必须）：收集5-8家券商目标价，批量反算隐含L，分解为TAM×市占率×净利率
- ☐ 理论业绩空间测算对照（**先检索2025年实际TAM作为起点**，再建立四档情景推算合理L，与隐含L对照给出偏离度）
- ☐ 权益现金流 vs 净利润评估（若现金含量持续偏低，定性下调 L）
- ☐ L/E3 倍数解读（对照框架分级表：<0.5 / 0.5-1 / 1-2 / 2-5 / 5-10 / >10）
- ☐ 敏感性分析
- ☐ **正算L值与情景表交叉验证**（v2.4.0新增）：正算合理市值前，验证所用L值=情景表加权L
- ☐ **表格论证**：DCF输入参数表、DCF反算结果表（含L/E0+L/E3）、理论业绩空间情景表、券商目标价隐含L对比表、敏感性分析表——每表配套文字论证≥500字，逐条解释 E1/E2/E3 取值来源与调整依据、三档折现率对应资产属性、**稳态年2035与增长年数N的计算依据**、反算结果逐行解读、各券商目标价隐含L分解为TAM×市占率×净利率、与理论业绩空间偏离度的支撑关系

**第二步：判断当前所处阶段**
- ☐ 个股累计涨跌幅 vs 指数对比（用实际周线/月线数据，划分走势重合段=兑现期 / 分离段=叙事变化期）
- ☐ 变换起始点分析（至少 3 个起点，说明每个起点对应的隐含天花板高度 L 水平）
- ☐ 叙事演变五问（旧叙事→为什么不对→新叙事→诱发因素→形成标志与结束信号）
- ☐ "起点决定涨幅"判别（当前起点隐含 L 偏高还是偏低？上修空间多大？）
- ☐ **表格论证**：累计涨跌幅对照表、变换起点隐含L表、叙事演变五问表——每表配套文字论证≥300字

**第三步：评估叙事变化可能性**
- ☐ 天花板高度 L 能否上修（逐条列出支持因素 + 证据 + 权重，以及抑制/下修因素）
- ☐ 贝叶斯网络，分情景分析天花板高度上修的条件对应的概率，这部分重点拆解
- ☐ 折现率 r 能否下移（出海降协方差论证；"无风险利率下行利好权益"不成立，风险溢价才是关键）
- ☐ 风险分析，重点对天花板高度可能下修的情况进行分析，预判概率
- ☐ **表格论证**：L上修支持/抑制因素权重表、贝叶斯网络情景概率表、折现率r下移条件表、向下风险情景表——每表配套文字论证≥500字（贝叶斯网络表为重点）

**第四步：识别拍卖机制影响**
- ☐ 中线位置与截距分解（当前股价中 DCF 锚 vs 拍卖漂移各占多少）
- ☐ 个股涨幅与全 A 成交额拟合度分析（换手率/振幅/大跌归因/成交额-股价相关性 → 拟合度高/中/低）
- ☐ "起点决定涨幅"量化应用（L 上修/维持/下修三情景对应股价变动）
- ☐ **表格论证**：中线位置/截距分解表、成交额-股价拟合度表、三情景股价变动表——每表配套文字论证≥300字

**第五步：商业模式与护城河定性**
- ☐ 成本曲线位置（行业曲线陡峭还是平坦？公司处于低成本端还是高成本端？）
- ☐ 分红率 > 股息率分析（实查分红数据：历年 DPS/EPS/分红率/股息率；判断是否构成"大小股东利益一致性声明"）
- ☐ 出海能力（是否同时上修 L + 下移 r = "斜着拔估值"）
- ☐ 技术路线/竞争格局风险（决定 L 可达性的核心变量）
- ☐ 框架案例库对标（至少对标 2-3 个历史案例，说明相似维度与启示）
- ☐ **表格论证**：护城河评估表、分红数据表、案例对标表——每表配套文字论证≥300字

**第六步：投资结论（必须包含全部 5 项）**
- ☐ ① 隐含终局 L（三档折现率区间）
- ☐ ② 与理论业绩空间测算对照的偏离度（高估/低估/合理 + 百分比）
- ☐ ③ 可能的叙事变化方向、概率与信号（至少 3 个方向）
- ☐ ④ 所处阶段明确标注（展望期 / 兑现期 / 流动性冲击期）
- ☐ ⑤ 决策建议（赔率判断、胜率判断）
- ☐ **表格论证**：综合研判表、情景推演表、核心建议表——每表配套文字论证≥500字

### 隐含终局 L 的倍数列示要求

在分析股价中隐含的终局业绩 L 时，除了在表格中列举 **L/E3**，也必须同时列举 **L/E0**（E0 为分析基准年/最近已完成财年的实际净利润）。两列并列展示，便于横向对照市场对当前盈利的隐含透支/折价倍数。

## 方法论红线

分析过程中严格遵守（详见 `references/methodology.md`）：

- **逻辑推理优于归纳总结**。慎用统计回归，相关性不可传递，"先有结论再找论据"是常见陷阱。
- **做反方观点的最佳辩手**。穷尽反例仍无法反驳，才接受观点；忽略样本量与方差谈概率无意义。
- **贝叶斯回溯，不开后视镜**。按当时可得信息复盘，叙事先行，超额收益区间短暂且分布不均。
- **用统一框架解释尽可能多的现象**。解释范围最广的预测力最强；切忌为细分场景量身定做框架（成长/周期/价值贴标签是循环论证）。
