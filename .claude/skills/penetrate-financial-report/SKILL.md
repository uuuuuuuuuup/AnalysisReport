# 穿透财报分析框架（v4.0）

## 通用化说明（v5.0 新增）

本 skill 已支持任意 A 股公司分析。运行方式：

```bash
cd .claude/skills/penetrate-financial-report/scripts
python generate_report.py --company 中际旭创 --code 300308.SZ
```

输出：默认 `reports/中际旭创_300308_SZ/中际旭创_穿透财报分析报告.md` + 图表 PNG。
可选 `--format docx` 或 `--format html`。

本 skill 内部会调用 `penetrate-narrative-stock-analysis` 的 Agent 获取 DCF 和叙事结论。

数据源优先级：优先使用项目内 skill `mx-data` / `gtht-lingxi-unified` 获取市场数据与一致预期，
其次通过 AI-Tools 获取三张表数据，必要时再交叉年报 / 公开研报 / 行业研究报告。

## 核心理念

**我们不是给财报估值，我们是给叙事估值。** 投资在很大程度上，是"许许诺精彩的未来，然后拿走现在的全部"——所谓的"未来"就是终局，只要终局足够精彩，资本市场对过程的容忍度可以非常高。反之，如果终局不够精彩，无论过程多么波澜壮阔，市场都不会给予高估值。

本框架在 `penetrate-narrative-stock-analysis`（穿透叙事分析）的基础上，将**叙事定价**与**财报深度验证**深度融合：

1. **叙事先行**：用DCF反算当前股价隐含的终局利润L（天花板高度），判断市场预期的是什么叙事。
2. **三张表深度验证**：对资产负债表、利润表按完整科目逐项列示，**结合行业背景与公司经营情况，对每一项变动进行深度分析**（不局限于数据对比），判断财报是否在兑现/证伪叙事。
3. **交叉印证**：叙事预期 vs 财报现实，偏差即机会或风险。

### A股常见的财报阅读错误（必须规避）

> 忽略估值水平，只关注增速的绝对值、边际变化以及是否超预期，试图从这三个维度寻找下一段时间的市场主线。

正确做法：**先判断当前股价隐含的叙事（天花板L），再看财报是否在兑现或证伪这个叙事，最后对三张表完整科目逐项做结合行业背景的深度分析。** 增速本身不产生超额收益，叙事变化才产生超额收益。

### v4.0 核心变更（相对 v3.0）

1. **删除第四部分「全A样本分位数定位」**：不再强制用户上传「财务打分模型.xlsx」，不再生成全A样本对比章节。综合结论改为基于三张表深度分析的财务质量评估，不依赖分位数评级。
2. **大幅扩展第二部分「资产负债表深度分析」**：从 5 页扩展到 9-10 页。每个科目变动必须配套四要素分析（变动幅度 → 变动原因（结合行业背景+公司经营）→ 同业对比/历史对比 → 财务质量影响与风险提示），每条分析 ≥150 字。
3. **大幅扩展第三部分「利润表深度分析」**：从 4 页扩展到 7-8 页。六个分析维度每个维度增加分产品/分地区收入拆解、量价拆解、股权激励、减值方法论、税收优惠明细等深度内容。
4. **新增「行业背景与经营情况」分析框架**：在第一部分 1.1 增加「行业背景」子节，作为第二、三部分每项变动分析的锚点。
5. **报告篇幅下限（Word 版本）**：使用 `--format docx` 生成详细版时，正文 ≥ 20 页，禁止用空表/重复文字/放大字号凑页数。
6. `scripts/financial_scoring.py` 与 `scripts/financial_scoring_builtin.py` 降级为**可选工具**，不再用于报告生成。

## 分析工作流（五步法·v4.0）

### 第一步：反算股价隐含的叙事（天花板L）

调用 `penetrate-narrative-stock-analysis` skill 的 `scripts/dcf_implied.py`，或手动完成DCF反算：

**输入**：当前市值（亿元）、未来3年一致预期净利润 E1/E2/E3、折现率三档（8%/10%/12%）。
**模型假设**：前3年用一致预期，第4-8年从E3匀速增长至终局L，第9年起永续稳定（g=0）。
**输出**：三档隐含终局利润L、L/E3倍数、L/E0倍数、第4-8年隐含复合增速。

**叙事判断**（L/E3分级）：
- <0.5：深度下滑叙事
- 0.5-1：下滑叙事
- 1-2：温和增长叙事
- 2-5：较高增长叙事
- 5-10：高增长叙事（较饱满）
- \>10：极高增长叙事（透支风险大）

### 第二步：确定财报验证重点 + 锚定行业背景

根据第一步反算出的隐含叙事，确定财报中哪些部分最值得审视，同时锚定行业背景作为后续逐项变动分析的坐标系：

| 隐含叙事类型 | 财报验证重点 | 关键科目 |
|-------------|-------------|----------|
| 高增长叙事（L/E3>5） | 增长能否持续？收入质量是否真实？ | 营收增速、应收账款周转率、毛利率、经营现金流/净利润 |
| 温和增长叙事（L/E3 1-5） | 盈利能力是否稳定？再投资效率？ | 毛利率、固定资产周转率、ROE、营运资本占比 |
| 下滑叙事（L/E3<1） | 是否触底？资产质量恶化程度？ | 资产减值、资产负债率、现金流覆盖、商誉 |
| 周期反转叙事 | 库存周期位置？成本曲线位置？ | 存货周转率、毛利率变化、资本开支节奏 |
| 出海叙事 | 海外收入占比？汇率影响？ | 分地区收入、海外资产、汇兑损益 |

**行业背景锚定**（在第一部分 1.1 完成，后续每项变动分析引用）：
- 行业景气度：处于周期什么位置（复苏/扩张/见顶/衰退）？
- 竞争格局：集中度变化、价格竞争烈度、新进入者威胁
- 政策环境：产业政策、补贴退坡、环保/安全监管、贸易壁垒
- 技术变革：技术路线迭代、产能过剩/紧缺切换、国产替代节奏
- 上下游：原材料价格走势、下游需求结构变化、渠道库存

### 第三步：资产负债表深度分析（完整科目 + 逐项变动分析）

对最新一期及上一年年末资产负债表，按以下维度逐项排查，**每一项变动必须结合行业背景与公司经营情况分析原因**：

**生产类资产**（固定资产、在建工程、无形资产、商誉、使用权资产）：
- 固定资产周转率变化趋势 → 是否反映产能过剩/利用率不足？结合行业产能周期
- 在建工程是否长期不转固（利息资本化嫌疑）→ 结合公司扩产计划与行业供需
- 商誉占净资产比例（>30%需警惕减值风险）→ 结合被收购方业绩对赌与行业景气
- 无形资产结构（土地使用权 vs 专利 vs 开发支出）→ 结合公司研发投入与技术路线

**营运资本**（应收账款、预付款项、存货、合同资产、应付账款、合同负债）：
- 应收款项周转率与毛利率是否背离 → 结合行业账期惯例与公司客户结构
- 营运净资产（不含存货）/总资产趋势 → 结合产业链话语权与竞争格局
- 存货周转变化（存货异常堆积=滞销或虚增）→ 结合行业库存周期与渠道库存
- 合同负债 vs 预收账款变化（订单景气度信号）→ 结合下游需求与公司订单能见度

**金融类资产**（交易性金融资产、长期股权投资、其他权益工具投资）：
- 金融资产占比是否过高（脱实向虚）→ 结合公司战略与闲置资金用途
- 长期股权投资收益 vs 投资现金流（关联方输血嫌疑）→ 结合参股公司经营
- 公允价值变动损益占比（利润稳定性）→ 结合金融资产标的性质

**负债与权益**（短期借款、长期借款、应付债券、递延所得税）：
- 有息负债率变化趋势 → 结合融资环境与公司资本开支计划
- 短期借款 vs 货币资金（短债长投风险）→ 结合债务到期结构
- 递延所得税资产/负债变化（利润调节信号）→ 结合可抵扣暂时性差异来源

### 第四步：利润表关键科目拆解（完整科目 + 逐项变动分析）

按重构后的利润表架构拆解，**每一项变动必须结合行业背景与公司经营情况分析原因**：

```
营业总收入
  - 营业总成本（营业成本 + 税金及附加 + 三费 + 财务费用）
  = 营业利润（经营性）
  + 其他收益（政府补助等）
  + 投资净收益（对联营合营企业 + 金融资产）
  ± 公允价值变动 / 减值损失 / 资产处置收益
  = 营业利润（合计）
  ± 营业外收支
  = 利润总额
  - 所得税
  - 少数股东损益
  = 归母净利润
```

**重点拆解维度**（每个维度结合行业背景深度分析）：
1. **收入质量**：营业收入 vs 销售商品收到现金（收现比）；营收增速 vs 应收增速；分产品/分地区收入拆解；量价拆解
2. **成本结构**：毛利率变化归因（量/价/成本结构）；三费率变化趋势；结合原材料价格与产品定价权
3. **非经常性损益**：政府补助、投资收益、公允价值变动占比（>30%需扣非看）；结合产业政策与参股公司经营
4. **减值损失**：资产减值 + 信用减值占利润比例（大幅波动=利润调节嫌疑）；结合行业景气与减值方法论
5. **所得税有效税率**：与法定税率偏离原因（递延税、税收优惠、海外税差）；结合高新认定与税收优惠明细
6. **扣非净利润与 EPS**：扣非占比、股本稀释原因；结合股权激励与回购

### 第五步：形成综合结论

综合叙事预期与三张表深度分析结果：
1. 当前股价隐含的叙事（天花板L三档区间 + L/E3 + L/E0）
2. 财报是否在兑现/证伪这个叙事（三张表逐项分析结果汇总 + 异常科目）
3. 财务质量评估（基于三张表分析的盈利质量、资产质量、现金流质量、产业链地位、再投资效率五维评估）
4. 主要风险点（异常科目 + 行业下修风险 + 叙事下修风险）
5. 结论：叙事与财报是否一致？是否存在预期差？

## 详细版报告生成规范（自动执行 · v4.0）

> **触发条件**：当用户说"分析[公司名称]""[公司名称]穿透财报分析""财务分析[公司]""穿透财报[公司]""分析某公司"并指明公司名称时，**无需额外确认，立即按本规范自动执行完整穿透财报分析**，默认输出 Markdown + 图片（PNG），可通过 `--format docx` 或 `--format html` 生成 Word / HTML 版本。

### 一、角色与任务

执行者角色：兼具「叙事定价」与「三张表深度验证」能力的资深财务分析师。任务：对用户指明的目标公司，运用**穿透叙事 + 三张表完整科目深度分析**框架，生成一份完整的穿透财报分析报告。

核心理念：**我们不是给财报估值，我们是给叙事估值。** 超额收益只来自叙事变化，而非增速本身。因此报告顺序固定为——先反算当前股价隐含的终局叙事（天花板 L），再对三张表完整科目逐项做结合行业背景的深度分析以验证/证伪该叙事，最后给出预期差判断。

**v4.0 核心要求**：三张表分析**不局限于数据对比**，必须结合行业背景、公司经营情况，对每一项变动进行深度分析（变动原因 → 同业/历史对比 → 财务质量影响 → 风险提示）。

A股常见错误（必须规避）：忽略估值水平，只盯增速绝对值、边际变化、是否超预期。正确做法：先判断隐含叙事，再看财报是否兑现，最后对三张表完整科目结合行业背景逐项深度分析。

### 二、输入与数据来源

- **输入**：用户指明的公司名称（A 股或港股）与股票代码。
- **数据来源优先级**：
  1. **项目内 skill**：`mx-data` / `gtht-lingxi-unified` 提供市值、股价、一致预期净利润与部分财报数据。
  2. **AI-Tools**：通过 `GetBalanceSheet` / `GetIncomeStatement` / `GetCashFlowStatement` / `GetFinancialIndicators` 等工具获取三张表数据。
  3. 公司年报/季报（合并报表口径）、公开研报、行业研究报告与产业链数据：用于交叉印证与深度分析。
  4. **（可选）用户上传的「财务打分模型.xlsx」**：v4.0 不再强制，仅作为辅助参考；未上传不影响报告完整性。

### 三、数据质量红线（强制）

1. **总市值交叉验证**：股价 × 总股本 = 总市值（亿元），三者必须自洽。
2. **单位换算**：Wind/iFind 原始数据为「元」，必须 `/1e8` 转为「亿元」，**严禁 `/1e9`**。
3. **DCF 反算校验**：反算结果须用敏感性表反向验证，误差 < 5%。
4. **一致预期异常告警**：若一致预期净利润 > 当年营收 × 历史最高净利率，触发数据异常告警并人工复核。
5. **季度同季对比**：Q1 比 Q1，Q2 比 Q2，不可跨季度比较（消除季节性）。
6. **单位统一**：所有金额标注「亿元」，并注明人民币/港元；港股按报告期末汇率换算为人民币后标注。
7. **三张表联动**：利润表每个科目变化，须在资产负债表/现金流量表找到对应。利润表是「意见」，资产负债表是「存在」，现金流量表是「事实」。
8. **六大循环配平**：投资筹资、采购付款、生产存货、销售收款、人力资源、货币资金循环，每个循环局部配平。
9. **每项变动必配分析**：三张表中任何变动 > 5% 的科目，必须配套文字分析（变动原因+行业背景+经营情况+影响），禁止「只列数据不分析」。

### 四、报告结构与内容要求（逐部分）

> **全报告正文 ≥ 20 页**（v4.0 强制下限，禁止用空表/重复文字/放大字号凑页数）。章节间用空段落分隔，不另起页（紧凑布局）。表格约 18 个、图表 12 张。变动 > 20% 的科目一律标红。

#### 封面信息块（紧随标题）

- 标题：`{公司简称} 穿透财报分析报告`
- 副标题：`叙事先行 · 三张表完整科目深度验证 · 行业背景联动分析`
- 逐行列示：公司简称、股票代码（A 股 .SZ/.SH；港股 .HK，如两地上市并列）、所属行业（申万一级）、分析日期（当日）、分析框架（穿透叙事 + 三张表完整科目深度分析 v4.0）、数据来源（公司年报/季报 + 公开研报 + 行业研究报告）。
- 末行免责声明：`【免责声明】本报告基于公开信息分析推演，不构成投资建议。`

---

#### 第一部分　叙事先行——反算股价隐含预期（约 3 页）

##### 1.1 公司概况与行业背景
- **公司概况**（一段话）：成立年份、上市时间与板块、主营业务、行业地位（市占率/排名等关键事实）。
- **行业背景**（一段话，v4.0 新增，作为后续变动分析的锚点）：行业当前所处周期位置、竞争格局（集中度/价格竞争）、政策环境、技术变革、上下游供需。**此段为第二、三部分每项变动分析的行业坐标系，必须具体到可量化指标**（如行业产能利用率、原材料价格涨跌幅、下游增速等）。
- 配 **7×4 概况表**（项目|内容|项目|内容），字段：公司简称、股票代码、一级行业、上市年份、当前股价、总股本、当前市值、{最新年度}营收（含增速）、核心市占率×2、{最新年度}归母净利润（含增速）、{最新年度}ROE。

##### 1.2 DCF 反算隐含终局利润 L
- 一段话说明模型：基于 DCF 第一性原理，用当前市值 + 前 3 年一致预期净利润反推股价隐含的终局利润 L。**模型假设固定**：前 3 年用一致预期 E1/E2/E3；第 4-8 年从 E3 匀速增长至 L；第 9 年起永续稳定（g=0）。折现率取 8%/10%/12% 三档。
- 配 **DCF 敏感性表（4×5）**，列：折现率 r | 隐含终局利润 L（亿元） | L/E3 倍数 | L/E0 倍数 | 第4-8年隐含复合增速 g。三行对应：
  - 8%（低协方差红利资产）
  - 10%（默认中性）
  - 12%（高风险/流动性折价）
- **强制**：表格必须同时列举 L/E3 与 L/E0 两套倍数。

##### 1.3 叙事类型判断与产业空间对照
- 以中性 r=10% 为基准，给出 L/E3 与 L/E0 两个倍数并解读。
- **L/E3 叙事分级**：<0.5 深度下滑；0.5-1 下滑；1-2 温和增长；2-5 较高增长；5-10 高增长（较饱满）；>10 极高增长（透支风险大）。
- 结合市场对可见期（如 2026-2028）净利润的预期，判断估值由近期业绩兑现还是远期叙事驱动。

##### 3.4 减值损失分析（约 1 页 · v4.0 扩展）
- **信用减值损失**：应收账款坏账计提，结合账龄结构与客户信用；应收质量改善/恶化判断。
- **资产减值损失**：占利润总额比；拆解存货跌价/固定资产减值/商誉减值/无形资产减值比例与计提比例；结合行业景气（价格下跌→存货跌价、产能过剩→固定资产减值、被收购方业绩不及预期→商誉减值）；减值方法论（单项/组合、可收回金额测算）。
- **整体减值占利润总额比**，判断是否存在大额减值操纵（大洗澡/隐藏利润）；与历史减值节奏对比。

##### 3.5 利润总额与所得税（约 1 页 · v4.0 扩展）
- **营业利润**、**利润总额**：{本年}增速、{最新Q1}同比；与归母净利润增速对比，判断利润结构（经营性 vs 非经常性）。
- **所得税费用 + 有效税率**：与法定 25% 偏离原因（高新 15% 优惠、海外税收优惠、递延税）；**税收优惠明细**（v4.0 新增）：列示公司享有的具体税收优惠（高新认定/西部大开发/出口退税/研发加计扣除）及到期时间，判断税收优惠可持续性。
- **净利润**、**少数股东损益**、**归母净利润**：{本年}增速、{最新Q1}同比；少数股东损益占比变化结合子公司股权结构。

##### 3.6 扣非净利润与 EPS（约 1 页 · v4.0 扩展）
- **扣非归母净利润**：与归母增速一致性 → 利润质量；非经常性损益 = 归母 - 扣非，算占比，判断扣非占比（>85% 为优）；非经常性损益明细（政府补助/投资收益/公允价值变动）。
- **基本 EPS**：{本年}增速 vs 归母增速，股本稀释原因（增发/转股/股权激励）；**股本变动追溯**（v4.0 新增）：列示报告期内股本变动事件及对 EPS 的影响。
- 末尾图注：`图3-1：{公司}营业收入与归母净利润趋势（{起始年}-{本年}）`（配图）。

#### 第四部分　综合结论（约 2-3 页 · v4.0 调整，原第五部分）

> v4.0 调整：综合结论不再依赖全A分位数评级，改为基于三张表深度分析的财务质量五维评估。

##### 4.1 叙事预期 vs 财报现实对比
- **7×4 表**：`维度 | 叙事预期 | 财报现实 | 是否一致`，6 行维度：增长水平、盈利质量、现金流质量、产业链地位、再投资效率、业绩可持续性。叙事预期列填 L/E0、L/E3 等量化锚；财报现实列填三张表分析得出的具体增速/比率/异常判断；是否一致列填「一致/背离」。

##### 4.2 财务质量五维评估（v4.0 新增，替代原全A分位数评级）
- **盈利质量**：毛利率/净利率水平与趋势、扣非占比、非经常性损益依赖度，结合行业可比公司。
- **资产质量**：应收账款质量（账龄/坏账）、存货质量（周转/跌价）、商誉减值风险、固定资产利用率，结合行业景气。
- **现金流质量**：经营性现金流/净利润、收现比、自由现金流（经营CF-资本开支），判断利润现金含金量。
- **产业链地位**：营运净资产/总资产（负值=强势占款）、应付应收差额、合同负债变化，结合行业竞争格局。
- **再投资效率**：固定资产+无形资产周转率、资本开支/折旧、ROIC，结合行业产能周期。
- 每维给「优秀/良好/中等/偏弱/危险」评级 + 1-2 句理由。

##### 4.3 主要风险点清单
- **7×4 表**：`风险类型 | 具体表现 | 严重程度 | 关注信号`，6 行。严重程度档：低/低中/中/中高/高。关注信号列填可跟踪的量化指标。风险来源：三张表异常科目 + 行业下修风险 + 叙事下修风险。

##### 4.4 预期差判断与关注信号
- 首行：`当前预期差判断：{中性偏正/中性/中性偏负}`。
- 4 点分析：① 叙事层面（L/E3 克制/饱满，估值驱动来源）；② 财报层面（三张表分析显示的财务质量五维评估结果）；③ 业绩可持续性（收入质量/成本结构/减值节奏）；④ 正向/负向预期差来源 + 下修空间判断。
- `未来关注信号：`后列 7 条可跟踪信号（季度毛利率、产能利用率、合同负债变化、业务结构占比、海外收入占比、固资周转率变化、原材料价格走势）。

### 五、格式与样式规范

1. **标题层级**：报告标题用 Title 样式；「第X部分」用 Heading 1；「X.Y」用 Heading 2。
2. **表格标红**：所有资产负债表/利润表中变动 > 20%（绝对值）的科目标红。
3. **单位**：所有金额「亿元」，每股收益「元」，比率带「%」。
4. **数字格式**：千分位逗号（如 4,237 亿元）；增长率带正负号（+17.0% / -19.0%）；无数据用「—」。

## 方法论红线

- **逻辑推理优于归纳总结**：慎用统计回归，相关性不可传递，"先有结论再找论据"是常见陷阱。
- **做反方观点的最佳辩手**：穷尽反例仍无法反驳，才接受观点。
- **贝叶斯回溯，不开后视镜**：按当时可得信息复盘，叙事先行。
- **三张表联动分析**：利润表的每个科目变化，都要在资产负债表和现金流量表中找到对应。利润表是"意见"，资产负债表是"存在"，现金流量表是"事实"。
- **权责发生制 vs 收付实现制**：净利润是"觉着自己赚了多少"，经营性现金流是"实际收到多少"，二者偏离即红旗。
- **六大循环配平**：投资筹资循环、采购付款循环、生产存货循环、销售收款循环、人力资源循环、货币资金循环，每个循环都应局部配平。
- **结合行业背景分析变动（v4.0 新增）**：三张表任何科目变动必须结合行业背景与公司经营情况分析原因，禁止「只列数据不分析」。
