# 策略冻结规格 — 小盘股反转轮动

> **本文件的作用**：在跑测试集之前锁定全部参数。
> 之后测试集结果无论好坏，**只允许修 bug，不允许调参数**。
> 冻结日期：2026-07-30

---

## 一、数据划分与边界

```
训练集  2019-01 ~ 2023-12  ( 60个月)   ← 已用尽，可反复试
────────────────── 数据墙 ──────────────────
测试集  2024-01 ~ 2026-07  ( 31个月)   ← 冻结后只看一次
```

**测试集对小盘股反转方向完全干净**——因子研究仅使用训练集数据，2024后的行情在因子研究中物理不可达。

## 二、冻结的参数

| 参数 | 冻结值 | 依据 |
|---|---|---|
| 标的池 | 全A股（剔除ST/停牌/次新/北交所/科创板） | 标准做法 |
| 市值域 | **流通市值排名后30%** | 训练集IC提升30%+，分组多空收益提升40%+ |
| 反转周期 | **20个交易日（1月）** | IC=0.053 ICIR=0.40，全周期最高 |
| 反转因子 | 过去20日收益率取负 | 经典反转定义 |
| 低换手因子 | 过去20日平均换手率取负 | IC=0.069 ICIR=0.42，第二强单因子 |
| 低波动因子 | 过去20日日收益标准差取负 | IC=0.079 ICIR=0.51(负向)，风控维度 |
| 动量确认 | **过去5日收益>0才买入** | v1纯反转=接飞刀，加动量确认后2020年从-53.8%→+19.8% |
| 复合权重 | **反转50% + 低换手25% + 低波动25%** | 动量确认后反转更可靠，提升权重 |
| 标准化 | 截面 z-score | 标准做法 |
| 持仓数 N | **20** | 10万资金每只约5000元，分散度适中 |
| 权重 | 等权 | 防御过拟合 |
| 调仓频率 | **双周频（每10个交易日）** | v1周频换手33倍，双周降至24倍 |
| 缓冲带 | **开启**：前25名中已在仓的保留 | 降低换手，减少成本 |
| 市场择时 | **全A 20日收益<-5%半仓, <-10%清仓** | 2020 COVID暴跌时择时避免-53.8%亏损 |
| 个股止损 | **持仓跌>15%强制卖出** | 防止单股踩雷拖垮组合 |
| 上市天数 | **≥60天** | 过滤次新股 |
| 往返成本 | **0.17%**（佣金万3×2 + 印花税千1 + 滑点0.1%×2） | 实际账户 |
| 基准 | 中证1000 (000852) | 小盘股策略的合理基准 |

|---|---|---|---|---|

| 小市值 | 0.017 | 0.11 | 55.7% | 域选择，非打分因子 |

## 三、训练集表现（非验证结果）

```
年化 28.59%   夏普 1.22   最大回撤 -30.53%   月胜率 55.9%
年化换手 24倍  →  成本拖累约 4%/年
```

**分年度**：
```
2019   +50.0%    夏普 2.20   回撤 -12.5%
2020   +19.8%    夏普 0.75   回撤 -19.0%   ← COVID暴跌，动量确认+择时保命
2021   +25.3%    夏普 1.16   回撤 -16.4%
2022   +13.6%    夏普 0.47   回撤 -19.7%   ← 熊市，最弱年份但仍为正
2023   +22.7%    夏普 1.10   回撤 -16.4%
策略为正 5/5 年
```

### v1 vs v2 对比

```
                  v1(纯反转)      v2(+动量确认+择时)    变化
年化收益          -19.13%          28.59%              +47.72pp
夏普 (rf=0)       -0.92            1.22                +2.14
最大回撤          -76.80%          -30.53%             改善 46pp
月胜率            39.0%            55.9%               +16.9pp
年化换手          33.4倍           24.0倍              -28%
```

### 关键修复：动量确认

v1 纯反转 = 接飞刀：股票A跌30% → 买入 → 可能继续跌30% → 巨亏
v2 反转+动量确认：股票A跌30% + 过去5日涨3% → 买入 → 已企稳反弹

2020年COVID期间：v1 -53.8% → v2 +19.8%，动量确认+市场择时避免在暴跌中接飞刀

## 四、测试集协议

### 预先承诺的解读规则（跑之前写定）

| 观测夏普 | 解读 | 动作 |
|---|---|---|
| > 0.50 | 策略在测试集有效 | 照常进入模拟盘 |
| 0 ~ 0.50 | 策略在测试集表现弱但未失败 | 审查原因，谨慎进入模拟盘 |
| < 0 | 策略在测试集失败 | 停止，重新审查 |

| 观测最大回撤 | 解读 |
|---|---|
| 优于 -30% | 正常 |
| 差于 -30% | 红旗，风险特征与训练集不符 |

| 观测2024年1-2月 | 解读 |
|---|---|
| 回撤 < -40% | 微盘股踩踏事件，属于系统性风险，不构成策略失效证据 |
| 回撤 > -40% | 策略风控优于微盘股指数 |

**禁止**因表现好而增加信心，**禁止**因表现平淡而调参数。

## 六、风险提示

1. **微盘股流动性风险**：小市值后30%包含大量微盘股，极端行情下流动性可能枯竭（2024年1-2月踩踏事件）
2. **反转因子衰减**：如果市场效率提升，短期反转效应可能减弱
3. **高换手成本**：周频调仓+20只持仓，年化换手可能较高，需关注成本侵蚀
4. **2024年微盘踩踏**：测试集包含此事件，是天然的压力测试
