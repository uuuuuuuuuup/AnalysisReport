# 策略冻结规格 — 多资产 ETF 动量轮动

> **本文件的作用**：在跑测试集之前锁定全部参数。
> 之后测试集结果无论好坏，**只允许修 bug，不允许调参数**。
> 冻结日期：2026-07-28

---

## 一、数据划分与边界

```
训练集  2015-10 ~ 2022-11  ( 86个月)  ← 已用尽，可反复试
────────────────── 数据墙 ──────────────────
测试集  2023-01 ~ 2026-07  ( 43个月)  ← 冻结后只看一次
```

训练集起点受三重约束，取最晚者：
1. 黄金ETF 518880 上市 2013-07-29
2. **中证1000 指数 2014-10-17 才发布**（聚宽无更早数据）
3. 统一 `MAX_K = 12` 个月动量回看，保证不同 K 值评估窗口可比

**已知代价**：统一窗口切掉了 **2015年6月股灾**——恰是检验绝对动量过滤最有价值的样本。
该偏差系统性地不利于过滤器，见第三节。

## 二、冻结的参数

| 参数 | 冻结值 | 依据 |
|---|---|---|
| 标的池 | 沪深300 / 中证500 / 创业板 / 红利 / 纳指 / 黄金 | 事前资产配置逻辑：A股大中盘+成长、防御风格、海外分散、实物资产 |
| 避险仓 | 国债ETF 511010 | 绝对动量为负时替代 |
| 动量回看 K | **6 个月** | 先验值（Antonacci 双动量标准设定），跑数据前即写定 |
| 持仓数 M | **2 只**，等权 | 同上 |
| 绝对动量过滤 | **开启** | 见第三节（数据上净负，基于先验保留） |
| 调仓频率 | 月频（自然月最后交易日） | — |
| 往返成本 | 0.16%（佣金万0.85×2 + 无印花税 + 价差约0.05%×2） | 实际账户免5+万0.85 |
| 基准 | 中证1000 (000852) | — |

**标的池选择偏差已检验并证伪**：
```
全标的池  年化 8.54%  夏普 0.64      仅A股  年化 8.45%  夏普 0.67
差距 0.09 个点（纳指被持有51%月份，却几乎无贡献）
```
→ 干活的是动量信号，不是特定资产。策略不依赖"事后知道该买什么"。

## 三、绝对动量过滤：为何数据为负仍保留

```
有过滤:  年化 8.54%  夏普 0.64  回撤 -14.98%  IR 0.49  国债月份占比 24.4%
无过滤:  年化 9.49%  夏普 0.69  回撤 -16.57%  IR 0.53
```

数据上净负（-1个点收益、-0.05夏普，换 +1.6个点回撤）。**仍保留，理由为先验而非数据：**

1. 评估窗口切掉 2015 股灾，正是过滤器最该发挥作用的样本 → 测试对它不公平
2. 时序动量是跨资产、跨百年样本最稳健的异象，有明确事前经济解释
3. 代价小（1个点），买的是训练窗口恰好未包含的尾部保护

**这是基于先验的决定。若因 86 个月样本就否决一个强先验风控件，等于重复"用训练集噪音调参"的错误。**

## 四、训练集表现（非验证结果）

```
年化 8.54%   夏普 0.64   最大回撤 -14.98%   波动 14.60%
超额 +9.00%  IR 0.49     月胜率 64.0%
年化单边换手 307%  →  成本拖累仅 0.49%/年
```

**⚠️ 超额 +9% 有水分**：同期中证1000 年化 **-5.17%**、回撤 -58.96%。
真正的成绩是绝对的 8.54% / 夏普 0.64 / 回撤 -15%，不是那个超额数字。

对照（同窗口）：
| | 年化 | 夏普 | 回撤 |
|---|---|---|---|
| 本策略 | 8.54% | 0.64 | -14.98% |
| 买入持有 沪深300 | 2.82% | 0.24 | -32.31% |
| 买入持有 中证500 | -0.97% | 0.07 | -43.21% |
| 买入持有 中证1000 | -5.17% | -0.08 | -58.96% |

**分年度**（策略为正 4/8，超额为正 6/8）：
```
2015  -3.3    2016 +16.9   2017 +18.6   2018  -5.4
2019 +10.9    2020 +34.7   2021  -3.6   2022  -1.5
```

### 三个必须正视的隐忧

**① 参数在训练集内部就不稳定**
前后两段（<2019 / ≥2019）夏普排序相关性仅 **0.155**。
K=12,M=3 前段 0.13 / 后段 0.79，剧烈不稳。
**网格中位夏普 0.28 可能才是更诚实的预期，而非 K=6,M=2 的 0.64。**

**② 训练集最后两年走平**
2021 -3.6%、2022 -1.5%，NAV 自 2021 年中横盘。测试集紧接其后。

**③ 绝对收益半数年份为负**
4/8 年为负（-3.3%、-5.4%、-3.6%、-1.5%），虽幅度都不大。

## 五、测试集协议

### 测试集能检测什么（先算清，防止事后过度解读）

```
43个月 = 3.58年
夏普标准误 ≈ √[(1+S²/2)/T] = √[(1+0.205)/3.58] = 0.58
若真实夏普 0.64 → 观测值 95% 区间约 -0.50 ~ +1.78
```

**43 个月无法确认夏普 0.64 非零，只能检测灾难性失败。定位：烟雾测试。**

### ⚠️ 夏普口径必须统一（协议修正 2026-07-28）

```
本规格所有夏普均为 rf = 0 口径:  sharpe = mean(月收益)/std(月收益) × √12
聚宽平台报告的夏普为 rf ≈ 4% 口径(已实测反推确认 4.06%)
换算:  sharpe(rf=0) = sharpe(聚宽) + 0.04 / 年化波动
```

**读平台数字时必须先换算，否则会把 0.072 拿去撞 -0.50 门槛而得出错误结论。**
（实例：2023-2024 平台报 0.072，换算后为 **0.285**，两者相差 0.21。）

### 预先承诺的解读规则（跑之前写定，不得事后修改）

| 观测夏普 **(rf=0 口径)** | 解读 | 动作 |
|---|---|---|
| > -0.50 | 落在预期分布内，**不构成任何证据** | 照常进入模拟盘/实盘 |
| < -0.50 | 超出 95% 区间下沿 | 停止，重新审查 |

| 观测最大回撤 | 解读 |
|---|---|
| 优于 -30%（训练集2倍） | 正常 |
| 差于 -30% | 红旗，风险特征与训练集不符 |

**禁止**因表现好而增加信心（43个月给不出这个结论），
**禁止**因表现平淡而调参数（那是把测试集变成训练集）。

### 测试集 notebook 的设计约束

`etf_rotation_holdout.ipynb` 刻意**不包含参数网格、不包含任何变体对照**，
只跑冻结配置 + 买入持有基准。让它在结构上无法用于探索。

## 七、Bug vs 调参 判定标准

| 情形 | 性质 | 允许修改 |
|---|---|---|
| 代码做的事和本规格不一致 | Bug | ✅ 修 |
| 取数越界、日期对不齐、下单失败未处理 | Bug | ✅ 修 |

## 九、测试集消耗记录 —— 已全部消耗

| 区间 | 月数 | 状态 |
|---|---|---|
| 2023-01 ~ 2026-07 | 41 | **已全部消耗** |

**自此，本策略无任何干净的历史样本外数据。唯一验证途径是前向实盘/模拟盘记录。**

### 完整测试集结果（2023-01 ~ 2026-07，41个月）

```
                训练集(86月)    测试集(41月)     比值
年化收益         8.54%          9.17%          1.07 ↑
年化波动        14.60%         22.20%          1.52 ↑
最大回撤       -14.98%        -21.33%          1.42 ↑
夏普(rf=0)       0.640          0.413          0.65 ↓
```

**夏普差 -0.227 = -0.38 个标准误（标准误 0.591）→ 统计上无法区分。**

### 按预先承诺规则判定：通过

- 夏普(rf=0) **0.413** > -0.50 → 落在预期分布内，照常进入实盘
- 最大回撤 **-21.33%** 优于 -30% → 正常
- 禁止因数字与训练集不同而调参数

### 关键发现：退化全在风险端，不在收益端

**收益甚至超过训练集**（9.17% vs 8.54%），但波动高 52%、回撤深 42%。
即"赚到了预期的钱，但过程比历史颠簸得多"。实盘预期应按测试集的风险口径。

### 分段反推（说明短样本的欺骗性）

```
2023-01 ~ 2024-12 (24月)  年化  5.42%
2025-01 ~ 2026-07 (17月)  年化 14.07%
合计      (41月)          年化  9.17%
```

**24 个月子样本给出 5.42%，完整 41 个月给出 9.17%——相差 2.6 倍。**
这正是夏普标准误公式预测的：24个月 SE≈0.79，本就无法定位真值。
**任何基于 1-2 年样本的结论都不可信，包括看起来"很差"的结论。**

### 最大回撤的成因（已知结构性弱点，非缺陷）

```
回撤区间 2024/10/08 ~ 2025/01/10，历时3个月，-21.33%
2024-09-30 调仓 -> 创业板+沪深300 (924行情使A股6月动量登顶)
随后A股急跌
```

6个月动量在月末测量时会被**单一剧烈月份主导**，导致在暴涨顶部买入。
这是月频动量的结构性特征。**不得为此调参数**（缩短回看期/加止损都是拟合）。

### 一个无法验证的已知未知

训练集上「仅A股」变体与全池几乎等效（差0.09个点），据此曾判定选择偏差被证伪。
但测试集期间策略重仓纳指+黄金（2023-2024 纳指17/24月、黄金15/24月），
**未知仅A股在测试集是否仍等效**。在测试集上跑该变体属于事后探索，规格禁止。

**代码验证：通过**
- 24 次调仓全部落在月末 14:45，无遗漏无重复
- 权重稳定 49.5%~50.3%，闲置现金 0.0%~1.0%，放大系数恒为 1.000
  （ETF 单价低，整数倍欠配几乎不存在；国债ETF 从未持有，其 110 元单价的隐忧未出现）
- 无下单失败、无「不调仓」、无死亡条件触发

累计 10.66%  年化 5.43%  年化波动 19.04%  夏普 0.285  最大回撤 -19.46%
超额 +16.67%  IR 0.322  (同期中证1000 -5.16%)
