## 三、冻结参数

| 参数 | 冻结值 | 依据 |
|---|---|---|
| 股票池 | 中证800历史成分股 | 流动性和100万元容量较好 |
| 因子 | BP、ROE | 训练区间最简且表现最佳的组合 |
| 因子权重 | 50% / 50% | 避免根据训练期强弱优化权重 |
| 持仓数 | 30只等权 | 研究组合口径；100万元单仓约3.3万元 |
| 调仓 | 每月首个交易日10:00 | 避开开盘价差最宽时段 |
| 信号日期 | 前一交易日 | 避免未来数据 |
| MAD去极值 | 5倍 | 训练研究口径 |
| 最短上市时间 | 120自然日 | 排除新股定价异常 |
| 交易成本 | 佣金万0.85免5；卖出印花税千1 | 实际账户参数 |

因子处理顺序：

```text
缺失剔除 → MAD去极值 → 申万一级行业+ln(总市值)中性化 → z-score
综合得分 = 0.5 × BP得分 + 0.5 × ROE得分
```

## 四、交易规则

1. 调仓日前一交易日取得中证800成分股、基本面和行业数据。
2. 排除ST、停牌、上市不足120日和价格无效股票。
3. 新买入遇涨停时按排名顺延；已有目标持仓不因涨停退出。
4. 按综合得分准备候选，选一手金额不超过放大后单仓预算的前30只。
5. 先卖出落榜股票，再等权买入目标股票。
6. 停牌或跌停卖不出的股票进入每日重试队列。
7. 对整数手造成的闲置现金有限放大目标值，现金低于1.5%即停止。
8. 不使用40日动量排除、止损、均线择时、排名缓冲或自动回撤清仓。

---

## 五、监控与失效条件

- 滚动12个月相对中证800超额小于0：告警。
- 滚动24个月相对中证800超额小于0：建议停用并复核。
- 最大回撤达到训练期最差约-35%：告警并人工复核。
- 所有条件仅告警，不自动交易。

---

## 六、容量与执行

- 10万元：基础单仓约3333元，高价股票可能一手买不起，必须按排名顺延。
- 100万元：基础单仓约3.33万元，对中证800流动性压力较低。
- 实盘预期必须计入成交价差、涨跌停和卖出延迟，不能直接采用研究组合收益。

---

## 七、不改清单

- BP与ROE各50%。
- 30只等权、月频调仓。
- 行业与市值中性化。
- 缺失值直接剔除。
- 不增加训练期未验证的过滤器或择时规则。
- 不依据2022-2026完整组合结果回调参数。
