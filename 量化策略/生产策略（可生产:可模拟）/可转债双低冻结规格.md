# 策略冻结规格 — 可转债经典双低轮动

> **本文件的作用**：在跑测试集之前锁定全部参数。
> 之后测试集结果无论好坏，**只允许修 bug，不允许调参数**。
> 冻结日期：2026-07-29

## 一、数据划分与边界

```
训练集  2019-01 ~ 2022-12  ( 48个月)   ← 已用尽，可反复试
────────────────── 数据墙 ──────────────────
测试集  2023-01 ~ 2026-07  ( 43个月)   ← 冻结后只看一次
```

起点约束：
1. 可转债日行情（CONBOND_DAILY_PRICE）从 2018-09-13 开始
2. 动量回看需要 3 个月前置 → 首期调仓 2018-12-28
3. 需用 bond.run_query 取价（get_price 对可转债返回全 NaN）

**测试集对可转债方向完全干净**——此前从未取过任何可转债数据，2023 后的行情在 notebook 中物理不可达。

## 二、冻结的参数

| 参数 | 冻结值 | 依据 |
|---|---|---|
| 标的池 | 全部可转债（A 股上市） | 截面排名需要最大池 |
| 打分因子 | **price 50% + premium 50%** | 经典双低。多因子（加动量）夏普 0.97 → 0.08 劣化 |
| 因子方向 | price 越低越好，premium 越低越好 | — |
| 标准化 | 截面 z-score | — |
| 去极值 | 无（z-score 自带标准化，可转债截面对比不需要） | — |
| 持仓数 N | **20** | N=30 夏普 1.01（最高），N=20 夏普 0.97；选 20 而非 30 因 10 万账户 5000 元/仓更可控 |
| 权重 | 等权 | 防御过拟合；IS/OOS -0.815 已证权重优化有害 |
| 调仓频率 | **月频**（每月最后交易日） | — |
| 调仓时间 | 14:45 | 收盘前，确保流动性 |
| 缓冲带 | **开启**：前 25 名中已在仓的保留 | 降换手（当前年化 958%）。与股票不同：CB 有溢价率独立维度，不制造价值陷阱 |
| 信用过滤 | **开启**：剔除正股 ST、转债价格 < 80 且溢价率 > 100% | 训练集选中搜特转债 33% 月份（后违约）。不剔除 ST + 违约信号组合 = 踩雷 |
| 剩余期限过滤 | 距到期 > 12 个月 | 到期 < 1 年的转债期权时间价值快速衰减 |
| 可交易性过滤 | 停牌、涨停排除 | 标准做法 |
| 往返成本 | **0.17%**（佣金万 0.85×2 + 无印花税 + 价差 0.05%×2） | 实际账户 |
| 基准 | 中证 1000 (000852) | 与 ETF 策略统一口径 |

### 为什么不用 premium 单因子

premium 单独年化 22.10%、夏普 1.13，比双低高 0.08。
不选它的理由：

1. **参数优化已被三轮实证否掉**：股票 IS/OOS -0.815、ETF 前后段 0.155、CB 前后段 -0.359
2. **单因子缺乏风控维度**：纯溢价率无债底锚，回撤 -19.4% vs 双低 -14.9%（深 30%）
3. **price 因子有独立作用**：当溢价率因子失效时（正股暴跌），低价转债有纯债价值兜底

测试集上会额外跑纯 premium 作为对照记录（非决策依据）。

### 因子贡献度（训练集，单因子跑 N=20）

| 因子 | 年化 | 夏普 | 最大回撤 | 换手 |
|---|---|---|---|---|
| premium | 22.10% | 1.13 | -19.4% | 0.584 |
| price | 13.28% | 1.06 | -14.2% | 0.239 |
| mom_1m | 11.98% | 0.62 | -24.0% | 0.840 |
| rev_3m | 2.39% | 0.23 | -18.8% | 0.615 |

## 三、训练集表现（非验证结果）

```
年化 15.32%   夏普 1.05   最大回撤 -14.9%   月胜率 64.6%
年化单边换手 958%  →  成本拖累 1.63%/年
```

⚠️ 训练集 48 个月 = 仅 4 年，夏普标准误约 0.55。
95% 置信区间下真值约 0.0 ~ 2.1，**区间本身包含零**。

**分年度**：
```
2018    +1.8%    (12月仅1个调仓点)
2019   +24.6%
2020    +9.9%
2021   +33.1%
2022   -10.1%
策略为正 4/5 年
```

**隐忧：**

① **信用风险在训练期内不可见**
被选中最多的搜特转债（16次/33%月份）2023年违约。2019-2022 零违约的历史给了虚假安全感。
2023 年后搜特、蓝盾等打破了"可转债零违约"记录。信用过滤只能在测试集验证其效果。

② **参数在训练集内部不稳定**
前后两段（<2021 / ≥2021）夏普排序相关性 **-0.359**。
N 敏感性网格中位夏普 0.97，说明 N 的选择对结果不敏感（都在 0.8-1.01）。

③ **2022 年 -10.1% 是唯一的负收益年份**
可转债整体在 2022 年受到利率上行+股市下跌双重打击。
没有连续两年亏损的记录（A 股策略有连续 2-3 年跑输的逆风）。

## 四、测试集协议

### 测试集能检测什么

```
43 个月 = 3.58 年
夏普标准误 ≈ √[(1+1.05²/2)/3.58] = 0.63
若真实夏普 1.05 → 观测值 95% 区间约 -0.19 ~ +2.29
```

**43 个月无法确认夏普 1.05 非零。只能检测灾难性失败。**

### ⚠️ 夏普口径

训练集使用 rf=0 口径：`sharpe = mean(月收益)/std(月收益) × √12`
与 ETF 策略一致，便于后期组合优化统一计算。

### 预先承诺的解读规则（跑之前写定）

| 观测夏普 (rf=0 口径) | 解读 | 动作 |
|---|---|---|
| > -0.50 | 落在预期分布内，**不构成任何证据** | 照常进入模拟盘/实盘 |
| < -0.50 | 超出 95% 区间下沿 | 停止，重新审查 |

| 观测最大回撤 | 解读 |
|---|---|
| 优于 -30%（训练集 2 倍） | 正常 |
| 差于 -30% | 红旗，风险特征与训练集不符 |

| 观测信用事件 | 解读 |
|---|---|
| 持仓中出现搜特级违约/退市 | 信用过滤失败，需升级过滤规则 |
| 持仓中无违约 | 过滤有效 |

**禁止**因表现好而增加信心（43 个月给不出这个结论），
**禁止**因表现平淡而调参数（那是把测试集变成训练集）。

### 测试集 notebook 的设计约束

只跑冻结配置 + 纯 premium 对照 + 买入持有基准。
**不包含参数网格、不包含任何变体探索。**

## 五、信用过滤规则（重要）

```
剔除条件（满足任一即剔除）：
1. 正股 is_st == True  （当前或最近1个月）
2. 转债价格 < 80 且 转股溢价率 > 100%
   （双低值为负数意味着极度低估，但同时极低价格 + 极高溢价 = 市场已定价违约概率）
```

搜特转债在 2022 年底时：价格 ~92 元、溢价率 ~30%，不触发条件 2。
但它 2023 年急速恶化。条件 2 无法提前捕获缓慢恶化的信用风险，
但可以拦住"市场已经明显定价了违约"的标的。

**条件 2 的有效性只能在测试集（2023-2026，含蓝盾、搜特违约事件）上验证。**

## 六、缓冲带规则

```
1. 对所有候选按 score 排序，取前 25 名作为候选池
2. 已在仓的标的如果在候选池中，优先保留
3. 剩余名额从候选池中按 score 从高到低补充，直到满 20 只
4. 若候选池中已在仓的 > 20 只，则按 score 排序后保留前 20
```

预期效果：换手降低 30-40%（年化从 958% 降至约 600-670%），成本拖累省 0.5-0.6 个点/年。

## 八-A、策略原创性声明

### 非原创部分（公开策略）

核心评分公式 **price + premium 各 50%，等权，月频调仓** 是可转债圈十多年的公开策略（经典双低），不是本项目的理论创新。参数 N=20 的标准设定也来自公开策略。

### 基于训练数据添加的部分（工程优化）

| 添加项 | 动机 | 类型 |
|---|---|---|
| 缓冲带（前25名保留在仓） | 训练集年化换手 958%，加缓冲带预期降 30-40% | 成本优化，非收益优化 |
| 信用过滤（price<80 且 premium>100%） | 训练集选中搜特转债 33% 月份，该标的 2023 年违约 | 风险修补，非收益优化 |
| 距到期 >12 月过滤 | 期权时间价值常识 | 标准做法 |

### 基于训练数据否决的部分

| 否决项 | 训练集证据 | 结果 |
|---|---|---|
| 动量因子 (mom_1m, rev_3m) | 单因子夏普 0.62/0.23，均弱于双低 1.05 | 保留经典双低 |
| 纯 premium 单因子 | 夏普 1.13 > 1.05，但回撤 -19.4% 更深、前后段相关性 -0.359 | 保留 price+premium 双因子 |

**否决比添加更关键——没有往公开策略上叠加"训练集优化过的调料"。**

### BigQuant 全量回测结果 (2019-01-01 ~ 2024-09-12)

```
                训练集(聚宽面板)   BigQuant回测      变化
年化收益         15.32%            15.02%          -0.30pp
夏普 (rf=0)      1.05              0.77           -0.28
最大回撤        -14.9%            -31.4%          恶化 2.1 倍
年化波动           —              15.93%            —
月胜率           64.6%             57.18%          -7.4pp
```

**关键发现：收益端基本稳住（15.32% → 15.02%），但风险端严重退化（回撤 -14.9% → -31.4%，深 2.1 倍）。**

这印证了"48 个月训练集太小"的结构性问题。训练集的 -14.9% 回撤远低于策略真实风险水平。实盘心理准备应按 -31% 做，而不是 -15%。

退化可能原因：
1. 2023-2024 可转债市场出现历史首次违约（搜特、蓝盾），改变了风险结构
2. 训练集 2019-2022 恰好在可转债"零违约"的黄金期，系统性低估了尾部风险
3. BigQuant 数据截止 2024-09-12，未覆盖 2024Q4-2026 的反弹

### ⚠️ 数据覆盖缺口

BigQuant 的 cn_cbond_bar1d_te 表仅覆盖到 2024-09-12，缺失 2024-10~2026-07 近两年数据。完整测试需等数据更新或切换到聚宽完成。
